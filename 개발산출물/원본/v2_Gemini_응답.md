## Part 1. 피드백 검토 및 핵심 문제 해결 방안

### 1. '도서관 방문 경험'의 재정의: 그래픽 연출 대신 '바텀 시트 컨텍스트 전환'과 '절제된 톤앤매너'
지적하신 대로 AI로 어설픈 '서가 일러스트'나 '줌인 애니메이션'을 구현하면 조악해지고 반복 사용 시 피로감만 높입니다. **"차갑지 않은 미니멀리즘"**으로 방향을 선회합니다.

* **공간 이동 없는 즉각적 전환 (Single-View Context Switch):**
  * 첨부해주신 지도 레퍼런스 화면처럼 **[상단 미니멀 지도 + 하단 바텀 시트]**의 단일 구조를 유지합니다.
  * 지도에서 특정 도서관 핀을 누르면 별도의 페이지로 이동하지 않고, **하단 바텀 시트의 헤더가 '전체 동네'에서 '선택한 도서관(예: 산수무등도서관)'으로 즉시 전환**됩니다.
  * 바텀 시트 내부에 곧바로 **① [도서관 광장 (지역 SNS)]**과 **② [내 발자취 (이곳에서 빌린 책)]** 두 개의 탭이 나타납니다.
* **AI가 실패하지 않는 '차갑지 않은 미니멀' 컬러 시스템:**
  * 그래픽 요소 대신 **배경색의 온도감과 여백, 가는 실선(1px border)**만으로 분위기를 잡습니다.
  * 순백색(`#FFFFFF`) 대신 **종이 질감에 가까운 미색(`#F9F8F6` 또는 `#F4F3EF`)**을 베이스로 깔고, 텍스트는 순수 검정 대신 **깊은 먹색(`#1C1C1E`)**, 포인트 컬러는 채도를 낮춘 **뮤트 세이지 그린 또는 웜 그레이** 1가지만 사용하여 단정하고 정적인 인상을 유지합니다.
* **홈 섹션 배치 유보:** 탭과 섹션의 구체적인 분할 비율은 본 개요 단계에서 확정하지 않고, **1차 와이어프레임 $\rightarrow$ 2차 디자인 시안 검토 단계**에서 시각적으로 비교해 결정합니다.

### 2. '반납 비서'의 사용자 수동 의존성 보완: 공공 API의 '상태 변화 감지' 활용
사용자가 매번 `[대여 예정 클릭 $\rightarrow$ 도서관 방문 $\rightarrow$ 대여 확인 클릭]`을 수동으로 해야 한다면 귀찮아서 쓰지 않게 됩니다. 공공 API에 '내 대출 조회' 권한은 없지만, **'특정 도서관의 특정 책이 현재 대출 가능한지(`loanAvailable: Y/N`)'는 조회할 수 있다는 점**을 역이용하여 반자동화합니다.

#### 💡 보완된 스마트 대여 플로우 (반자동 상태 감지)
1. **[찜하기 / 빌리러 가기]:** 사용자가 앱에서 빌리고 싶은 책을 골라 `[산수무등도서관에서 빌릴 예정]`(북마크)을 눌러둡니다. (이 시점엔 도서관에 책이 있음: `대출 가능 Y`)
2. **[현장 방문 & 바코드 인증]:** 도서관에 가서 앱 하단의 **모바일 회원증 바코드**를 찍고 책을 빌립니다.
3. **[자동 감지 및 원클릭 확정]:**
   * 사용자가 앱에서 바코드를 열었거나, 백그라운드에서 해당 도서관의 그 책 상태가 **`대출 가능(Y)` $\rightarrow$ `대출 중(N)`으로 바뀐 것이 감지**되면, 앱을 켰을 때 상단에 가벼운 토스트 배너를 띄웁니다.
   * *"방금 산수무등도서관에서 『채식주의자』를 빌리셨나요? [네, 반납일 챙겨주세요]"*
   * 사용자는 복잡한 입력 없이 **[네]** 버튼만 한 번 누르면 오늘 날짜 기준으로 +14일 반납 예정일이 자동 세팅됩니다.
4. **[OCR/바코드 스캔 보조]:** 예정 버튼을 안 누르고 그냥 빌려온 경우에도, 책 뒷면의 **ISBN 바코드를 폰 카메라로 1초 스캔**하면 도서 정보와 반납 예정일이 즉시 등록되게 하여 수동 입력의 번거로움을 없앱니다.

### 3. 알림 방식 검토: 디스코드 웹훅 vs 앱 알림 (웹 푸시 / 인앱 알림)
결론부터 말씀드리면 **사용자 경험(UX) 측면에서 '앱 자체 알림(인앱 알림 센터 + 브라우저 웹 푸시)'으로 가는 것이 훨씬 자연스럽고 서비스 완결성이 높습니다.**

| 비교 항목 | 앱 알림 (인앱 알림 센터 + Web Push) — **권장** | 디스코드 웹훅 |
|---|---|---|
| **사용자 경험** | 일반 상용 앱과 동일. 별도 외부 앱 설정 없이 앱 내 종 모양(🔔) 아이콘과 브라우저 푸시로 즉시 확인 | 일반 도서관 이용자에게 '웹훅 URL 발급/등록'은 진입장벽이 높고 서비스 톤앤매너와 이질적임 |
| **구현 방식** | • 접속 시: 상단 알림 배너 & 알림함(`Notifications` 테이블) 뱃지 표시<br>• 백그라운드: Web Notification API (브라우저 알림) 호출 | 백엔드에서 외부 Discord URL로 HTTP POST 전송 |
| **시연(데모) 전략** | 화면에서 '반납 임박 시뮬레이션' 실행 시 **모바일 화면 상단에 실제 푸시 알림 토스트가 내려오고 알림함에 빨간 불이 들어오는 연출** 가능 | 발표 시 브라우저 외에 디스코드 창을 별도로 띄워야 함 |

* **판단:** 도서관 커뮤니티라는 차분한 서비스 컨셉에는 개발자 친화적인 디스코드보다 **앱 내 자체 알림 시스템(인앱 토스트 + 알림 센터 + Web Notification API)**이 훨씬 어울립니다.

## Part 2. 한책 (Hanchaek) 프로젝트 기획 초안

### 1. 프로젝트 개요
* **서비스명:** 한책 (Hanchaek)
* **한 줄 정의:** 차갑지 않은 미니멀 지도 위에서 동네 도서관의 책을 찾고, 이웃의 독서 기록을 발견하는 로컬 도서관 커뮤니티 & 반납 비서
* **핵심 가치:**
  1. **직관적 탐색:** 복잡한 지도 정보는 지우고, 내 주변 도서관의 거리와 실시간 대출 가능 여부만 미니멀하게 표기.
  2. **공간 기반 커뮤니티:** 지도에서 도서관을 찍으면 그 도서관을 이용하는 동네 사람들의 핀터레스트형 독서 카드와 내 대여 발자취를 즉시 열람.
  3. **번거로움 없는 대여 관리:** 통합 바코드 회원증 제시부터 도서 대출 상태 변화 감지를 통한 원클릭 대여 등록 및 앱 푸시 반납 알림.

---

### 2. 핵심 화면 및 기능 구성 (초안)

#### ① 홈 화면 (데포르메 지도 + 컨텍스트 바텀 시트)
* **미니멀 데포르메 지도 (상단/배경):**
  * 상가/음식점 POI를 모두 제거하고 주요 도로망, 랜드마크, 내 위치(또는 집), 주변 도서관 마커만 미색/먹색 톤으로 정적 렌더링.
  * 도서관 마커에 거리(`800m`) 및 대출 가능 상태 표시.
* **동적 바텀 시트 (하단):**
  * **기본 상태 (전체 동네):** 우리 동네 인기 독서 스냅, 방금 반납된 추천 도서, 다가오는 반납 일정 요약.
  * **도서관 선택 상태 (도서관 방문 뷰):** 별도 페이지 이동 없이 시트 제목이 해당 도서관으로 바뀌며 아래 2개 탭으로 구성.
    * **탭 1 [도서관 광장]:** 이 도서관에서 책을 빌린 이웃들의 핀터레스트형 감상 피드.
    * **탭 2 [내 발자취]:** 내가 이 도서관에서 빌렸던 책과 기록들을 모아보는 공간.
  * *(※ 홈 화면의 세부 섹션 분할과 탭 배치 비율은 1차 와이어프레임 및 2차 디자인 시안 단계에서 최종 확정)*

#### ② 핀터레스트형 로컬 독서 SNS
* **2열 메이슨리(Masonry) 그리드 피드:** 이미지와 타이포그래피 중심의 감성 독서 카드 배열.
* **3종 배경 & 텍스트 템플릿 제공:**
  * 직접 찍은 사진 / 고화질 책 표지(알라딘·카카오 도서 API 활용) / 차분한 단색·종이 질감 배경 중 선택.
  * 좋아하는 구절을 사진 위에 얹는 미니멀 고딕, 타자기 명조, 만년필 손글씨 템플릿 지원.
* **즉각적인 도서 연결 (Actionable Card):**
  * 게시물 클릭 시 본문 감상과 함께 **[내 주변 도서관 대출 가능 확인]** (1순위) 및 **[Yes24에서 구매하기]** (ISBN 연동 링크) 버튼 제공.

#### ③ 전체 독서 아카이브 & 스마트 반납 비서 (하단 바 메뉴)
* **통합 독서 아카이브:** 도서관 구분 없이 내가 읽은 전체 독서 기록과 통계를 한곳에서 조회·필터링(지도에서 특정 도서관을 찍어 볼 때의 공간적 경험과 분리된 개인 서재 경험).
* **통합 모바일 회원증:** 도서관 키오스크에서 즉시 스캔 가능한 책이음 바코드(Code 128) 모달.
* **스마트 대여 확인 및 앱 알림:**
  * `[빌릴 예정]` 등록 도서의 공공 API 대출 상태(`Y` $\rightarrow$ `N`) 변화를 감지하거나 바코드 사용 이력을 바탕으로 **"방금 이 책을 빌리셨나요?" 원클릭 대여 확정 팝업** 제공 (ISBN 바코드 스캔 등록 병행).
  * 반납 예정일(D-3, D-1, 당일) 도래 시 **앱 내 푸시 배너 및 알림 센터**를 통해 연체 방지 리마인드 제공.
