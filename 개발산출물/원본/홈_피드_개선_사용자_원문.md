# 홈·피드 개선 사용자 원문 (2026-11-23)

## 최초 요청

아래 5가지 홈/피드 개선 사항을 기존 명세서·계약서(library-visit, local-feed, book-search)와 대조해 명세화(문서·계약 개정 초안 정리)해줘. 바로 코드 구현은 하지 말고, 충돌/결정 필요 사항이 있으면 먼저 정리해서 확인받아줘.

1. 큐브 뚜껑 글자·색 페어링 확정 반영
- 근거 시안: `개발산출물/시안/큐브_뚜껑_색페어링_시안.html` (D안 확정)
- 대상: `mobile/src/features/library-visit/FacadeHome.tsx`, `mobile/src/theme/tokens.ts`
- 내용: 화이트 계열 5종(`marshmallow`, `neutral`, `porcelain`, `eggshell`, `vanillaCanvas`)만 어두운 글자(대비 4.5 이상, `#1D1D1F` 기준)를 사용하고, 나머지 16종(`CUBE_PALETTE` 15종 + `pinClosed`)은 전부 `#FFFFFF` 적용.

2. 큐브 운영 시간(`TODAY`) 미표시 수정
- 대상: `server/app/routers/libraries.py` (`library_summary`, `today_hours`, `closed_today`), `mobile/src/features/library-visit/FacadeHome.tsx`
- 내용: 현재 `is_closed is False`일 때만 `hours_text`를 내려줘서 휴관 미확인(`is_closed: null`) 도서관의 `TODAY`가 비어 보임. 휴관이 확실한(`is_closed is True`) 경우를 제외하고 운영시간을 내려주도록 파서/응답 규칙과 프론트 fallback 정리.

3. 가로 스크롤 `< >` 버튼 추가 (웹 접근성 개선)
- 대상 3곳:
  - 홈 "이 동네 인기 도서": `mobile/src/features/library-visit/PopularBooksRow.tsx`
  - 검색 진입 "최근 본 도서": `mobile/src/features/book-search/SearchEntry.tsx`
  - 방문 화면 책장: `mobile/src/features/local-feed/Bookshelf.tsx`
- 내용: 마우스 휠/터치 없이도 넘길 수 있게 3곳 모두 `< >` 버튼 규칙(배치 위치, 한 번 누를 때 이동 폭, 양 끝 비활성화/숨김) 명세화.

4. SNS 피드 부족 시 지역 단위(구 → 시) 확장 채우기 + 도서관명 필 표기
- 대상: `mobile/src/features/library-visit/LibraryNewsSection.tsx`, `useHomeFeed.ts`, `mobile/src/features/local-feed/PostCard.tsx`, `server/app/routers/feed.py`
- 내용:
  - 선택한 도서관의 게시물이 화면 채우기에 모자랄 때 `해당 도서관 → 같은 구(dtl_region_code) → 같은 시(region_code)` 순으로 게시물을 긁어와 채우는 기준(최소 채움 개수, 중복 제거, 정렬, 기존 무한스크롤/커서와의 관계) 명세화.
  - 다른 도서관에서 가져온 게시물(또는 확장된 피드) 카드 우측 상단에 작은 알약(필) 형태로 도서관 이름을 짧게 표기하는 UI 규칙 정리.

5. 시연용 도서관 임시 게시물 mock 데이터 시드
- 대상: `server/app/seed.py` (또는 별도 시연 시드 스크립트)
- 내용: 광주 북구·동구·남구(특히 광주 중앙, 산수, 사직 방면 도서관 전체)에 시연 시 눌러볼 임시 게시물(`posts`)을 멱등하게 채우는 규칙·구성안 정리.

## 추천안 확인 및 변경 지시

표의 추천대로 진행

- 흰글자에 대비 규칙 문제는 뚜껑에 대해서 대비 규칙 전부 무시
- 도 지역은 같은 도 전체 허용. 피드에 대해서 지금은 방문 기록이 없으면 가까운 후보 중 **자체 글이 있는 첫 도서관**을 자동 선택합니다. 이 규칙을 유지하고, 세 후보가 모두 비었을 때만 가장 가까운 곳을 기준으로 지역 글을 채우는 안을 추천한 거도 함께 적용
- 시연 범위는 최소 포함이 남구 문화정보, 계림꿈나무, 광주사직, 광주중흥, 광주중앙, 광주산수, 금호평생교육원, 북구는 중흥,무등과 무등 기준으로 잡았을 때 인근 도서관. 게시물은 도서관마다 업로드 가능한 종류(책 관련 게시물 5, 방명록 1, 모임 1) 다 넣어서
