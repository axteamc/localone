# 00. 기획 원본 — 의도 보존 기준

> 상태: **운영**(2026-11-11 작성). 담당: D. **모든 산출물보다 앞서는 기준 문서**다. 01·02·계획 등은 이 문서와 원문 파일에서 파생되며, 어긋나면 파생 문서를 고친다. 이 문서의 §2(우선순위)와 `원본/` 폴더는 사용자만 바꾼다.
> 만든 이유: 사용자 기획 → Gemini `v2.md` → Codex 기획 문서로 이어지는 전달 과정에서 중심(도서관 기반 지역 커뮤니티)이 보조(반납 비서)로 뒤바뀌었다. 원인 요약은 이 문서 §8, 변경 기록은 [스펙 변경 이력 C-12](스펙_변경_이력.md), 규칙은 `../team/docs/문서_운영.md` §4.

## 1. 원본 파일과 읽는 순서

| 파일 | 성격 | 규칙 |
| --- | --- | --- |
| [원본/기획_원문_사용자.md](원본/기획_원문_사용자.md) | 사용자의 최초 기획 원문 | **불변.** AI가 고치지 않는다. 다른 AI에게 넘길 때는 요약이 아니라 이 파일 |
| [원본/v2_Gemini_응답.md](원본/v2_Gemini_응답.md) | Gemini의 응답(제안). 기존 문서의 직접 입력 | **불변.** 제안이며 확정이 아니다 |
| 이 문서 §2 | 우선순위 선언 | 사용자만 바꾼다 |
| 이 문서 §3~§6 | 추적·점검 | 기획 문서를 고칠 때마다 AI가 갱신한다 |

1. 기획·요구사항·계획·시안을 쓰거나 고치기 전에 원문 파일과 §2를 먼저 읽는다.
2. 새 아이디어·다른 AI의 제안·사용자의 새 지시가 들어오면 §3에 줄을 추가하고, §2와 충돌하면 사용자에게 먼저 묻는다.
3. 문서 작업을 마칠 때 §5(AI 추가)와 §3(원문 반영)을 맞추고 답변 끝에 "원문에 없는데 넣은 것 / 원문에 있는데 뺀·바꾼 것"을 적는다.

## 2. 우선순위 선언 (사용자 결정)

출처: 원문 첫 줄 + 2026-11-11 사용자 확인("반납 비서는 원하는 기능이지만 처음 구상은 단순한 버튼 방식").

| 구분 | 내용 |
| --- | --- |
| **중심** | 지도에서 도서관을 골라 "방문"하는 경험, 그 도서관 기반의 지역 독서 커뮤니티(핀터레스트형 SNS, 독서 기록) |
| **보조** | 빌리는 책을 편리하게 확인하는 기능: 소장·대출 가능 조회, 빌릴 예정 → 빌렸어요 → 타이머·알림 → 반납했어요 |
| **안 함** | 공공 데이터 상태 변화로 대출을 추정·제안하는 기능, 도서관 회원증 바코드, 영수증 OCR, 서버 푸시·알림함 (2026-11-11 사용자 결정, C-11) |

이 표와 충돌하는 제안은 사용자 확인 없이 요구사항에 넣지 않는다. "보조"가 "중심"보다 요구사항·수용 기준·일정에서 더 무거워지면 §6에서 걸러 낸다.

## 8. 왜 뒤틀렸나 (원인 요약, 2026-11-11 분석)

확인 가능한 입력은 사용자 원문, `v2.md`, 기존 문서 세 가지뿐이다. Gemini 대화 전체와 Codex 지시문은 없어서 일부는 추정이다.

1. **전달 사슬이 길고 매 단계가 앞 단계의 결과만 받았다.** 사용자 → Gemini → Codex → 문서. 원문과 대조하는 단계도, 사용자가 중간에 확인하는 단계도 없었다.
2. **Gemini는 "도움이 되려는" 방향으로 넓혔다.** 반납 비서에 자동 감지·회원증·OCR·알림 비교를 붙여 핵심 가치 3개 중 하나로 키웠고, 광장·발자취를 대출 이력에 묶었다(§4).
3. **Codex는 "엄밀하게" 하는 방향으로 변형했다.** `v2.md`를 유일한 입력으로 보고 Gemini의 기능을 지우지 않은 채 "후보"로 남겼다. 날짜·알림·격리처럼 수용 기준을 쓰기 쉬운 쪽이 두꺼워지고, 느낌이 중요한 방문·시각 카드는 한 줄 "지향"이 되었다.
4. **기술 선행 순서가 제품 우선순위를 정해 버렸다.** 인증 → 도서 → 대출 → 기록 → 커뮤니티 순 일정으로 가장 중요한 기능이 맨 뒤(M2)로 갔다.
5. **팀 규칙의 Step 상한이 범위를 깎았다.** 넘치는 부분을 사용자 확인 없이 대기 목록으로 돌렸다(구매 링크·카드 서체).
6. **"그래픽 연출 제거" 피드백이 방문 경험 전체를 지웠다.** 연출만 빼고 방문 느낌은 다른 방식으로 살렸어야 했다.
7. **검토하는 쪽도 파생 문서만 보면 같은 오류를 낸다.** 이 분석 과정에서 Claude도 원문 없이 처음 검토하다 "피드가 도서관에 갇혔다"고 잘못 지적했다.

대책은 `../team/docs/문서_운영.md` §4의 규칙 1~9이다.
