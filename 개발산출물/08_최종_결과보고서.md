## 1. 프로젝트 개요 및 문제 정의

- **서비스명**: **동네한권 (localone)**
- **핵심 정의**: *"도서관에 갈 사람만 쓰는 앱이 아니라, 앱을 열다 보면 동네 도서관에 가고 싶어지게 만드는 지역 독서 커뮤니티"*
- **기간 및 산출 범위**: 2026-11-10(화) ~ 2026-11-26(목) (훈련일 12일, 총 PR 331건, DB 마이그레이션 `0001`~`0033`)
- **문제 해결 방향**:
  1. 기존 공공 도서관 유틸리티 앱의 단순 검색·CRUD 한계를 넘어, **도서관 방문 경험(파사드 큐브 홈 → 도서관 광장 2열 피드 → 오늘의 서가 3장 체제 → 방문 스탬프·한마디 → 작은 모임)**을 중심 가치로 재구성했다.
  2. 공공 API가 실시간 개인 대출 원장을 제공하지 않는 현실 제약을 반영해 **"빌렸어요" 수동 기록 + 서울(KST) 날짜 D-day 타이머·기기 알림**으로 반납 비서를 부담 없는 보조 기능으로 설계했다.
  3. **React Native + Expo 단일 코드베이스**로 iOS · Android · Web 3개 플랫폼을 동시에 지원하고, **FastAPI + PostgreSQL(Supabase) + Google Cloud Run**으로 실서비스 운영 배포까지 완료했다.

## 4. 도메인 모델 · DB · 백엔드 · 앱 구현 구조

- **DB 스키마 (`server/migrations/versions/0001`~`0033_user_public_profile`)**:
  - PostgreSQL(Supabase) 기반 33개 마이그레이션 적용 완료, **전 테이블 RLS 활성화(`relrowsecurity = true`)**.
  - 개인 데이터 소유권 경계(`user_id` + 타인/미존재 동일 `404 NOT_FOUND`), 탈퇴 시 `WITHDRAWAL_STEPS` 순차 철회/정리(`DELETE /api/v1/me`), `posts.reading_log_id`·`reading_logs.loan_id` `ON DELETE SET NULL` 보존 규칙 적용.
- **백엔드 (`server/`)**:
  - Python · FastAPI · SQLAlchemy · Alembic. Supabase JWKS 기반 JWT 검증(자체 토큰 미발급), 서울(KST) 날짜 통일(`today_kst`), DB 트랜잭션 밖 외부 I/O 분리, 공개 이미지 프록시(`#76`·`#77`)로 내부 사용자 ID·원본 저장소 주소 은닉.
- **모바일·웹 (`mobile/`)**:
  - React Native · Expo SDK · expo-router · TypeScript · `react-native-web` 단일 코드베이스.
  - 플랫폼 분기는 공통 어댑터(`src/lib/platform.ts`, `src/auth/`)에 격리하고, 비동기 경합 방지(`latest.ts` 요청 순번/취소)·로그아웃 상태 정화(`registerSignOutCleanup`)·99색 `CUBE_PALETTE`와 4종 도서관 룩 토큰(`src/theme/tokens.ts`) 적용.

## 6. 테스트 결과 요약 및 문제 해결

- **최종 자동화 테스트 결과** ([07 테스트 결과서](07_테스트_결과서.md)):
  - **서버**: 격리 PostgreSQL 17 기준 `alembic upgrade head` (`0033`) + `pytest -W error -q` **999건 통과**.
  - **모바일**: `jest --runInBand` **57 suites / 966건 통과**, `npm run typecheck` **0 오류**, Expo 웹·Android·iOS export 통과.
  - **운영·플랫폼 확인**: 운영 웹(Edge Playwright 390×844) C-96 v2 지도 모드·C-97 작성자 공개 프로필 비로그인 동선 콘솔 오류 0, Android Release APK 에뮬레이터 딥링크·프로필/탭 렌더링·오류 0 확인.
- **주요 해결 사례**:
  - **CORS 배포 덮어쓰기 장애 (`#318`)**: `deploy-web.sh`가 숫자형 웹 URL을 지우던 문제를 수정하고 배포 끝 2주소 `OPTIONS` 200 자동 검증 추가.
  - **실 Kakao 행정구역명 핫픽스 (`#312`)**: 실응답의 `전남광주통합특별시` 정규화 누락으로 인한 503 오류 즉시 해소.
  - **개인정보 보호 공개 이미지 전달 (`#328`, `C-97`)**: 공개 프로필·게시물 응답에서 내부 `user_id`와 원본 저장소 URL을 제거하고 `#76`·`#77` 프록시 경로로 일원화.

## 7. 한계 및 후속 과제

1. **미확인 실기기·로그인 동선**: 자동화 브라우저의 Google OAuth 차단으로 인해 로그인 상태의 웹·Android·iOS 수동 동선 및 iOS 실기기(LiveContainer IPA) 전체 회귀는 후속 수동 확인이 필요하다.
2. **외부 API IP 고정 및 배치 주기**: 정보나루 일일 500건 제한(미등록 IP) 해소를 위해 공개 출시 전 Cloud Run Direct VPC Egress + Cloud NAT 고정 IP 도입 및 `sync-theme-holdings`·`sync-yes24-curated` 정기 스케줄링이 필요하다.
3. **M3 확장 항목**: 카메라 ISBN 스캔(`MOBILE-02`), 다크 모드 테마 구현, 앱스토어/플레이스토어 정식 배포 관문은 개인 후속 개발 범위로 이관한다.
