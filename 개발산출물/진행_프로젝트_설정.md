- [Capacitor iOS](https://capacitorjs.com/docs/ios), [Push](https://capacitorjs.com/docs/apis/push-notifications), [React Native 구성 요소](https://reactnative.dev/docs/intro-react-native-components), [iOS Web Push](https://webkit.org/blog/13878/web-push-for-web-apps-on-ios-and-ipados/): 네이티브/웹 경계를 비교했다. 버전·플러그인 호환/성능·서명은 실기기 미검증이다.

## 4. SET-1 스캐폴딩 명세에 준비할 범위

5. **환경/검증:** 비밀값 없는 예시, 로컬 격리 DB·CI 환경, build/type check/표적 검증 명령·기대 결과·잡을 버그. 화면이 포함되면 배치 약속→spec 실패→구현→통과→4개 폭 검토를 명세한다. 현재 규칙에 언급된 검사기 파일은 저장소에 없으므로 존재한다고 쓰지 않는다.
