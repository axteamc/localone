## 페이지마다 하는 일 (같은 순서)

1. **감사**: 웹 390·1280 스크린샷 + 레시피 표와 다른 점 목록(바탕·머리·카드·제목·표찰·버튼·목록 줄·빈 화면·곡률·700 남은 곳·노랑 채움 버튼(무광 판으로)).
2. **중심 요소 시안**: 바꾸면 화면에서 제일 먼저 보이는 것이 달라지는 요소만 후보 3개(연속값은 기준 + 3단계). 나머지는 레시피대로 `기본값(Claude)`. 시안은 `개발산출물/시안/<페이지>_파사드_시안.html`.
3. **반영**: D가 고른 것을 코드에. 담당 주니어 기능 폴더를 고치면 PR 검토 메모에 남기고 해당 계약의 화면 칸과 어긋나지 않는지 본다(계약 변경이 필요하면 D가 먼저).
4. **웹 검사**: `npx tsc --noEmit`, `npx jest`, `npm run e2e:web`(390·1280), 스크린샷을 시안과 비교.
5. **PR**: 페이지 하나에 PR 하나(`design/page-<이름>`), 파일 10개 넘으면 먼저 묻는다. 머지는 D.
