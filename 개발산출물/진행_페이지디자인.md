### P1 로그인 + 로고

- 결정(2026-11-18 D): 로고 **F 글자형 ㄷ + 한 권**(앱 기본 로고, 다른 후보는 시안에 남겨 바꿀 수 있게), 격자 **1단계**(.30), 관계 **C 아래 창**. 배포용 SVG: [개발산출물/로고/](로고/README.md). 시안 두 개에 채택 표시·명세 반영.
- 추가 요청(2026-11-18 D): 로그인 시안에서 로고 책이 "다 노랑"으로 보임(값은 같고 52에서 피치 책 폭 6px라 묻힘 → 로고 64로 키움), 주 버튼 노랑이 "너무 별로", **검정 + 노랑 자제**(그믐과 겹침). 로그인 시안에 "정할 것 3 주 버튼 색(앱 전체)"·"정할 것 4 로고 색" 추가. 주 버튼 색이 정해지면 `actionColors`(`theme/index.ts`)와 S4 결정 기록을 바꾸고, 노랑 버튼을 쓰는 곳(홈 "도서관 찾기" `HomeScreen.tsx` 등)은 페이지별로 고친다.
- 결정(2026-11-18 D, 2차): 주 버튼 **B 무광 판**("흰색과 회색의 밸런스로 다른 버튼들도 조형") → `actionColors` primary·secondary 값을 바꾸면 모든 화면 버튼이 바뀐다(계약 화면 칸과 어긋나는지 PR 때 확인). 로고는 **F 내려놓고 G 슬라이딩 도어**(노랑 유지, 다리 없음, 진한색 없음) — [로고 시안](시안/로고_시안.html) "정할 것 2"에 다듬은 안 G1~G6(손잡이 있음/없음, 책장스러운 안, SNS 책장 참조) 추가, 추천 G3. 로그인 시안의 "로고 색" 칸은 대체됨.
