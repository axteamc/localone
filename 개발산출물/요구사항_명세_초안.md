# 요구사항 명세 초안 — 동네한권 (LOCALONE)

> 2026-11-10 / 사용자 검토 전. 기획 자료 v2 및 사용자 지정 스택을 반영한 **제품 계약 제안**이다. 현재 구현·API·DB 계약은 없으며 물리 스키마·경로·HTTP 상태·함수 시그니처를 확정하는 구현 명세가 아니다.
> 순서와 대기는 [상용 서비스 계획](../계획/상용_서비스_계획.md), D2와 재개는 [프로젝트 설정 진행](진행_프로젝트_설정.md)에 둔다.

## 1. 핵심 경험과 범위

동네 도서관/도서를 탐색하고, 본인이 확인한 대출을 기록해 반납을 관리한다. 개인 서재에 남긴 감상은 선택한 경우에만 도서관 광장에 공개한다. 공개 카드의 도서에서 주변 소장·대출 가능 조회로 돌아온다.

| 구분 | 제품 동작 제안 |
| --- | --- |
| 홈 | 상단 지도 + 하단 컨텍스트 바텀 시트. 도서관 핀 선택 시 같은 화면에서 제목/컨텍스트 전환. 전체 동네로 돌아갈 수 있음 |
| 도서관 선택 | 도서관 광장 / 내 발자취 두 탭. 개인 데이터는 로그인 필요. 공개 피드 출시 전에는 제공 상태를 명시하고 빈 가짜 피드를 만들지 않음 |
| 탐색 | 도서 검색, 도서관 위치·거리, 선택한 ISBN의 소장/대출 가능 조회, 빌릴 예정 저장. 지도 전체의 무조건적인 '대출 가능' 배지 금지 |
| 반납 비서 | 대출일·예정일 사용자 확인, 기한 수정·반납 처리, D-3/D-1/당일 알림함과 선택한 외부 푸시 |
| 개인 서재 | 도서관별 발자취 및 전체 독서 기록·필터·기초 통계. 대출 기록과 감상 기록은 별개이며 연결 가능 |
| 지역 SNS | 2열 메이슨리 지향의 독서 카드, 감상 상세, 주변 도서관 조회 연결. 구매 링크와 배경/서체 확장은 사용 조건 확인 후 제공 |
| 모바일 보조 | ISBN 스캔은 도서 식별 보조. 회원증 제시는 호환 검증 전 제공을 약속하지 않음 |

미색 `#F9F8F6`/`#F4F3EF`, 먹색 `#1C1C1E`, 세이지 또는 웜 그레이 포인트 1종은 디자인 후보이다. 종이 질감·서가 그래픽·줌인 연출은 필수 기능이 아니다. 와이어프레임 → 디자인 시안 검토에서 홈 비율·좁은 폭의 카드 열 수·토큰·서체를 확정한다. 색상 대비·키보드 접근·시트 포커스·텍스트 확대를 함께 검수한다.

## 2. 역할과 권한

| 역할 | 허용 | 제한 |
| --- | --- | --- |
| 방문자 | 공개 도서관·도서·공개 카드 조회 | 개인 예정/대출/서재/회원증/알림 접근·쓰기 불가 |
| 로그인 사용자 | 본인 예정·대출·기록 관리, 본인 카드 공개·철회, 신고 | 타인 비공개 기록·알림·기기 토큰·회원증 접근 불가. 도서관 선택은 권한 증명이 아님 |
| 운영자 | 신고 대상 공개 게시물 검토·숨김, 처리 사유 기록 | 일반 운영 역할로 개인 대출·위치·회원증을 열람하지 않음. 별도 지원 접근은 추가 명세·승인 필요 |
| 서버 작업자 | 기한 도래 알림 생성·전송, 허용된 공공 데이터 갱신 | 로그인 사용자를 임의 대체하지 않음. 수신자 소유권·동의 재확인, 최소 권한 적용 |

도서관 회원증을 보여준 사실은 동네한권 로그인·도서관 공식 인증·실제 대출의 증거로 사용하지 않는다. 공개 광장은 도서관을 선택해 참여하는 공간이며 실제 대출 인증 배지를 발급하지 않는다.

## 3. 논리 데이터와 소유권

아래는 요구 수준의 필드이며 SQL/DTO 이름·타입은 후속 명세에서 확정한다. 필수/선택 및 공개 경계를 생략하지 않는다.

| 데이터 | 필수 정보 | 선택 정보 | 소유·노출·검증 |
| --- | --- | --- | --- |
| 계정/프로필 | 불변 사용자 식별자, 계정 상태 | 공개 표시명 | 인증 주체에서 사용자 확정. 이메일·인증 수단은 공개 프로필에서 제외 |
| 도서관 | 제공자 도서관 식별자, 이름, 출처 | 주소, 좌표, 이용 안내, 갱신 시각 | 공공 데이터. 좌표 없으면 거리 계산 불가 표시 |
| 도서 | 내부 식별자, 제목, 출처 | ISBN, 저자, 표지 URL | 스캔/외부 도서 연결은 유효 ISBN 필요. ISBN 없는 수동 기록과 구분 |
| 소장/대출 관측 | 도서관·도서 식별자, 소장 상태, 대출 가능 상태, 조회 시각, 출처 | 제공자 기준 시각 | `가능/불가/알 수 없음`, 소장 `있음/없음/알 수 없음` 구별. 개인 데이터와 분리 |
| 빌릴 예정 | 소유자, 도서, 도서관, 생성 시각, 상태 | 메모 | 본인 전용. 상태 `예정/해제/대출확정 연결`. 도서관 예약과 다름 |
| 개인 대출 | 소유자, 도서, 대출일, 반납 예정일, 상태, 등록 출처 | 도서관, 연결 예정 ID, 실제 반납일 | `대출중/반납완료`. 연체는 날짜 파생 상태. 수동/사용자 확인 출처를 공식 내역과 구별 |
| 독서 기록 | 소유자, 도서, 작성 시각, 공개 상태 | 감상, 독서일, 도서관, 대출 연결 | 기본 비공개. 도서관 없는 기록은 전체 서재에만 분류 |
| 공개 카드 | 작성자 공개 식별자, 도서, 게시 시각, 공개용 내용, 게시 상태, 도서관 | 공개 허용 이미지·인용문 | `공개/철회/운영숨김`. 원본 개인 대출·기록 전체를 응답에 포함하지 않음 |
| 알림/구독 | 소유자, 알림 종류, 관련 대출, 예정일 버전, 수신 예정 시점, 읽음 상태 | 기기 구독·토큰, 전송 결과 | 본인 전용. 읽음과 전송 성공은 별개. 잠금 화면의 도서명은 기본 비노출 제안 |
| 회원증(후보) | 소유자, 도서관/체계, 사용자 입력 번호 | 표시명 | 저장 위치·암호화·보관 기간 미확정. 결정 전 서버 수집/로그 기록 금지 |
| 신고 | 신고자, 공개 카드, 사유, 처리 상태 | 운영 처리 사유 | 신고자 정보 비공개. 운영자만 처리, 중복 제출 정책은 상세 명세에서 고정 |

- 사용자 ID는 요청 본문을 신뢰하지 않고 인증 주체에서 얻는다. 조회·수정·삭제·다운로드·기기 구독 모두 소유자를 확인한다. A의 식별자로 B의 데이터를 찾는 fallback을 금지한다.
- FastAPI 경유 접근을 추천한다. SQLAlchemy의 소유자 조건과 DB 권한을 별도로 설계한다. Supabase 사용만으로 RLS가 적용된다고 가정하지 않는다. 브라우저에 DB 관리자/서비스 비밀키를 전달하지 않는다.
- 탈퇴 시 개인 대출·예정·기록·기기 구독 삭제, 공개 카드 철회, 대기 알림 취소를 제안한다. 백업 잔존 기간·신고 증거 보관 기간·삭제 완료 기한은 운영 정책 승인 전 미확정이며 출시 관문이다.
- 정확한 위치·집 주소는 기본 영구 저장하지 않는다. 위치는 사용자 동의 후 거리 계산에만 사용하고 EXIF 위치는 공개 이미지에서 제거한다. 거부 시 지역 선택으로 탐색한다.

## 4. 데이터 흐름과 경계

1. React → FastAPI → 도서관/서지/지도 제공자. 공공 정보는 출처·관측 시각과 캐시 상태를 함께 표시한다. 제공자 비밀키는 서버 설정에 둔다. 지도 클라이언트용 키는 허용 도메인·앱 제한을 적용한다.
2. 인증 사용자 → 빌릴 예정 → 직접 대출 확인 → 개인 대출 저장 → 기한 기반 알림함 → 동의한 채널 전송 → 사용자의 반납 처리. 공공 API는 개인 대출 원장이 아니다.
3. 선택적 상태 변화 관측 → 확인 제안만 생성 → 사용자가 도서관·책·대출일·예정일 검토 → 확정 시 대출 저장. Y→N은 다른 이용자의 대출이나 자료 변경일 수 있으며 바코드 열기만으로 확정하지 않는다.
4. 개인 기록 → 명시적 공개 선택 → 공개용 필드만 카드화 → 도서관 광장 → 도서 상세/대출 가능 조회. 철회·운영 숨김 직후 피드·상세 접근을 막고 공개 캐시를 무효화한다.
5. 외부 이미지 업로드는 DB 트랜잭션 밖에서 처리한다. DB 확정 실패 시 정리, 커밋 이후 취소 시 참조 파일 보존을 구별한다. 공공 API 대기는 DB 트랜잭션 밖에서 수행한다.
6. 도서관/사용자 전환 시 이전 요청 취소와 응답 세대 검사를 적용한다. 사용자 A 로그아웃 후 B 로그인에서 A의 캐시·진행 요청·알림 토큰 연결이 남지 않아야 한다.
7. 알림 스케줄은 서버에서 수행하는 안을 추천한다. 앱 종료 상태의 주기적 폴링을 전제하지 않는다. 중복 실행은 사용자·대출·예정일 버전·알림 차수로 중복 생성/발송을 억제하고, 전송 직전 반납·삭제·동의 철회를 재확인한다.

## 5. 핵심 수용 기준(승인 후 검증할 기준, 실행 결과 아님)

| AC | 준비/행동 | 기대 결과 |
| --- | --- | --- |
| AC-AUTH | A 로그인 → 로그아웃 → B 로그인 | A의 개인 화면·캐시·기기 구독이 B에게 보이지 않음. 만료/철회 세션은 쓰기 거부 |
| AC-ISOLATION | A 토큰으로 B의 예정·대출·기록·알림·회원증 ID 조회/변경/삭제 | 모든 접근 거부, B 데이터 변화 없음. 공개 카드만 공개 필드로 조회 가능 |
| AC-LIB | 도서 선택 후 도서관 핀 선택, 이후 전체 동네 복귀 | 페이지 전환 없이 컨텍스트 변경. 선택 도서+도서관 조합의 상태·출처·조회 시각 표시 |
| AC-RACE | 도서관 X 조회 지연 중 Y 선택, X 응답 늦게 도착 | Y 화면이 X 결과로 덮이지 않음. 실패 응답도 현재 컨텍스트만 변경 |
| AC-UNKNOWN | 제공자 시간 초과/오류/미지원 도서관 | 불가/미소장으로 단정하지 않고 알 수 없음·재시도 제공. 오래된 캐시는 시각과 함께 구별 |
| AC-PLAN | 같은 도서·도서관 빌릴 예정 반복 저장·해제 | 활성 예정 중복 억제, 해제 후 관측 제안 중단. 실제 예약 성공 문구 없음 |
| AC-LOAN | 도서·대출일·예정일 입력 후 저장 버튼 반복 클릭 | 본인 대출 한 건만 저장. 예정일은 대출일 이전 불가, 수정 가능한 오류 안내 |
| AC-DATE | 기본 +14일 후보를 검토하거나 실제 반납일을 입력 | +14일은 추정임을 명시하고 확정 전에 수정 가능. 도서관별 기간을 공식 기한으로 단정하지 않음 |
| AC-HINT | Y→N 또는 회원증 열기 관측 후 제안 거절 | 대출·반납 일정 생성 없음. 승인 시에도 날짜·도서관을 검토해야 등록 |
| AC-SCAN | ISBN 인식 성공/오인식/카메라 거부 | 도서 후보 검토 후 등록, 실패·거부 시 ISBN 직접 입력. 회원 번호/ISBN 스캔을 혼동하지 않음 |
| AC-REMIND | 기한 D-3/D-1/당일, 작업 중복/재시작 | 기본 Asia/Seoul 날짜 기준 각 차수 알림함 한 건. 늦게 등록한 과거 차수 몰아 발송 금지, 당일 차수만 처리 |
| AC-RETURN | 반납 완료 또는 기한 변경 후 이전 알림 작업 실행 | 이전 버전 미전송 알림 취소, 새 기한으로 재계산. 이미 전달된 푸시 회수 보장 없음 |
| AC-PUSH | 권한 거부·구독 만료·오프라인·전송 실패 | 알림함은 조회 가능. 푸시 도착을 보장하지 않고 재시도 제한·구독 정리. 서비스 워커/서버 전송 없는 인앱 토스트를 백그라운드 푸시로 표시하지 않음 |
| AC-READ | 도서관 있는 기록/없는 기록 작성 후 전체·도서관 필터 | 본인 기록만 표시. 도서관 없는 기록을 임의 도서관으로 보정하지 않음. 빈 통계는 0으로 표현 |
| AC-PUBLISH | 비공개 기록 작성 → 카드 공개 → 철회 | 작성만으로 공개되지 않음. 공개·철회 범위 확인, 철회 후 직접 URL/피드에서 읽기 차단 |
| AC-MOD | 신고 후 운영자 숨김 | 공개 노출 중단, 처리 사유·행위 감사 기록. 타인 비공개 데이터가 운영 화면에 포함되지 않음 |
| AC-UI | 로딩/빈/성공/실패/비로그인, 390·768·1150·1280 폭 | 시트·탭·카드 조작과 포커스 복귀 가능, 가로 넘침·가림 없음. 열 수/정렬 약속은 화면 명세에서 고정 |
| AC-DELETE | 계정 탈퇴 및 전송 대기 작업 재실행 | 개인 접근 차단·공개 철회·구독 해제·알림 취소. 승인된 보관/백업 정책에 따라 삭제 결과 추적 |

기한 알림의 발송 시각·사용자 시간대 변경 규칙·재시도 횟수·텍스트 길이·페이지 크기·미디어 용량·중복 대출 기준은 해당 구현 직전 명세에서 수치로 고정해야 하며 임의 구현할 수 없다.

## 6. 예외 및 오류 계약 준비

아래는 제품 오류 분류다. 공개 API 경로·요청/응답 전 필드·HTTP 상태 코드·오류 코드 문자열은 D2 이후 해당 Step 명세에서 조건별로 하나씩 확정한다. 현재 `/api/v1` 또는 레거시 계약이 존재한다고 가정하지 않는다.

| 조건 | 사용자에게 보일 결과/서버 방어 |
| --- | --- |
| 미인증·세션 만료 | 로그인 필요, 입력 보존 범위를 정하고 저장 성공으로 표시하지 않음 |
| 타인 소유/존재하지 않는 개인 리소스 | 존재 여부 누설 없이 동일한 거부 정책. 데이터 변경 없음 |
| 잘못된 ISBN·날짜 역전·필수값 누락 | 해당 필드 오류, 저장 없음. 과거 대출·연체 기록 입력은 허용 |
| 중복 클릭·네트워크 재시도·동시 수정 | 중복 생성 방지, 충돌 안내 후 최신 상태 재조회. 덮어쓰기 정책 상세화 |
| 제공자 제한·시간 초과·포맷 변경 | 알 수 없음/지연 안내, 호출 상한·백오프 적용. 예외를 빈 성공 응답으로 삼키지 않음 |
| 지도 실패·위치 거부 | 지역/도서관 목록으로 같은 탐색 여정 제공, 타인 위치로 fallback 금지 |
| 공개 철회·운영 숨김·삭제 카드 링크 | 더 이상 공개되지 않음 안내, 비공개 원문 반환 금지 |
| 이미지/스캔 실패 | 업로드 취소·재시도/수동 입력, 미완료 파일 정리. 사진만으로 대출 확정 금지 |
| 회원증 미지원·잘못된 번호 | 공식 인증/대출 완료로 표시하지 않음. 도서관 공식 회원증 안내 |
| 취소·앱 종료·외부 푸시 장애 | 취소 전파·트랜잭션 롤백, 알림함 영속 상태 보존, 외부 전송 제한 재시도 |

## 7. 초안에서 수정한 가정과 외부 근거

공식 문서 확인일: 2026-11-10. 제공자의 현재 운영 조건은 키 발급/실측 전 미검증이다.

- **실시간성:** [정보나루 공지](https://data4library.kr/noticeV?cn=129)는 `loanAvailable`을 조회 전날 상태로 설명한다. [현행 활용 안내](https://data4library.kr/apiUtilization)를 함께 확인했지만 실제 갱신 SLA·쿼터는 미확정이다. '실시간', '방금 반납', 개인 대출 자동 감지를 제품 보장으로 쓰지 않는다.
- **웹 푸시:** [WebKit](https://webkit.org/blog/13878/web-push-for-web-apps-on-ios-and-ipados/)은 iOS/iPadOS 16.4부터 홈 화면 웹 앱의 Web Push와 사용자 동작에 따른 권한 요청을 설명한다. Notifications API 호출만으로 종료 상태 발송이 구현되지는 않는다. 지원 OS/브라우저·설치 상태는 출시 전 실기기로 확인한다.
- **네이티브 푸시:** [Capacitor Push](https://capacitorjs.com/docs/apis/push-notifications)는 iOS 설정이 필요하며 해당 플러그인은 iOS silent push를 지원하지 않는다. 네이티브 앱 선택이 주기적 백그라운드 API 관측을 보장하지 않는다.
- **회원증:** Code 128 표시와 책이음 공식 발급·단말 호환은 별개다. 제휴·인증 가능 여부를 확인하지 않았으며 공식 통합 회원증으로 광고하지 않는다.
- **외부 콘텐츠:** 알라딘·카카오·지도·Yes24는 후보 제공자/연결 대상이다. 사용 조건·커버리지·표지/인용문/폰트 사용 권한·비용은 미확인이다. 외부 구매 링크는 결제 구현을 뜻하지 않는다.
