# 모호점 해소 기록

> 상태: **작성 중**(2026-11-11 시작). 담당: D. 기획·명세·구현 중 나온 **프로젝트 차원의 모호점·미결정 사항**을 질문 → 선택지 → 결정 → 반영 문서까지 남긴다.

- 상태: `해소` / `대기`(결정 필요) / `보류`(진입 조건 대기). 번호는 이어서 붙이고 지우지 않는다. 결정이 뒤집히면 새 행을 만들고 이전 행에 `→ Q-n`을 적는다.
