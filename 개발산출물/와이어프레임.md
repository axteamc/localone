# 와이어프레임

> 상태: **골격 — 미작성**. 담당: D(전체 구성), 기능별 화면은 담당 팀원과 명세서 `시안`에서 확정. 선행: 기능 명세서 승인 전에는 **초안 구성도만** 그린다. 갱신 시점: 명세서의 시안이 정해질 때, 디자인 토큰 결정(Q-29) 후 시안으로 승격.
> 입력: [02 §1 핵심 경험](02_요구사항_정의서.md), [유저 플로우](유저_플로우.md), 기능별 `specs/<기능>/시안.html`.
> 2026-11-11 개정: 도서관 방문·광장 중심으로 화면 목록 재구성.

## 최신 화면·검수 결정(C-46)

[묶음 상세 결정](명세/SNS_검색_프로필_상세결정.md)을 우선한다. 내 정보는 **내 게시물 / 좋아요 / 북마크** 3탭으로 시작 화면은 내 게시물이다. 프로필 상단은 사진·닉네임·한 줄 소개·편집·팔로우 버튼이며 팔로워 수/목록은 표시하지 않는다.

일반 피드는 제목 없는 이미지 중심·작성자만 작게, 좋아요 수는 상세에 표시한다. 모임 식별 정보는 유지한다. 방문 기록 북마크·최근 저장순·재저장/재공개 표현(D3~D6) 및 글쓰기 버튼(F3)은 **시안을 실제로 보여 주고 사용자 검토를 받는 필수 관문**이다. 문서 채택만으로 시안 검토 완료로 처리하지 않는다. 글쓰기 위치·형태는 세부 명세에서 정한다. 검색 진입은 키보드와 추천/최근 도서 동시 표시, 모임 안내는 앱 안 알림 목록도 제공한다. 아직 새 시안은 작성·검토하지 않았다.

## 이전 화면 결정(C-26~43)

[SNS·검색·내 정보 개정](명세/SNS_검색_프로필_개정.md)을 우선 적용한다. 글쓰기는 하단 바에서 빼고 SNS의 +/연필 버튼으로 이동한다. 피드는 별도 제목 없는 형태가 기본이며 북마크 필터를 추가한다. 내 정보는 인스타그램식 프로필과 좌측 좋아요·우측 북마크 수집 탭을 참조한다. 두 수집 목록은 본인에게만 제공한다(C-31). 내 정보의 좋아요는 최근 좋아요한 순서, 북마크는 최근 저장한 순서로 표시한다(C-34). 삭제·공개 철회·운영 숨김된 피드는 SNS 북마크 필터와 내 정보의 두 모음에서 자리표시 없이 숨긴다(C-32). 검색창 선택 시 추천 도서·최근 검색 도서를 보여 준다. 검색 진입 추천 영역은 도서관 안에서는 해당 도서관 테마, 밖에서는 공통 테마를 사용한다(C-37). 해당 범위에 설정된 테마가 있으면 테마 도서, 없으면 공공 데이터의 인기 도서를 표시한다(C-36). 최근 검색 도서는 검색 결과에서 눌러 상세를 본 책을 표지·제목으로 표시하며 선택 시 책 상세를 다시 연다(C-35). 북마크는 이웃의 기록·방명록·모임 모두에 제공하며(C-29), 목록의 길게 누르기·점 세 개 메뉴 안과 상세의 별도 버튼에 둔다(C-28). 저장한 피드는 두 곳에서 ‘북마크 해제’ 상태로 표시하고 확인창 없이 해제한다(C-33). SNS 북마크 필터는 현재 도서관만 보여 주며 내 정보 북마크 탭은 모든 도서관의 저장 피드를 모아 보여 준다(C-30). 상세는 새 첨부처럼 넓은 화면의 왼쪽 큰 이미지·오른쪽 반응/작성자/본문/댓글 구성을 목표로 하며 모바일 배치는 시안에서 확인한다. 하단 바는 **홈 / 독서 기록 / 대출·반납 / 내 정보** 순서의 4개로 확정했다. 발자취는 독서 기록의 도서관별 보기로 통합하며 별도 탭·사이드바 메뉴를 두지 않는다(Q-44 해소). 아래 구성과 기존 HTML은 이전 시안이며 새 화면 그림은 아직 작성하지 않았다.

## 앱 전체 구성 (이전 초안 — C-26 재설계 대상)

- **하단 바:** 홈(지도·방문) / 독서 기록(전체) / 게시물 쓰기 / 내 대출·반납 / 내 정보 — 항목 수와 이름은 시안에서 확정한다. 내 발자취는 방문 페이지 밖의 하단 탭 또는 사이드바이며 어느 쪽인지, 독서 기록 탭과 따로 둘지는 미정(Q-44)이라 두 안을 모두 그려 비교한다.
- **홈:** 위쪽 데포르메 지도, 아래쪽 섹션(지역 인기글·내 최근 독서 기록·추천 서적). 핀을 누르면 같은 화면에서 도서관 방문 화면으로 전환.
- **도서관 방문 페이지(2026-11-11 개정, C-13):** 지도에서 핀을 누르면 페이지가 바뀐다. 위쪽은 핀터레스트형 피드(게시물·방명록·모임·"다녀왔어요" 카드가 같은 모양으로 섞임), 아래쪽은 고정된 책장(오늘의 서가: 넘겨 보는 페이지: 요즘 사람들이 읽은 책 / 인기 도서 / 운영자 테마 추천, 순서는 시안에서 정함). 피드와 책장 사이는 얇은 블러 띠 + 그라데이션(C)으로 나누고, 불가능한 기기에서는 그라데이션 페이드(B)만 쓴다. 그날 첫 입장 때 피드 섹션 우측 상단에 "다녀왔어요" 스탬프가 뜨고 눌러서 공개 여부를 정한다. 광장/내 발자취 두 탭은 없앴다.
- **두 가지 기록 화면:** 하단 바의 독서 기록(전체·필터·통계, 원장 느낌)과 도서관 안의 내 독서 기록(위치 미정)은 다른 구성으로 그린다.
- **디자인 방향:** 모던, 콘크리트·아치 공간 분위기의 배경. Arne Vodder 가구의 곡률·배색·형태만 참조하고 나무색은 쓰지 않는다(02 §1).
