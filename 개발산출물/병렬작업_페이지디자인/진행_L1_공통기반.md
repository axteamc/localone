## 진행 기록

- 2026-11-18 (win) 선행 PR #186 머지 확인. 메인 폴더에 다른 세션(L2) 작업이 열려 있어 worktree `../libproject-theme`(브랜치 `design/theme-base`, main 8b6f151)에서 작업, 웹은 Metro 8083.
- 받침 방법 확인(공식 문서): RN `boxShadow`는 "웹 스타일 prop의 규격 준수 구현"(view-style-props), 0.76부터 New Architecture 전용, Android 9+(바깥 그림자). 웹 규격상 box-shadow는 레이아웃 크기에 들어가지 않는다. react-native-web 0.21은 문자열을 CSS로 그대로 넘긴다(`StyleSheet/preprocess.js`). → `borderBottomWidth`(높이·글자 위치가 밀림)·바깥 View(스타일 객체 하나로 못 줌) 대신 **`boxShadow: "0 2px 0 0 reliefBottomMid"`(번짐 0)**. 테두리는 사방 1px 그대로라 버튼 높이·글자 위치는 이전과 같다(받침은 그림자라 높이에 안 들어감).
- `theme/index.ts`: `ledge(color, depth=2)`, `actionColors` 값 교체(주 `panelLit`+줄눈+받침/글자 `inkStrong`, 보조 `panelFrosted`+줄눈/글자 `text`) + `primaryPressed`·`secondaryPressed` 추가(기존 키 유지), `cardSurface(theme, { onPanel })` 추가. 시험 2개 추가(값, 노랑 미사용, 4룩 대비 4.5 이상, 카드 modern 6).
- 누름 상태는 화면이 `({ pressed }) => [..., pressed && ACT.primaryPressed]`로 붙여야 보인다 → 지금 화면들은 누름 변화 없음(L4).
- jest 첫 실행에서 `home-news` 등 4개가 시간 초과로 실패, 다시 두 번은 모두 통과(캐시 없는 첫 실행 탓으로 봄). `expo start`가 `tsconfig.json` include를 고쳐서 되돌림(커밋 안 함).
