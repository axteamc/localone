# 갭 분석 보고서

> 상태: **골격 — 미작성**. 담당: D. 선행: 마일스톤 검수 직전, 추적표와 07 테스트 결과서. 갱신·작성 시점: 마일스톤(M1·M2·M3) 종료 때마다.
> 입력: [02 요구사항](02_요구사항_정의서.md), [추적표](추적표.md), [07 테스트 결과서](07_테스트_결과서.md)

## 작성할 내용

1. 요구사항 ID별 달성도: 02의 요구사항·AC와 실제 구현·테스트 결과를 대조
2. 갭 목록: 미구현·부분 구현·명세와 달라진 점(원인, 영향, 조치, 대기 목록 연결)
3. 추적 누락: 추적표에서 상태는 구현 이상인데 명세서·계약서·테스트가 `-`인 행
4. 플랫폼별 갭: 웹·Android·iOS 중 확인하지 못한 것
5. 출시 판단 근거: 알려진 결함([버그 리포트](버그_리포트.md))과 갭이 마일스톤 관문(계획 §3)을 막는지
