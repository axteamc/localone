# 02. 요구사항 정의서 — 동네한권 (localone)

> 상태: **전면 개정(2026-11-25)** — M1·M2 전체 기능, YES24 연동(Y-6), 실기기 개선(C-87~91, P8) 구현 및 운영 배포 기준.
> 이 문서는 제품 동작·권한·데이터 경계·수용 기준(AC)의 기준 문서다. 원문 추적은 [00_기획_원본.md](00_기획_원본.md), 물리 스키마는 [05_ERD_및_DB설계서.md](05_ERD_및_DB설계서.md), 엔드포인트는 [06_기능_API_정의서.md](06_기능_API_정의서.md), 세부 계약은 `../team/contracts/`를 따른다.

## 주요 확정 정책 요약

1. **도서관 방문 중심 + 반납 비서 보조(C-11)**: 공공 API 상태 변화로 개인 대출을 자동 추정하지 않고, "빌렸어요" 클릭만으로 서울(KST) 날짜 기준 D-day와 기기 알림을 관리한다.
2. **홈 큐브 파사드 전환(C-65 · C-68 · H6)**: 홈은 지도 대신 현재 위치(`+` 기점) 기준 방위 블록 화면(20색 `CUBE_PALETTE`, 2단 이름 표기, TODAY 운영시간)을 쓰며, 위치 미수신 시 지역 코드만 임시 기억한다.
3. **독립 북마크·3탭 내 정보·모임·알림함(C-46 · C-47)**: 내 정보는 `내 게시물 / 좋아요 / 북마크` 3탭(팔로우 버튼 허용, 수/목록 미표시) + `도서관 방문 모음`으로 구성한다. 모임은 회차별 약속·미정 일정 허용·즉시 참가·종료 후기·다음 모임·출석 확인·불참 패널티(누적 1회 3일·2회 7일·3회 30일·4회 불가)를 지원하며, 앱 내 알림함(`/inbox`)을 제공한다(서버 푸시는 미사용).
4. **외부 API 확정(C-66 · Q-48 · Y-6)**: 도서 서지·표지는 **카카오 책 검색 API**, 도서관·소장·인기는 **도서관 정보나루 API**(전국 1,624곳, `어제 기준` 표기 + 보정된 공식 홈페이지 `실시간 확인`), 큐레이션·구매는 **YES24 Open API**를 사용한다.
5. **실기기 개선(C-87~91 · P8)**: 게시물 수정(본문·이미지 위 글자), 설정 화면(`/settings`, 계정·반경/기본 도서관·알림 토글·탈퇴), SNS 도서 카드 구매 버튼 제거(도서 상세에서 YES24 연결), 도서관 미지정 빌릴 예정·일괄 소장 조회(`#70`)를 반영했다.

## 1. 핵심 경험과 범위

**동네한권은 지역 도서관을 앱에서 "방문"하는 느낌으로 쓰는 서비스다.** 도서관 단위로 작은 독서 커뮤니티가 모이고, 책을 빌리는 일은 그 곁에서 편리하게 돕는다. 대출·반납 관리는 보조이고, 중심 가치는 도서관을 고르고 → 그곳의 이웃 독서 기록·게시물을 만나고 → 다음 책을 찾는 순환이다.

| 구분 | 제품 동작 요약 |
| --- | --- |
| **홈** | 현재 위치(`+` 기점) 기준 등각 큐브 파사드(20색 팔레트, 2단 이름 표기, 거리·방위·TODAY 운영시간). 지도는 두지 않는다. 하단 창에 자주 방문하는 도서관 피드·YES24 추천 도서·내 최근 독서 기록 배치 |
| **도서관 방문** | 큐브 블록을 누르면 방문 페이지로 화면 전환(방문 횟수별 멘트 카드 + 도서관 고유 룩 4종). 위쪽 2열 광장 피드(게시물·방명록·모임·방문 스탬프 혼합) + 블러 띠 + 아래쪽 책장(오늘의 서가) |
| **광장** | 핀터레스트형 2열 메이슨리. 일반 게시물 카드는 이미지·문장만 노출. 상세에서 대여 경로(소장 조회) 우선, 도서 상세에서 YES24 구매 연결, 같은 책 이어 읽기, 공감·북마크·공유 |
| **독서 기록** | 하단 `독서 기록` 탭에서 비공개 기록 전체·도서관별 보기(내 발자취 통합)·통계 제공. 템플릿 카드로 광장에 공유 가능 |
| **책 확인** | 카카오 책 검색 + 정보나루 기반 내 주변(3km/5km)·도시 전체 소장/대출 가능 조회(`어제 기준` + 도서관 홈페이지 `실시간 확인`), 지정/미지정 빌릴 예정 및 다권 일괄 조회 |
| **반납 비서(보조)** | "빌렸어요" → 서버 KST 기준 D-day 타이머 + 기기 로컬 알림(D-3·D-1·당일) → "반납했어요". 공공 API 상태 변화로 대출을 추정하지 않음 |
| **작은 모임 & 알림함** | 회차별 약속·미정 일정·댓글 협의·즉시 참가·종료 후기·다음 회차 생성·출석 확인·기간제 제한. 앱 내 알림함(`/inbox`) 연동 |
| **내 정보** | 프로필 편집, `내 게시물 / 좋아요 / 북마크` 3탭, 팔로우 버튼, 도서관 방문 모음, 설정(`/settings`) |

## 4. 데이터 흐름과 경계

1. **공공·외부 API 분리**: 앱 → FastAPI(`ProviderEngine`) → 정보나루·카카오·YES24. 모든 외부 I/O는 DB 트랜잭션 밖에서 수행하며, 비밀키는 서버 Secret Manager에만 둔다.
2. **단순 반납 비서**: 빌릴 예정 → "빌렸어요"(서울 날짜 기록) → 앱 기기 로컬 알림 예약(D-3·D-1·당일) → "반납했어요"(예약 해제). 공공 API로 대출·반납을 추정하지 않는다.
3. **광장·탐색 연결**: 게시물 작성(EXIF 제거) → 올리기 → 광장 노출 → 상세에서 소장 조회 우선·같은 책 이어 읽기, 도서 상세에서 YES24 구매 연결. 철회·숨김 직후 피드·상세·북마크에서 차단한다.
4. **비공개 기록 → 광장 공유**: 비공개 독서 기록 → 템플릿 선택 → 새 게시물로 공개(원본 기록은 비공개 유지).
5. **요청 경합 및 로그아웃 정화**: 도서관·도서 전환 시 이전 요청 취소 및 응답 세대 검사(`reqSeq`/`AbortController`)를 적용하고, 로그아웃 시 캐시·진행 요청·기기 예약 알림을 모두 지운다.

## 5. 핵심 수용 기준 (AC)

| AC | 검증 조건 | 기대 결과 |
| --- | --- | --- |
| **AC-AUTH** | A 로그인·알림 예약 → 로그아웃 → B 로그인 | A의 화면·캐시·예약 알림이 B에게 남지 않음. 만료/철회 세션 쓰기 거부 |
| **AC-ISOLATION** | A 토큰으로 B의 개인 데이터 조회/변경/삭제 | 모두 동일 `404` 거부, DB 행 변화 없음 |
| **AC-LIB** | 검색 → 상세 → 주변/도시 전체 소장 조회 → 실시간 확인 | `어제 기준`·출처·시각 표기, 단정 문구 없음. 도서관 홈페이지 외부 이동. 3km/5km 미발견 시 도시 전체 재검색 |
| **AC-RACE** | 도서관 X 조회 지연 중 Y 선택, X 늦게 도착 | Y 화면이 X 결과로 덮이지 않음 |
| **AC-UNKNOWN** | 제공자 오류/시간 초과/미지원 | 불가/미소장으로 단정하지 않고 `알 수 없음`·재시도 안내 |
| **AC-PLAN** | 지정/미지정 빌릴 예정 중복 저장, 다권 일괄 조회 | 활성 중복 억제, 실제 예약 문구 없음. 일괄 조회 시 미확인 도서관 제외 |
| **AC-LOAN / DATE / REMIND / RETURN / NOTIFY** | "빌렸어요" 연타, 기한 수정, 반납, 권한 거부 | 단건 저장, 서울 날짜 기준 +14일(추정), D-3·D-1·당일 예약/수정 시 재예약/반납 시 해제, 권한 거부 시에도 D-day 표시 |
| **AC-READ** | 도서관 유무별 기록 작성·필터 | 본인 기록만 표시, 도서관 없는 기록 임의 보정 없음, 빈 통계 0 |
| **AC-PUBLISH / COVER / FEED** | 작성·수정·철회, 표지 대체, 2열 피드·이어 읽기·공감·북마크 | 철회·숨김 즉시 차단, EXIF 제거, 대여 경로 우선, 빈 광장 가짜 데이터 없음 |
| **AC-VISIT / STAMP** | 큐브 선택 → 방문 페이지 전환, 위치 거부, 스탬프 | 페이지 전환 + 피드/책장 표시, 위치 거부 시 임시 지역 시작 + 위치 허용 버튼, 스탬프 하루 1회·본인만 조회 |
| **AC-CLUB / CLUB-MOD / MOD** | 미정 모임·즉시 참가·후기·다음 모임·댓글 제한·신고 숨김 | 승인 없는 즉시 참가, 관리자 승인 후 제한, 숨김 즉시 비노출 및 감사 기록 |
| **AC-UI / DELETE** | iOS·Android·Web 화면 상태 및 계정 탈퇴 | 넘침/가림 없음, 탈퇴 시 M1/M2 전체 데이터 순서별 정리 및 기기 알림 해제 |

## 6. 예외 및 오류 원칙

- **미인증·세션 만료**: 로그인 안내, 저장 성공 오표시 금지.
- **타인/미존재 리소스**: 존재 여부 누설 없이 동일 `404` 거부, 데이터 무변경.
- **날짜 역전·잘못된 입력**: 필드 오류 반환, 저장 없음.
- **제공자 한도·시간 초과**: `알 수 없음`/지연 안내, 빈 성공 응답 금지.
- **위치 거부(홈)**: 임시 시작 위치(기억된 지역 코드 또는 기본 위치) + 위치 허용 버튼, 타인 위치 fallback 금지.
- **공개 철회·숨김**: 즉시 목록·상세·북마크 노출 차단.

## 7. 검증된 외부 연동 근거

- **도서관 정보나루 Open API**: 전국 264개 시군구 코드 기준 1,624곳 도서관 동기화·홈페이지 URL 보정 완료. `bookExist`(소장)·`loanItemSrchByLib`(도서관별 인기대출도서)·`loanAvailable`(전날 기준) 운영 검증 완료.
