## 2. 제공자별 상세 정의

### D1. 도서관 정보나루 (data4library.kr)

- **문서 기준**: 정보나루 Open API 매뉴얼 `v20260620` (SHA256 `672AC843...DF2`, [APP-0-P1 결과](결과/APP-0-P1_앱공통기반.md) §2 확인).
- **호출 한도 및 앱 상한**: 제공자 일일 한도 30,000건 → 앱 일일 호출 상한 **70% = 21,000건/일** (`provider_daily_usage` 테이블에 트랜잭션 밖 호출 전 원자 증가로 예약).
- **데이터 기준일(불변 조건)**: `bookExist` 대출 가능 여부는 **전날 기준**(`data_basis_date`)이다. 화면에 "실시간"·"방금 반납" 문구를 쓰지 않고 기준일·출처·조회 시각을 함께 표시한다.
- **오류·지연 처리**: 응답 5초 초과 또는 제공자 오류 시 소장/대출 가능 상태를 `'unknown'`("알 수 없음 + 다시 시도")으로 반환하며 '없음/불가'로 단정하지 않는다. 표지 주소(`bookImageURL`)에 `http://`가 섞여 있으면 서버가 `https://`로 정규화해 내려준다(비영리 화면 표시용, 이미지 복사·재배포 금지).
- **식별자·지역 코드**: 도서관 식별자는 `libCode`, 도서는 13자리 `isbn13`(10자리는 서버에서 13자리로 변환). 지역 코드는 매뉴얼 pp.63~70 기준 **활성 264개 시·군·구 코드** 추출 완료(`mobile/src/lib/regions.ts`, 폐지 코드 `23030`·`37310` 제외, `22520` 대구 군위 포함).
- **미확인(실측 대기)**: 키 발급 후 `libSrch` `pageSize` 최대치 실측(Q-18), 시연용 실시간 확인 주소표 대상 도서관(광주 7곳 안팎 + 서울 3곳 안팎, Q-48) 확정.

### D2. 네이버 책 검색 API

- **역할**: 도서 검색·서지·표지 조회 **1순위**(Q-39). 표지가 없거나 깨지면 대체(서브 출처 Google Books / 국립중앙도서관 API는 미확인).
- **문서 기준 한도·파라미터**: 일 25,000건, `display` 최대 100, `start` 최대 1000, 정렬 `sim`·`date`.
- **응답 필드**: `image`(섬네일 URL), `isbn`, `description`, `pubdate` 등(`Book`의 `description`·`pub_year`는 C-64로 계약 보완).
- **미확인(실측 대기)**: 응답 `isbn`의 10/13자리 혼합 실측, 표지 이미지 복사·저장·상업 이용 약관(Q-41).

### D3. 카카오맵 (지도·위치)

- **구현 방식(Q-12)**: 앱은 `react-native-webview` + 카카오맵 JS SDK, 웹은 JS SDK 직접 사용. REST API 키는 FastAPI 서버에만 둔다.
- **반경·위치 정책**: 내 주변 기본 반경 3km, 설정 5km(직선거리), 결과는 거리순. 위치 거부 시 임시 시작 위치(`11020` 서울특별시 중구 등)와 시·군·구 단위 선택 제공. 사용자의 정확한 위치·집 주소는 영구 저장하지 않는다(05 §6).
- **미확인**: 지도 + 하단 시트 제스처 성능 및 WebView `baseUrl` 도메인 등록(Q-12), 데포르메 구현 방식(Q-30).

### D4. 도서관 휴관일

- **출처(Q-22)**: 정보나루 `libSrch`의 `closed` 필드(자유 문장, 예: `"매월 첫째주, 셋째주 월요일 / 법정공휴일"`).
- **전처리·표시 규칙**: 정기 규칙(요일·몇째 주)과 법정공휴일은 계산해 안내하되 원문 문구를 함께 보존한다. 임시 휴관이나 해석 실패 시 단정하지 않고 원문과 "확인 필요"를 표시한다.

### D5. 예스24 Open API (큐레이션 및 구매 연결 — 2026-11-24 실측 확정, C-81)

- **인증·호출 한도**: HTTP 헤더 `X-Api-Key`(쿼리 파라미터 불가). 기본키 실측 한도 **일 20,000회·초당 10회**(`x-ratelimit-limit-day`/`second` 헤더 확인) → 앱 일일 호출 상한 **70% = 14,000건/일**, 연속 호출 간 최소 간격 `0.2초` (`provider_daily_usage` `'yes24'` 예약). 제휴키 일 100,000회(초당 20회).
- **확정 엔드포인트**:
  - 큐레이션: `GET https://apis.yes24.com/v1/category/bestsellerSteady`(1순위) / `bestseller` (`categoryId=001`, `page=1`, `pageSize=100` 1회 조회 후 `adultYn != "Y"`·`goodsType == "도서"`·아동/수험서/만화 분류 제외 필터 적용해 상위 20권 저장).
  - 단건 구매 직링크: `GET https://apis.yes24.com/v1/goods/itemDetail?searchType=ISBN13&query={isbn13}` (응답 `items[0].isbn13 == 요청 isbn13`·`goodsType ∈ {"도서","만화"}`·`itemStatus ∈ {"판매중","예약판매"}`·`link` 접두 `https://www.yes24.com/` 모두 충족 시 `kind="product"`, 아니면 `kind="search"` 폴백).
- **약관·데이터 정책(Q-41 ② 해소)**: 상업적 이용 사전 승인 없이 허용. 3대 의무 필수 준수 — ① **섹션 단위 출처 표기**(`출처: YES24` / `데이터 제공: YES24`), ② **도서 상세에서 예스24 상품 상세페이지 연결**, ③ **서비스 노출 범위 내 캐싱만 허용**(전체 수집·영구 축적·제3자 재배포 금지, 가격·재고 변동 필드 미저장). 표지는 **`cover`(앞표지) URL만 사용**(`sideCover`·`backCover` 미사용, 이미지 파일 복사 금지).
- **상세 실측·오류 코드**: [YES24 1단계 실측·계약개정안](명세/YES24_1단계_실측_및_계약개정안.md) 참조.

## 3. 전처리·공통 규칙

1. **좌표 누락**: `latitude`·`longitude`가 없는 도서관은 거리 계산 및 지도 핀에서 제외하고 "거리 정보 없음"으로 처리한다.
2. **EXIF 제거**: 사용자가 올리는 게시물 사진은 공개 저장 전에 EXIF 위치 정보를 서버에서 제거한다(NFR-05).
3. **일일 호출 상한**: 외부 제공자 호출은 반드시 DB 트랜잭션 밖에서 수행하며 `ProviderEngine`을 통해서만 호출한다.
