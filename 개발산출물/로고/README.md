# 동네한권 로고 (배포용 원본)

2026-11-18 D 결정: 앱 기본 로고는 [로고 시안](../시안/로고_시안.html)의 **G 슬라이딩 도어**(처음 고른 F 글자형 ㄷ + 한 권에서 바꿈). 결정 기록은 [DESIGN.md](../../DESIGN.md) "결정 기록 — 로고 형태".

| 파일 | 쓰는 곳 |
| --- | --- |
| `동네한권_로고.svg` | 밝은 바탕(백색·유리판) 위 로고, 로그인 상단, 시연 자료 |
| `동네한권_로고_진한바탕.svg` | 진한 바탕(`inkStrong`) 위. ㄷ이 `paper`로 뒤집힌다 |
| `동네한권_앱아이콘_1024.svg` | 앱 아이콘 원본(백색 정사각형, 로고 72%). 모서리는 OS가 깎으니 둥글게 만들지 않는다 |

- **지금 이 폴더의 SVG 3개는 내려놓은 F다.** G 다듬은 안(로고 시안 "정할 것 2", G1~G6)이 정해지면 이 3개를 그 모양으로 바꾼다(다리 없음, 진한색 없음, 손잡이 있음/없음 중 고른 것).
- (F 기준 설명) 형태: 격자 64. ㄷ은 `inkStrong`, 안의 책 `fill1`, 옆 책 `fill2`. 색은 warm 룩 값(`#2E333F`·`#E9C970`·`#EDC9A9`, 진한 바탕은 `#EFF1F1`). 앱 안에서 쓸 때는 값이 아니라 테마 토큰으로 칠한다(룩이 바뀌면 같이 바뀜).
- **바꾸고 싶을 때:** 로고 시안에 다른 후보 6개(A~E, G)가 그대로 있다. 고른 후보의 SVG(`FORMS`의 `svg`)를 이 폴더 파일로 옮기고 DESIGN.md 결정 기록을 고친다.
- 아직 안 함: PNG(1024·48 등) 내보내기, `mobile/assets` 아이콘 교체, 앱에 로고 컴포넌트 넣기.
