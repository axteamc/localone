## 4. D 판단 쟁점 (발행 전에 D가 정할 것)

1. **LOCAL-3 템플릿 표현**: `image_kind='template'`로 이미지 파일 없이 앱이 그린다(캡처 라이브러리 없음). 그리고 `posts.reading_log_id`·`reading_logs.loan_id`의 `ON DELETE SET NULL`은 05 R12 `NO ACTION` 원칙의 예외다.
2. **방문 기록 카드 북마크**(C-46 D3 확정): 표를 넣지 않았다. MY-1 북마크 탭(게시물 전용)과 묶는 방식이 필요하다(추천: VISIT-4에 `stamp_bookmarks` + MY-1 북마크 응답에 `item_kind` 추가).
3. **잉크 손글씨 서체** 사용 조건(계획 §4) 확인 전에는 서체 파일 없이 기울임만.
4. **혼합 피드**: 새 #32로 바꾸고 #26(게시물만)은 홈 하단 창용으로 유지.
5. **알림함 화면 담당**: C-47 G1 "담당 배정 때 정함" → 화면 B(CLUB-2), 내 정보 아이콘 A(MY-2), 서버 D로 잡았다.
6. **CLUB-2 크기**: 사용자 동선 셋이라 Step 상한을 넘을 수 있다. 나누기는 계획 변경이라 사용자 결정.
7. **READ-1-P2 파일 10개**(경로 파일 3개 포함) — 참고치 7 초과.
8. **MY-3 `IsoCube` 내보내기** 리팩터(A 파일) 허용 여부.
9. **운영 화면 위치**: 앱 안 `/ops`(운영자 외 `404`). 운영자 지정은 DB에 직접 넣기.
10. **반납 집계 쓰기**: C 파일 `loans.py`에 D 블록 하나. `RETURN_STATS_WRITE_ENABLED=False`로 두고 Q-49 뒤에 켠다.
