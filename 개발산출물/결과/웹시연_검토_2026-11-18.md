## 3. 시연 준비 판단

- **지금 그대로는 웹 시연에 쓰기 어렵다.** 홈·도서관 방문·로그아웃 안내는 되지만, 책 검색·상세(W-1)가 가짜 데이터라 "검색 → 상세 → 가까운 도서관 소장" 흐름을 보여 줄 수 없다.
- 시연 전에 고칠 것(순서): ① W-1(C) ② W-2(A) ③ W-3은 고치거나, 시연을 개발 모드가 아닌 실행(예: `npx expo start --web --no-dev`)으로 한다 — `--no-dev` 동작은 미확인이라 고친 뒤 확인.
- 외부 설정: Supabase Redirect URL `http://localhost:8081/login`은 실제 웹 로그인(#11)으로 확인됨. 카카오 지도 웹 도메인은 W-4(지금 화면엔 영향 없음).

- **고치는 계획:** D 결정(2026-11-18)으로 W-1·W-2·W-3·A-1을 [진행_시연전개선](../진행_시연전개선.md) S1에 넣었다. W-4는 지도를 다시 쓸 때 D가 카카오 콘솔에서 확인.
