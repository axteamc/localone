## 남은 보완

### 1. 색을 토큰 정의 한 곳에서 조정하는 정책이 완전히 적용되지 않았다

- `specs/library-visit/세부/VISIT-1_시안.html:133`, `:135`에 새 상태 카드·알약의 `rgba(...)` 그림자 값이 직접 들어 있다. 기존 `.drop .row`(76줄), `.dim`(82줄) 등에도 직접 색 값이 남아 있다.
- 이번에 추가한 B 인계 배너도 `VISIT-1_방문멘트_비교.html:39`, `VISIT-1_큰틀_시안.html:217`에 `#B45309`, `#FEF3C7`, `#7C2D12`를 직접 쓴다.
- 영향: 대표 핀 색만 바꾸는 것은 가능하지만, 공통 토큰만 수정해 전체 색을 조정한다는 기존 코멘트의 약속은 충족하지 못한다.
- 방향: 현재 색은 유지하고 선·오버레이·그림자·인계 안내 색도 의미별 토큰으로 모아 사용처에서 참조한다. 색 재선택은 필요 없다.

### 2. C-61 이후에도 옛 범위·대기 문장이 남아 있다

- `specs/library-visit/세부/VISIT-1.md:143`은 홈 지도 아래 VISIT-06을 여전히 M2로 적는다. 같은 PR의 큰 틀 명세 397줄과 C-61은 M1 VISIT-1b로 당겼다고 명시한다.
- 큰 틀 명세 202줄에는 방문 페이지 검색 진입점의 위치를 A가 정한다는 문장이 남아 있다. 현재 기능 배정 A·B절은 방문 페이지 전체 B, 방문 페이지 검색창 없음이다.
- 세부 시안 566줄의 “다음 세부 VISIT-2”도 현재 A의 다음 세부 VISIT-1b와 혼동할 수 있다.

### 3. 새 상태 화면의 검색창 높이가 채택안과 다르다

- `specs/library-visit/세부/VISIT-1_시안.html:549`의 새 예외 창은 `style="height:auto"`로 `.drop`의 `height:58%`(71줄)를 덮어쓴다.
- 이 창은 검색 결과 없음·창 닫기 상태에 공통 사용된다. 명세의 채택안과 HTML 명세 패널 589줄은 화면 58%의 반쪽 창이다.
- 영향: 상태에 따라 작은 내용 높이의 창으로 바뀌므로 마지막 화면 검토가 채택안과 다른 모양을 보여 준다.
- 방향: 채택한 높이를 유지한다. 키보드 때문에 높이를 바꾸려는 의도라면 그 조건과 값을 명세에 명확히 기록한다. 높이 불일치는 소스 대조 결과이며 실제 픽셀·화면 캡처 검증은 하지 않았다.
