## 0. 설계 원칙 요약

1. **화면 폭(`TOP_LINE = 92`)과 `topFont` 계단 특성 반영:** `FacadeHome.tsx:100-107`에서 6자 이하는 1줄(`per <= 6`), 7~10자는 2줄(`per = 4~5`, 주인공 큐브 기준 `fontSize = 16px` 무축소)이다. 무조건 2~3자로 무리하게 자르기보다 **1줄(2~6자)을 기본 목표로 하되, 기관 정체성이 필수인 경우 7~10자(2줄 무축소 구간)까지 자연스럽게 허용**한다.
2. **문맥 인지형 접두 제거(오제거 원천 차단):** 전국 244개 `REGIONS` 목록을 자동 활용하되, `구립/시립/교육청` 같은 명시적 표지가 없는 시군구명(`서구`, `남구`, `북구`, `양산` 등)은 **소속 지역(`dtl_region_code`/`address`) 일치 또는 시도 접두 연쇄/공백 경계** 조건을 만족할 때만 떼어 `남구로어린이도서관`·`양산어린이도서관` 같은 오제거를 막는다.
3. **접미사 선제 처리 + 2계층 분류:** `도서관`·`공공도서관`·`작은도서관`·하위실(`학습관자료실` 등)은 제거하되, 도서관과 다른 독립 기관명(`평생교육관`, `교육문화회관`, `기념회관`, `교육문화원`)과 이용 대상·특화 수식어(`어린이`, `청소년`, `영어`, `정보문화`)는 보존한다.
4. **기존 공개 API 하위 호환 유지:** `coreLibraryName(name, lib?)`, `regionOf(lib)`, `cubeNames(libs)` 시그니처를 유지하고 `lib.dtl_region_code`는 optional 필드로 수용한다(`deps.ts`에서 `REGIONS`를 함께 재수출).

### 1.2 단계별 처리 순서 (`analyzeLibraryName` → `coreLibraryName` / `cubeNames`)

내부 분석 함수 `analyzeLibraryName(name, lib?)`가 `{ core, regionFromPrefix, libRegion, strippedBranchTag, strippedSmallLib }`를 계산하고, `coreLibraryName`은 `core` 문자열만 반환한다.

1. **Step 1 — 입력 정규화 및 비한글 가드:**
   - `original = name.trim().replace(/\s+/g, " ")` (다중 공백을 단일 공백으로 정규화하되 **단어 경계 공백은 유지**).
   - 한글이 전혀 없으면(`!/[가-힣]/`) `original` 그대로 반환.
2. **Step 2 — 소속 지역 해석 (`resolveLibRegion(lib)`):**
   - 우선순위 ① `lib.dtl_region_code` → `REGION_BY_CODE` 조회.
   - 우선순위 ② `lib.address` 토큰 파싱 (`sido` + `sigungu` + `subGu`, `세종특별자치시`·`전남광주통합특별시` 포함).
   - 우선순위 ③ `lib.area_label?.trim() || null`.
3. **Step 3 — 분관 분리 및 말미 괄호 처리:**
   - **패턴 A (`<본관> 분관 <독립 분관명>`):** `^.+?\s*분관\s+(.+)$` 매칭 시(앞부분이 `도서관|교육관|회관|문화원`으로 끝나거나 공백 `분관` 구분자인 경우), 뒤의 `<독립 분관명>`(`최상준도서관`)을 작업 대상 `s`로 채택하고 `strippedBranchTag = "분관"` 기록.
   - **패턴 B (말미 괄호 태그):** 말미 `(?:\s*[(\[][^()\[\]]*[)\]])+$`를 추출.
     - 괄호 안이 `(분관)`/`(본관)`/`(신관)`/`(별관)`/`(임시)`/`(구 …)` 등 메타 태그이거나, 괄호를 떼고 남은 본문이 한글 2자 이상이면 말미 괄호를 제거하고 `strippedBranchTag`에 보존(충돌 시 복원 가능).
     - 단, 괄호 안이 `<2자 이상 고유명>분관` (예: `(병점분관)`)이면 분관 고유명(`병점분관`)을 별도 태그로 유지하거나 충돌 방지를 위해 그대로 보존(§4 엣지케이스 참조).
   - **패턴 C (문장 중간 괄호):** 말미 괄호 제거 후에도 중간에 `(`·`)`·`[`·`]`가 남아 있으면 구조를 훼손하지 않도록 `original` 반환.
4. **Step 4 — 접미사(하위실·도서관 유형) 선제 제거:**
   - ① 하위실 접미사: `/\s*(?:학습관자료실|자료실|열람실|도서실)$/` 제거(잔여 한글 2자 이상일 때만).
   - ② `작은도서관` 조건부 제거: `/\s*작은도서관$/` 매칭 시, 앞부분이 **순수 접두사(지역·설립주체)만이 아니고** 접두사 제거 후에도 2자 이상 남을 경우에만 `작은도서관` 전체를 제거(`strippedSmallLib = true`). 그렇지 않으면(`강남구립작은도서관`, `작은도서관`) `도서관`만 제거해 Step 6의 범용어 보정(`강남 작은`)으로 넘긴다.
   - ③ 일반 도서관 접미사: `/\s*(?:공공도서관|도서관)$/` 제거(잔여 2자 이상일 때만; `도서관`을 떼면 2자 미만이면 `original` 반환).
5. **Step 5 — 별칭·행정명·설립주체 접두사 반복 제거 (긴 후보 우선, 잔여 ≥ 2자 가드):**
   - 루프마다 `s`의 앞에서 아래 4군을 **긴 매칭 우선**으로 검사하고, 제거 후 남는 문자열이 **2자 이상**일 때만 제거한다. 제거 시마다 `strippedSido` / `strippedSigungu`를 기록하고 뒤따르는 선행 공백을 제거한다.
   - **군 1 (명시적 행정·교육청·통합특별시 접두):**
     - `ADMIN_ALIASES` + `(?:교육청|교육지원청|시립|도립|립)?`
     - `SIDO_FULL/SHORT` + `(?:교육청|교육지원청|특별시립|광역시립|특별자치시립|특별자치도립|시립|도립)`
     - 확장 구조 정규식 폴백: `/^[가-힣]{2,10}(?:통합특별시|특별자치시|특별자치도|특별시|광역시)(?:교육청|교육지원청|립)?/` 및 `/^[가-힣]{2,6}도(?:교육청|교육지원청|립)/`
     - 시군구 교육지원청: `/^[가-힣]{2,6}(?:시|구|군)?교육지원청/`
   - **군 2 (설립주체 결합 시군구 접두):**
     - `SIGUNGU` 기반 `<시군구명>립` / `<시군구약칭>(?:시립|구립|군립)` (예: `광산구립`, `강남구립`, `광주시립`, `수원시립`)
     - 단독 설립주체: `/^(?:구립|시립|군립|도립|공립|교육청)/` (`국립` 제외)
   - **군 3 (설립주체 없는 시군구 접두 — 문맥 가드 필수):**
     - `서구`, `남구`, `북구`, `광산구`, `강남구`, `광주시`, `수원시 장안구` 등 `시/구/군` 단위가 붙은 시군구명.
     - **허용 조건(셋 중 하나):**
       - (a) `libRegion`의 소속 시군구(`sigunguFull` 또는 `subGu`)와 일치, 또는
       - (b) 직전 루프에서 `strippedSido`가 제거되었고 해당 시도의 `SIGUNGU_BY_SIDO`에 속함, 또는
       - (c) `lib` 미제공 상태이며 바로 뒤에 공백 경계가 있음(`/^서구\s+/`).
   - **군 4 (단독 시도 약칭 — 문맥 가드 필수):**
     - `광주`, `서울`, `부산`, `경기` 등 2글자 시도 약칭.
     - **허용 조건(셋 중 하나):**
       - (a) 바로 뒤에 공백 경계가 있고 `libRegion.sidoShort`와 일치(또는 `lib` 미제공), 또는
       - (b) 바로 뒤에 해당 시도의 시군구명(`SIGUNGU_BY_SIDO`)이나 설립주체가 밀착(`광주남구...`), 또는
       - (c) 직전 루프에서 이미 같은 `strippedSido`를 제거한 중복 시도명(`전남광주통합특별시교육청` 제거 직후의 `광주` → `광주학생교육문화회관`에서 `광주` 제거).
   - **Step 5b — 말미 단독 설립주체 정리 (지역명+설립주체만 남은 경우):**
     - 예: `세종시립도서관` → Step 4 후 `세종시립` → Step 5에서는 통째로 떼면 0자가 되어 유지됨.
     - 이 상태에서 `s`가 `<2자 이상 지명>(?:특별시립|광역시립|특별자치시립|특별자치도립|시립|구립|군립|도립)`이면 설립주체만 뗀다(`세종시립` → `세종`, `강남구립` → `강남`).
     - 지명이 1자 + 행정단위(`동구립`, `중구립`, `서구립`, `남구립`, `북구립`)이면 끝의 `립`만 뗀다(`동구립` → `동구`).
6. **Step 6 — 범용어 보정, 광역 지명 중의성 보정, 최소 길이 안전장치:**
   - **최소 길이 가드:** `len(s) < 2`이면 `original` 반환.
   - **광역 지명 중의성 헬퍼 `disambiguateMetro(regionOrCore, effectiveSido)`:**
     - `METRO_SHORTS.has(target)`이고 `effectiveSido`가 존재하며 `effectiveSido !== target`이면 `${effectiveSido}${target}` 반환 (예: `target="광주"`, `effectiveSido="경기"` → `"경기광주"`).
   - **범용어(`GENERIC.has(s)`) 보정:**
     - 우선 지역명 선택: `baseRegion = strippedSigungu ?? strippedSido ?? libRegion?.sigunguShort ?? libRegion?.sidoShort ?? lib?.area_label?.trim() ?? null`.
     - `baseRegion`에 `disambiguateMetro(baseRegion, libRegion?.sidoShort ?? strippedSido)` 적용.
     - 최종 결과: `baseRegion ? `${baseRegion} ${s}` : original`.
   - **비범용어 광역 지명 중의성 보정:**
     - `s` 자체가 `METRO_SHORTS`에 속하고 `effectiveSido = strippedSido ?? libRegion?.sidoShort`가 `s`와 다르면 `disambiguateMetro(s, effectiveSido)` 적용 (`경기도교육청광주도서관`: `s="광주"`, `effectiveSido="경기"` → `"경기광주"`).
7. **Step 7 — `cubeNames(libs)` 다단계 동명 충돌 해소 (최대 7곳 판 기준):**
   - 0단계: 모든 도서관에 `analyzeLibraryName(lib)` 적용 → `core` 생성.
   - 1단계(충돌 집합만): 겹치는 도서관끼리 **세부 지역/속성 접두·접미**로 해소 시도:
     - ① 서로 `sigunguShort`가 다르면 `disambiguateMetro(sigunguShort, sidoShort)`를 앞에 붙임(이미 해당 접두로 시작하면 중복 부착 금지).
     - ② `sigunguShort`까지 같고 `area_label`(동/읍/면)이 다르면 `area_label`을 앞에 붙임.
     - ③ 지역이 같고 한쪽만 `strippedBranchTag`(예: `(분관)`) 또는 `strippedSmallLib`(`작은`)을 떼어낸 경우, 떼어낸 표식을 복원(`논현문화마루` vs `논현문화마루(분관)`, `광남` vs `광남작은`).
   - 2단계(최종 안전장치): 1단계 후에도 여전히 겹치면 해당 충돌 항목만 `lib.name.trim()`(원래 이름) 사용.

### 1.3 핵심 제어 흐름 의사코드

```ts
function analyzeLibraryName(name: string, lib?: LibRegionInput): AnalyzedName {
  const original = name.trim().replace(/\s+/g, " ");
  if (!hasHangul(original)) return fallback(original);

  const libRegion = resolveLibRegion(lib); // dtl_region_code -> address -> area_label
  // 1. 분관 분리 및 말미 괄호 정리
  let { text: s, branchTag, bailout } = extractBranchAndTrailingParens(original);
  if (bailout) return fallback(original);

  // 2. 접미사 선제 제거 (하위실 -> 조건부 작은도서관 -> 공공도서관/도서관)
  s = stripRoomSuffix(s);
  const { text: afterType, strippedSmall } = stripLibraryTypeSuffix(s, libRegion);
  if (len(afterType) < 2) return fallback(original);
  s = afterType;

  // 3. 접두사 반복 제거 (군1 명시적 -> 군2 설립주체 -> 군3 문맥 시군구 -> 군4 문맥 시도약칭)
  let strippedSido: string | null = null;
  let strippedSigungu: string | null = null;
  while (true) {
    const match = matchLongestAllowedPrefix(s, { libRegion, strippedSido, strippedSigungu });
    if (!match || len(s.slice(match.length).trimStart()) < 2) break;
    strippedSido = match.sidoShort ?? strippedSido;
    strippedSigungu = match.sigunguShort ?? strippedSigungu;
    s = s.slice(match.length).trimStart();
  }

  // 4. 말미 단독 설립주체 정리 (예: "세종시립" -> "세종", "동구립" -> "동구")
  s = stripTrailingFounder(s);
  if (len(s) < 2) return fallback(original);

  // 5. 범용어 및 광역 지명 중의성 보정
  const effectiveSido = libRegion?.sidoShort ?? strippedSido;
  if (GENERIC.has(s)) {
    const rawRegion = strippedSigungu ?? strippedSido ?? libRegion?.sigunguShort ?? libRegion?.sidoShort ?? lib?.area_label?.trim() ?? null;
    const region = rawRegion ? disambiguateMetro(rawRegion, effectiveSido) : null;
    return result(region ? `${region} ${s}` : original, { libRegion, branchTag, strippedSmall });
  }
  s = disambiguateMetro(s, effectiveSido);
  return result(s, { libRegion, branchTag, strippedSmall });
}
```
