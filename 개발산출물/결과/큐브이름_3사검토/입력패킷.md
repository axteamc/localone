## 1. 배경 및 제약 조건

### 1.1 화면 및 기능 제약
- **표시 위치:** 홈 화면 등각 큐브의 **윗면** (`mobile/src/features/library-visit/FacadeHome.tsx`).
- **글자 수·폭 제약:**
  - 윗면 마름모 가운데 줄 기준 가용 폭 `TOP_LINE = 92` (`110.8`에서 양옆 여백 제외).
  - **6자 이하:** 1줄 표시 (`want`: 주인공 16px, 나머지 12.5px).
  - **7자 이상:** 2줄로 줄바꿈되며, 한 줄 글자 수가 늘어나면 `fontSize`가 최소 6px까지 축소됨.
  - 따라서 핵심 이름은 **가능하면 2~6자(최대 7~8자 내외)**로 간결하고 직관적이어야 함.
- **표시 범위 분리:**
  - **화면에 보이는 큐브 윗면 글자만** 줄인다.
  - 접근성 이름(`accessibilityLabel`), 검색창, 방문 페이지, 목록 등 다른 곳은 **원래 이름(`name`)**을 그대로 유지한다.
- **입력 데이터 (외부 공공데이터 추가 호출 없음):**
  - 도서관 객체: `id`, `name` (원래 이름), `address` (도로명 주소), `area_label` (동/읍/면 등, nullable).
  - 앱 내장 지역 표(`mobile/src/lib/regions.ts`): 정보나루 `dtl_region` 코드 244개 (`code | sido | sigungu`, 예: `24010|광주광역시|동구`, `31250|경기도|광주시`, `29010|세종특별자치시|세종시`).
- **실행 환경:** 클라이언트 순수 함수 (`shortName.ts`: `coreLibraryName`, `regionOf`, `cubeNames`).

### 1.2 현재 규칙 요약 (`mobile/src/features/library-visit/shortName.ts`)
1. **원본 유지 예외:** 한글이 없거나(영문명), 괄호(`()`, `[]`)가 있거나, 앞말·끝말을 떼고 남은 글자가 2글자 미만이면 원래 `name`을 반환한다.
2. **앞말(`PREFIXES`) 제거:** 공백을 모두 제거한 뒤 정규식으로 앞말을 반복 제거한다. (예: `{2,4}글자 + (특별시|광역시|특별자치시|특별자치도)교육청`, `{1,4}글자 + (구립|시립|군립|도립)`, `구립|시립|군립|도립|공립|교육청`). 단, `국립`은 떼지 않는다 (`국립중앙` → `중앙` 방지).
3. **끝말(`SUFFIX`) 제거:** 끝의 `공공도서관` 또는 `도서관` 하나만 뗀다.
4. **범용어(`GENERIC`) 보정:** 남은 핵심 이름이 `{"중앙", "어린이", "청소년", "작은", "공공", "시민", "구민", "평생학습", "정보", "기적의", "본관", "분관"}` 중 하나면 앞말 또는 주소(`regionOf`)에서 꺼낸 지역명을 앞에 붙인다. (예: `부산 시민`, `서울 어린이`).
5. **동명 충돌 해소 (`cubeNames`):** 판(최대 7곳)에 함께 보이는 도서관 중 줄인 이름이 겹치면 겹친 것끼리만 `regionOf(lib)`를 앞에 붙이고, 그래도 겹치면 원래 `name`을 쓴다.

### 1.3 현재 규칙의 문제 진단 (광주 29곳 실측: 10곳 정상 / 19곳 이상)
1. **행정명 길이·변경 미대응:** `{2,4}글자` 정규식이라 `"전남광주통합특별시"`(6글자)를 전혀 떼지 못한다.
2. **설립주체 없는 구 이름 미대응:** `"구립"`이 붙지 않은 `"광주 서구 …"`, `"광주남구…"`, `"전남광주통합특별시 북구 …"`에서 구 이름을 못 뗀다.
3. **기관 유형 확장 미대응:** 끝말이 `도서관`만 있어서 `평생교육관`, `교육문화회관`, `기념회관`, `분관 ○○` 등이 그대로 남는다.

## 2. 이전 검토안 (참고용 — 미채택)

> 날려야 할 말 세 종류: ① 지역 접두(광주·서울·강남구·수원시 — 시도·시군구 목록이 있어 규칙적) ② 설립주체(시립·구립·군립·도립·국립·공립·사립 — 닫힌 집합) ③ 유형 접미(도서관·작은도서관·어린이도서관·청소년도서관·정보도서관·○○분관 — 닫힌 집합에 가깝지만 변형 있음).
>
> 함정: 중앙이 고유명일 때(범용어 목록에 걸리면 지역명 되살려 `광주 중앙`) / "작은"은 "작은+도서관"이 붙어 있을 때만 유형 / 지역 접두 겹침(긴 것부터 매칭, 광주광역시 vs 경기 광주시) / 동명 도서관(표시할 때 지역을 따로) / 다 벗겨 빈 결과면 원본(안전장치).
