## 1. 규칙 설계안

### 1.1 처리 순서

```
0. 원본 유지 검사      한글 없음 → name 그대로
1. 정규화             NFC, 전각→반각, 공백 위치 기억 후 공백 제거
2. 괄호 처리           (분관)(본관)(별관) 등 닫힌 집합 → 지움 / 그 밖의 괄호 → 괄호째 지움(큐브 표시용)
3. 지역 판정           regionOf(lib): 주소 → REGIONS로 {sido, sigungu} 확정 (토큰 해석의 기준)
4. 앞말 제거 (반복, 최대 4회)
   4a. 교육청 단위      ^(지역토큰)+교육청 → 지움, 직후 "같은 시도의 줄임말"(광주·서울)이 또 나오면 그것도 지움
   4b. 지역 단위        ^시도정식명 / ^시도줄임말(뒤가 시군구·립·공백일 때만) / ^자기 시군구(앞에 시도가 있었거나, 뒤가 립·교육청·공백일 때만)
   4c. 설립주체         지역토큰 바로 뒤의 "립" / ^(구립|시립|군립|도립|공립|사립)
       ※ "국립"은 떼지 않고, 만나면 앞말 제거를 멈춘다
5. 분관 처리           …분관(고유명) → 고유명만 / (고유명)분관$ → 고유명만
6. 끝말 제거
   6a. 도서관류(L)      공공도서관|작은도서관|도서관|자료실|도서실|문고  — 하나만, 긴 것부터
   6b. 기관류(F)        교육문화회관|평생교육관|평생학습관|교육문화원|기념회관|문화회관|학습관 — 최대 2개, 뗀 것은 스택에 보관
7. 안전장치 (아래 순서대로, 처음 성립하는 것 채택)
   7a. 핵심어가 범용어이거나 비었고, 6b에서 뗀 F가 있으면 → F를 안쪽(마지막에 뗀 것)부터 다시 붙인다
   7b. 핵심어가 범용어면 → 지역 표시명 + " " + 핵심어
   7c. 핵심어가 비었고 4c에서 뗀 "지역+립" 단위가 있으면 → 그 단위(예: 세종시립)
   7d. 핵심어가 비었고 마지막으로 뗀 지역토큰이 있으면 → 그 지역토큰(예: 경기도교육청광주도서관 → 광주)
   7e. 그래도 2자 미만 → name 그대로
8. cubeNames 충돌 해소  (§1.4)
```

### 1.3 지역 판정과 표시명 (`regionOf`)

```ts
regionOf(lib) => { sido: string /*REGIONS sido*/, sigungu: string | null }
```
- 주소 첫 토큰을 `SIDO_ALIASES.full`로 찾고, 둘째 토큰을 그 시도의 REGIONS `sigungu`로 찾는다.
- `전남광주통합특별시 동구 …`처럼 통합명이 오면 둘째 토큰(동구·서구·남구·북구·광산구)이 REGIONS `광주광역시` 아래에 있으면 `광주광역시`로, 아니면 `전라남도`로 본다.
- 주소가 비거나 못 찾으면 `area_label`, 그래도 없으면 `null` → 지역 관련 단계(4b의 시군구 제거, 7b)는 건너뛴다.

**표시명** (`regionLabel(lib, level)`)
- `level = 'sido'` → 시도 줄임말: `광주`, `서울`, `세종`, `경기`
- `level = 'sigungu'` → 시군구 정식명 그대로: `남구`, `강남구`, `광주시`, `수원시` (시·군은 "시/군"을 남겨 `광주`(광역시)와 `광주시`(경기)가 갈리게 한다)
- 7b에서 어느 level을 쓸지: **이름에서 떼어 낸 지역토큰 중 가장 좁은 것의 level**. 이름에 지역토큰이 없었으면 `sigungu`.

### 1.4 충돌 해소 (`cubeNames`, 판 최대 7곳)

1. 판 안에서 줄인 이름이 같은 것끼리만 묶는다.
2. 묶음 안에서 `regionLabel(lib, 'sigungu')`가 서로 다르면 그것을 앞에 붙인다(`북구 중흥` / `동구 중흥`).
3. 시군구가 같거나 이미 지역이 붙은 이름이면 `regionLabel(lib, 'sido')`를 시도해 보고(광주 vs 경기 광주시처럼 시도가 다를 때),
4. 그래도 겹치면 그 묶음만 원래 `name`.
- 이미 앞에 같은 지역 표시명이 붙어 있으면(7b 결과) 또 붙이지 않는다.

## 2. 결정 쟁점 4가지 — 제안과 이유

### 결정 1. 교육청 소속 기관 표기
**제안: `○○교육청`은 항상 지운다. 기관 유형(F)도 기본은 지우고, 지운 뒤 남은 말이 범용어거나 비면 그때만 유형을 되살린다. "교육청"을 짧게 붙이지 않는다.**

| 원래 | 결과 |
| :--- | :--- |
| 전남광주통합특별시교육청중앙도서관 | 광주 중앙 |
| …교육청금호평생교육관 | 금호 |
| …교육청학생독립운동기념회관 | 학생독립운동 |
| …교육청광주학생교육문화회관 | 학생교육문화회관 |
| 세종시교육청교육문화원 학습관자료실 | 교육문화원 |

이유
- 큐브는 "어느 동네 그 건물"을 알아보는 자리다. 운영 주체(교육청·구청·시청)는 사용자가 고를 때 쓰는 정보가 아니고, 시립·구립을 떼는 지금 규칙과 같은 원리다. `교육청`을 붙이면 2~3자를 쓰면서 구별력은 거의 없다.
- 유형을 늘 남기면 `금호평생교육관`(7)·`학생독립운동기념회관`(10)처럼 길어져 2줄·축소 글꼴이 된다. 유형을 늘 지우면 `학생`처럼 뜻이 없는 말만 남는 경우가 생긴다. → "지워 보고 안 되면 되살린다"가 둘 다 피한다.
- `광주학생…`의 `광주`는 교육청 이름(전남**광주**통합특별시)을 되풀이한 말이라 4a에서 함께 뗀다. `경기도교육청광주도서관`의 `광주`는 교육청 이름(경기도)과 다르므로 남긴다.
- 포기하는 것: `금호`만 보고는 평생교육관인지 모른다. 방문 페이지·목록에는 원래 이름이 나오므로 받아들인다.

### 결정 2. 분관 표기
**제안: 분관 고유명만 남긴다(`최상준`). 괄호 `(분관)`은 지운다(`논현문화마루`). 고유명이 없는 분관(`○○도서관 분관`)은 `○○ 분관`으로 둔다(범용어 `분관` 보정).**

이유
- 현장 간판·주민이 부르는 이름은 분관 고유명(최상준도서관)이다. `중앙 최상준`(5)은 본관을 아는 사람에게만 도움이 되고 길다.
- `(분관)`은 "본관이 따로 있다"는 행정 정보라 큐브에서 구별에 쓰이지 않는다. 같은 판에 본관이 함께 떠서 이름이 겹치면 §1.4가 처리하고, 끝까지 겹치면 원래 이름(괄호 포함)이 나온다.

### 결정 3. 구 이름이 이름에 박힌 경우
**제안: 구 이름을 지운다(`상록`, `푸른길`, `신용`). 단, 떼는 구는 "이 도서관 자신의 시군구"이고, 앞에 시도가 붙어 있거나 / 뒤가 `립`·`교육청`이거나 / 원래 이름에서 공백으로 떨어져 있을 때만 뗀다.**

이유
- 판에 함께 뜨는 도서관은 대부분 같은 구라서 `서구`는 7곳 모두에 똑같이 붙는 말이 된다. `구립`을 떼는 지금 규칙(광산구립신가 → 신가)과도 맞는다.
- 여러 구가 섞여 같은 이름이 나오면 §1.4가 그 둘에만 구를 붙인다.
- 조건을 거는 이유: `종로도서관`(서울시교육청)·`광주도서관`(경기도교육청)처럼 지역명 자체가 고유명인 경우를 지키기 위해서다. 그래도 다 떼어 비면 7d가 되살린다.

### 결정 4. 범용어와 지역 모호성
**제안: 범용어 보정은 지금처럼 지역을 앞에 붙이되, 붙이는 지역은 "이름에서 뗀 가장 좁은 지역"의 단계로 고르고, 시도는 줄임말(`광주`), 시·군은 정식명(`광주시`)으로 쓴다. 지역 해석은 이름 글자가 아니라 주소(`regionOf`)로 정한다.**

| 원래 | 결과 | 왜 |
| :--- | :--- | :--- |
| 전남광주통합특별시교육청중앙도서관 | 광주 중앙 | 뗀 지역이 시도급 → 시도 줄임말 |
| 광주시립중앙도서관(경기) | 광주시 중앙 | 뗀 지역이 시군구급(경기 광주시) |
| 광주남구청소년도서관 | 남구 청소년 | 뗀 지역 중 가장 좁은 것이 남구 |
| 서울특별시교육청서울시립어린이도서관 | 서울 어린이 | 시도급만 뗐음 |

이유
- `광주` 두 글자가 광주광역시인지 경기 광주시인지는 이름만으로 알 수 없다. 주소의 시도로 먼저 정하면 `광주시립`을 "광주시 + 립"으로 볼지 "광주 + 시립"으로 볼지가 뗄 때는 결과가 같고, 붙일 때만 갈리므로 표시명 규칙(광역시는 `광주`, 시는 `광주시`)으로 갈라 주면 된다.
- 범용어 앞에 시도를 붙이면 같은 시 안의 구립 `어린이`·`청소년`이 서로 겹친다. 이름에 박혀 있던 가장 좁은 지역을 쓰면 원래 이름이 담은 정보를 그대로 살린다.
- `학생`을 범용어에 넣는다(결정 1의 `학생교육문화회관` 처리에 필요).
