## 1. 3사 공통 합의 사항 (이견 없음)
이 항목들은 3사 모두 동일한 결론을 도출했으며, 시안 선택과 무관하게 v2 규칙의 기본 골격으로 확정 적용할 수 있습니다.

1. **교육청 소속 표기 완전 제거:**
   - 큐브에서 운영 주체 정보는 공간만 차지하므로 `전남광주통합특별시교육청`, `서울특별시교육청` 등의 명시적 접두사는 무조건 제거한다.
2. **분관 표기 원칙 (고유명 우선):**
   - `<본관> 분관 <고유명>` 형태는 본관과 `분관` 표식을 지우고 독립 고유명(`최상준`)만 남긴다.
   - 단독 괄호 `(분관)`도 제거한다(`논현문화마루`). 본관과 동시 노출되어 충돌할 때만 `cubeNames`가 복원한다.
3. **단순 구 이름 삭감:**
   - 주소와 일치하는 접두형 구 이름(`광주 서구`, `북구`, `강남구립`)은 지운다 (`상록`, `신용`, `개포하늘꿈`). 단, `종로도서관`처럼 지역명 자체가 유일한 핵심인 경우만 안전장치로 보존한다.
4. **광역 지명 모호성 방지:**
   - `광주광역시`와 `경기도 광주시`는 하드코딩 예외나 상위 행정구역 결합(`경기광주`)을 통해 전국 단위 노출 시 혼동이 없도록 렌더링한다.

## 2. 갈리는 쟁점 (결정 필요)
다음 두 가지 쟁점은 "가독성(짧은 글자 수)"과 "장소 정체성 보존" 중 어느 것을 우선할지에 따라 3사의 의견이 갈렸습니다. 

1. **비도서관 기관 유형(`평생교육관`, `교육문화회관`, `기념회관`)의 처리:**
   - **Gemini Web / Codex:** 전부 삭제. (예: `금호`, `광주 학생`, `학생독립운동`) - 간결성 최우선.
   - **Claude:** 기본 삭제하되, 전부 지워서 무의미한 범용어(`학생`)만 남으면 조건부 복원. (예: `금호`, `학생독립운동`, `학생교육문화회관`)
   - **Gemini:** 도서관이 아닌 기관명은 무조건 보존. (예: `금호평생교육관`, `학생독립운동기념회관`)
2. **범용어(`중앙`, `어린이`, `청소년`) 앞 지역명 보충 수준:**
   - **Codex / Gemini:** 시도(광역) 약칭 결합. (`광주 중앙`, `광주 청소년`)
   - **Gemini Web:** 시군구 결합. (`동구 중앙`, `남구 청소년`)
   - **Claude:** 이름에서 떼어낸 가장 좁은 지역 결합. (`광주 중앙`, `남구 청소년`)
