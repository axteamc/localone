### 추가 후보 D — 요소별 최종 추천 하나씩

**① 카드 D: 무광 면 + 정보 카드에만 2px 받침.** B의 재료감을 얇게 가져오고, 이미지·검색 행은 C처럼 평평하게 둔다. '카드마다 같은 효과'보다 홈과 같은 재료의 위계를 유지하는 안이다.

- 배경 bg, 카드 panelFrosted; 테두리 새 제안 `surfaceEdge=mix(text,bg,.14)` 1px, 아래 받침 `surfaceFoot=mix(text,surface2,.15)` 2px. 그림자 0, 하이라이트 0. 광택 대신 명도 차이로 재료를 드러낸다. 곡률 radii.card: warm/toffee/oxford18, modern6. 표지는 radii.bookCover 그대로.
- 정보 카드(도서관 소장 정보·안내 묶음)에만 받침, 표지·사진·일반 결과 행에는 받침 없음. 빈 상태는 그 자체로 중첩 카드가 필요하지 않다.
- 얻는 것: 콘크리트 같은 차분한 면, 긴 목록의 밀도, 네이티브/웹 일관성, 4룩에서도 새 색 강조 없음. 포기: 홈 블록의 강한 돌출·광택.
- 누르면: 검색 행은 책 상세, 소장 정보 카드는 기존처럼 자체 비클릭, 오른쪽 실시간 확인만 외부 사이트. 비클릭 카드는 눌림/hover 변화 없음.
- **추천: D.** 홈의 표면은 공유하면서 공간 블록과 정보 카드의 역할 차이를 보존한다.

**② 버튼 D: 중성 명도 한 단계 + 가벼운 보조 행동.** 화면 주 행동만 `actionStrong=mix(text,bg,.90)`, 글자 paper, 높이48, 글자15/700, radii.control9999, 테두리0·그림자0. 누름 `actionPressed=mix(text,bg,.96)`, 100ms 명도 전환, 놓으면 140ms 복귀. 움직임 줄이기 설정에서는 즉시 전환.

- 일반 카드 안 행동은 text 13/700 링크, 누름 영역44 이상. 이미 확정된 '실시간 확인' 오른쪽 작은 필은 형태를 유지: panelFrosted, surfaceEdge 1px, control9999, 높이34+hitSlop5. 기존 44 터치 영역 유지. 비활성은 opacity .45, 처리 중 폭 유지.
- 얻는 것: 강한 행동 한 개, 파랑·갈색 없는 4룩, 색이 아닌 명도로 강조. 포기: 노랑을 행동 표시로 공유하는 방식.
- 누르면: 저장은 현재 로그인 확인/도서관 선택·저장 분기 그대로, 외부 버튼은 사이트로, 로그인은 기존 제공자 흐름 그대로. 실패를 성공 모양으로 바꾸지 않고 기존 오류/재시도 유지.
- **추천: D.** B의 색 통일보다 이번 '색을 추가하지 않는 강조'와 네 가지 룩 조건을 우선한다.
- **규칙 변경 필요(기존 DESIGN 문장):** '주 행동=inkStrong'을 중성 파생 actionStrong 허용으로 고쳐야 한다. 이번 사용자의 금지색·토큰 규칙을 바꾸자는 제안은 아니다. 현재 Oxford의 fill1/inkStrong, toffee의 fill1을 그대로 유지하면서 '파랑·나무색을 어디에도 쓰지 않기'는 양립하지 않는다. 이번 구현에서는 기존 홈 배색을 변경하지 않았다. 향후 기본 팔레트 전체를 바꾸는 일은 별도 사용자 결정이며 이 제안에 끼워 넣지 않는다.

### 기능 제안 — 시각 변경과 분리, 전부 미채택

1. 대출·반납 비로그인 화면에 '책 먼저 찾아보기' 보조 링크 추가: 로그인 외에 할 수 있는 일이 없어 막힌 느낌을 줄인다. 기존 /search 이동, text15/700, 최소44, 주 버튼 아래12. `app/(tabs)/loans.tsx`, 작음. 새로운 문구·진입 동선이라 별도 기능 결정.
2. 내 정보의 '준비 중이에요'와 '로그인 안 함'을 목적 설명 한 문장으로 통합: 현재 중복 상태보다 로그인 후 할 수 있는 일을 전달. 확정된 기능만 설명하고 미구현 기능을 약속하지 않는다. 15/22, 최대2줄. `app/(tabs)/me.tsx`, 작음. 문구 확정 필요.
3. 홈 인기 도서의 '집계 기준'을 누르면 범위·기간 설명 열기: 인기가 곧 대출 가능으로 읽히지 않게 한다. 13/18, 최소44 터치, panelFrosted·radii.card 안내. `PopularBooksRow.tsx`와 신규 안내 컴포넌트(짐작), 중간. 서버가 이미 제공하는 사실만 표시하고 기준일을 추정하지 않음.
