## 1. 프로젝트명 및 한 줄 정의

**동네한권 (localone)**
> **"도서관에 갈 사람만 쓰는 앱이 아니라, 앱을 열다 보면 동네 도서관에 가고 싶어지게 만드는 지역 독서 커뮤니티"**

내 주변 도서관을 입체 큐브 파사드로 보여주는 홈 화면에서 도서관을 골라 **방문 페이지**로 들어가면, 그 도서관을 오가는 이웃들이 남긴 **핀터레스트형 2열 광장 피드(사진·책 표지·단색 배경 위 좋은 문장)**와 **오늘의 서가(책장) · 방명록 · 작은 모임**을 만나며 다음 읽을 책을 발견한다. 읽고 싶은 책이 생기면 가까운 도서관의 소장·대출 가능 여부(`어제 기준`)를 확인해 **빌릴 예정**에 담고, 실제 도서관에서 책을 빌린 뒤엔 **"빌렸어요"** 한 번으로 D-day 타이머와 반납 알림까지 가볍게 챙긴다. iOS · Android · Web 단일 코드베이스(React Native + Expo)로 구현·배포되었다.

---

## 2. 배경 및 왜 '단순 대출/반납 시스템'이 아닌가

1. **기존 도서관 유틸리티의 한계**: 실제 공공 도서관의 대출·반납 원장은 지자체 및 국립중앙도서관(책이음) 통합 DB에 있어 외부 개인 앱이 대출 처리를 대행할 수 없다. 이미 책을 정하고 도서관에 간 사람은 도서관 내 대출기나 지자체 공식 앱을 쓰지, 제3의 CRUD 앱을 쓸 이유가 없다.
2. **탐색 동기 부재**: 기존 도서관 앱은 "이미 읽을 책을 정한 사람"만 여는 검색기일 뿐, 동네 도서관에 가고 싶게 만드는 동기(이웃의 문장, 공간감, 모임)를 주지 못한다.
3. **동네한권의 전환**: 반납 비서는 부담 없는 보조로 두고, **공공 도서관을 이웃의 문장과 이야기가 쌓이는 동네 거점으로 '방문'하는 커뮤니티 경험**을 중심에 둔다.

## 4. 목적

1. **도서관 기반 지역 독서 커뮤니티 구현**: 공간적 방문 경험(큐브 파사드 홈, 도서관별 고유 룩 4종, 방문 멘트·스탬프)과 문장 중심 피드(제목·작성자·숫자 노출을 덜어낸 이미지 카드)를 결합한다.
2. **투명한 공공 데이터 + 철저한 개인 데이터 격리**: 검증된 JWT(`sub`) 기반 소유권 분리, 타인/미존재 리소스 동일 `404` 은닉, 사진 EXIF 위치 자동 제거, 외부 I/O와 DB 트랜잭션 분리 원칙을 지킨다.
3. **단일 코드베이스 크로스 플랫폼 & 건축적 디자인**: React Native + Expo로 iOS·Android·Web을 한 벌의 코드로 구현하고, 일관된 디자인 토큰 체계를 유지한다.
4. **실운영 가능한 품질과 검증**: 격리 DB 기반 자동화 테스트(pytest 947+ · Jest 929+), CI/CD, Google Cloud Run 운영 배포까지 완결한다.

## 8. 디자인 시스템 요약 (현재 앱 기준)

- **조형 컨셉**: Arne Vodder 사이드보드(곡률·색 블록) + 현대 건축(콘크리트·회반죽 벽·무광 유리판 `panelFrosted`/`panelLit` + `1px seamHairline` + `2px reliefBottomMid` 받침). 나무 질감·나무색은 배제한다.
- **색 배정 원칙 (85:10:5)**: 화면의 85%는 무광 배경·블록, 10%는 구조(`inkStrong`·줄눈·두께면), 5%는 포인트(`fill1~3`).
- **타이포그래피**: 크기와 굵기 분리(제목 `22~24px` Regular 400, 본문 `14px`, 영문 계기판 표찰 `10~11px` Medium 500 + 넓은 자간). 굵기 700/600 미사용, 한글 문장과 계기판 숫자 한 줄 혼합 금지.
- **테마 & 팔레트**: 도서관 방문 페이지 **룩 4종**(`warm` `#E1E1DE`/`#E9C970` · `modern` `#CDCDCB`/`#FB5102` · `toffee` `#E4E2DB`/`#6E5140` · `oxford` `#CDCDCB`/`#35557F`), 홈 큐브 **`CUBE_PALETTE` 20색**, 로고 **I4(책 세 권 쌓기)**.
