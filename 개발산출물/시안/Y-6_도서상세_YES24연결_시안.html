정할 것 ①. YES24 연결을 어디에 두나 결정 전

채택안(기본 선택): 세 후보 모두 본문 순서는 지금 그대로(②-A)로 그렸어요.

A. 가까운 도서관 목록 바로 아래 텍스트 링크 추천

도서관 카드들이 끝난 곳에 가는 줄 하나를 긋고 YES24에서 책 정보·구매 보기 ↗를 글자 링크로 둡니다. 아래에 "YES24 사이트로 이동해요" 작은 안내.

누르면 이렇게 이어져요

책 상세 → 아래로 스크롤 → 도서관 목록을 다 본 뒤 링크 → 새 창(웹)/브라우저(앱)에서 YES24 상품 페이지 → 돌아오면 같은 상세 화면.

열어야 보이는 것
  • 도서관 4곳이면 첫 화면 끝(점선) 바로 아래라 조금만 내리면 보여요. 5곳 이상이면 카드 수만큼 더 아래.
  • 도시 전체(20곳+)로 넓히면 그만큼 더 아래로 밀려요.
  • 누르는 동안 "여는 중…"으로 바뀌고, 못 열면 링크 아래에 안내 한 줄.
얻는 것 / 포기하는 것

＋ "근처에서 못 빌리면 → 사러 가기" 순서라 대여 우선(O-16)과 맞고 명세 §1.3 1순위 그대로. 시선을 뺏지 않음.
－ 도시 전체 모드에선 한참 내려가야 보임.

추천 이유: 도서관을 다 확인한 사람이 다음에 할 행동 자리에 놓여, 대출 버튼과 경쟁하지 않으면서도 약관상 "상세에서 연결"을 숨기지 않아요.

B. 상단 판 안, ISBN 줄 아래 작은 링크

표지 옆 제목·저자·출판사·ISBN 줄 바로 아래에 작은 글자 YES24에서 보기 ↗. 두 버튼 위쪽, 첫 화면에 늘 보여요.

누르면 이렇게 이어져요

책 상세 열자마자 보임 → 누르면 바로 YES24 → 돌아오면 같은 상세 화면.

열어야 보이는 것
  • 스크롤 없이 보여요.
  • 좁은 화면에서 긴 제목(2~3줄)이면 표지 옆 칸이 길어져 두 버튼이 약간 내려가요.
얻는 것 / 포기하는 것

＋ 찾기 쉬움. 도서관 개수와 상관없이 같은 자리.
－ 처음 보이는 곳에 "구매"가 들어와 대여 우선 위계가 약해져요. 버튼 두 개와 링크가 가까워 잘못 누를 수 있어요.

C. 머리띠 오른쪽 점 3개(⋯) 메뉴 안

머리띠 오른쪽 ⋯를 누르면 작은 메뉴에 YES24에서 책 정보·구매 보기 ↗ 한 줄. 화면 본문에는 아무것도 늘지 않아요.

누르면 이렇게 이어져요

책 상세 → ⋯ 누름 → 메뉴 → YES24 → 돌아오면 같은 상세 화면(메뉴 닫힘).

열어야 보이는 것
  • 메뉴를 열기 전에는 YES24가 있다는 걸 알 수 없어요.
  • 메뉴 항목은 지금 1개뿐(공유 등은 없음).
얻는 것 / 포기하는 것

＋ 본문이 가장 깔끔. 대출 위계 그대로.
－ "상세에서 연결" 의무를 숨긴 것처럼 보일 수 있어요. 머리띠는 화면 경로 파일(app/books/[isbn13].tsx)도 고쳐야 해 범위가 커져요. 항목 1개짜리 메뉴는 어색해요.

정할 것 ②. 본문 순서 — 도서관 목록과 책 소개 결정 전

채택안(기본 선택): 세 후보 모두 YES24 링크는 ①-A 자리로 그렸어요.

A. 지금 순서 유지: 상단 판 → 가까운 도서관 → (YES24) → 책 소개 추천

지금 화면과 같아요. 도서관 카드는 찾은 만큼 전부 보이고, 책 소개는 맨 아래 전체 글.

누르면 이렇게 이어져요

상세 → 첫 화면에서 가까운 도서관 1~2곳 확인 → 스크롤하며 나머지 도서관 → YES24 링크 → 책 소개.

열어야 보이는 것
  • 도서관 4곳이면 첫 화면에 카드 4곳이 다 보이고, 책 소개는 첫 화면 끝 바로 아래부터.
  • 도시 전체 20곳이면 소개는 훨씬 아래.
얻는 것 / 포기하는 것

＋ "빌릴 수 있나?"가 바로 보임(대여 우선). 확정된 구조·시험 그대로라 고칠 게 적음.
－ 책 내용이 궁금한 사람은 많이 내려가야 함.

추천 이유: 이 앱에서 책 상세에 오는 가장 흔한 이유는 "근처에서 빌릴 수 있나"이고, 그 답이 첫 화면에 남아요.

B. 책 소개 3줄을 상단 판 바로 아래로 (더 보기로 펼침)

상단 판 아래에 책 소개 3줄 + 더 보기. 그 다음 가까운 도서관, 맨 끝에 YES24 링크.

누르면 이렇게 이어져요

상세 → 책 소개 3줄 읽기 → (더 보기 누르면 전체 펼침, 다시 누르면 접힘) → 도서관 → YES24.

열어야 보이는 것
  • 소개가 없는 책은 이 칸이 사라져 A와 같아져요.
  • 첫 화면의 도서관 카드가 약 1곳으로 줄어요.
얻는 것 / 포기하는 것

＋ 어떤 책인지 먼저 알 수 있음(검색에서 처음 본 책에 좋음).
－ 대여 정보가 한 칸 밀림. 펼침 상태가 새로 생겨 시험이 늘어요.

C. 도서관 3곳만 먼저 + "도서관 N곳 더 보기" → YES24 → 책 소개

가까운 도서관은 앞 3곳만 보이고 나머지는 도서관 N곳 더 보기로 펼쳐요. 그래서 YES24 링크와 책 소개가 덜 밀려요.

누르면 이렇게 이어져요

상세 → 도서관 3곳 → (더 보기 → 전부 펼침) → YES24 → 책 소개.

열어야 보이는 것
  • 4번째 이후 도서관은 펼쳐야 보여요(도시 전체 모드에서도 동일).
  • "총 N곳 중 확인 …" 요약 줄은 그대로.
얻는 것 / 포기하는 것

＋ 대여 우선 유지 + 아래 내용이 가까워짐.
－ 빌릴 수 있는 도서관이 4번째 이후면 놓칠 수 있음. 확정된 소장 목록(LIB-2/LIB-3) 동작이 바뀌어 고칠 파일·시험이 가장 많아요.
