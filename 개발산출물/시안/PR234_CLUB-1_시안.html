book-club · CLUB-1 시안 — 방문 페이지의 모임 카드

보는 법. 화면 3개를 비교해 보세요. 휴대폰 안의 "들어가기 →"를 누르면 모임 화면이 열리고, "‹"로 돌아와요. 화면 아래 "일정 미정으로 보기"를 누르면 날짜·장소가 아직 안 정해진 모임이 어떻게 보이는지 바뀌어요. 노란 테두리가 추천이에요. 고르는 건 직접 해 주세요.
이미 정한 것. 모임 카드는 방문 페이지 피드에 게시물 사이로 섞여 나와요. 위가 둥근 아치 모양, 위에 "모임" 알약, 아래 "들어가기 →". 누르면 모임 화면으로 가고, 모임 화면은 맨 위 약속 정보 → 바로 아래 "모임에 참가" → 참가자 → 댓글 순서예요(노트에 적어 둔 것).

정할 것 1. 피드의 모임 카드에서 제일 먼저 눈에 띄는 것 확인

왜 정하나. 피드를 내리던 사람이 이 카드를 보고 "들어가 볼까?"를 정해요. 카드에서 무엇이 제일 크게 보이느냐에 따라 누가 들어오는지가 달라져요. 세 화면 모두 같은 모임이에요.

표준 근거: P-12 알맞은 순간에 한 번 묻는 카드 (지도 "집으로 저장할까요?")

잘 안 될 때 보이는 화면

모임 화면에서 생기는 일이에요. 버튼을 눌러 상태를 바꾸고, 휴대폰 안의 버튼도 눌러 보세요. 바뀌는 곳만 바뀌고 나머지(약속 정보)는 그대로 남아요. 문구는 제가 먼저 넣어 둔 거예요.

처음부터 끝까지 이렇게 써요

  1. 사용자가 방문 페이지 피드를 내리면 동네한권이 게시물 사이에 모임 카드를 보여 준다. 카드에는 날짜·시각이 제일 크게, 그 아래 장소·모임 이름·참가 인원이 보인다(날짜가 미정이면 "날짜 미정").
  2. 사용자가 모임 카드의 "들어가기 →"를 누르면 동네한권이 모임 화면을 연다.
  3. 동네한권이 모임 화면 맨 위에 약속 정보(책·날짜·장소·인원)를, 바로 아래에 "모임에 참가" 버튼을 보여 준다.
  4. 사용자가 "모임에 참가"를 누르면 동네한권이 바로 참가자 명단에 사용자의 닉네임을 넣고 버튼을 "참가 취소"로 바꾼다.
  5. 사용자가 방문 페이지 "+"를 누르고 "모임"을 고르면 동네한권이 모임 만들기 화면을 연다.
  6. 사용자가 한 화면에서 이름(필수)·날짜·장소·책·정원·소개를 위에서부터 채운다. 날짜를 모르면 사용자가 "미정"을 켠다.
  7. 사용자가 "올리기"를 누르면 동네한권이 모임을 만들고 피드 맨 위에 그 모임 카드를 보여 준다.
  8. 만든 사람이 머리 ⋯ → "일정·장소 바꾸기"에서 시작 시각을 바꾸면 동네한권이 이미 참가한 사람의 알림함에 안내를 넣는다.
  9. 참가자가 안내를 누르면 동네한권이 모임 화면을 열고 맨 위에 "시작 시각이 바뀐 모임이에요" 띠를 보여 준다.
  10. 참가자가 모임이 끝나기 전에 "참가 취소"를 누르면 동네한권이 명단에서 빼고, 시작 뒤라도 빠진 것으로 세지 않는다.
  11. 만든 사람이 머리 ⋯ → "모임 취소"에서 이유를 적고 "모임 취소"를 누르면 동네한권이 모임을 "취소된 모임"으로 바꾸고 참가자 알림함에 안내를 넣는다.
