## 4. 환경과 문서 주의

- 계획·요구사항을 바꾸면 `../team/PROJECT.md`·`기능_배정.md`도 같은 차례에 맞춘다(팀원 Claude는 team 쪽을 읽는다).
- 이 PC의 사용자 스킬 `~/.claude/skills/pr-review`는 StockMind 전용이다. 이 레포에서는 `.claude/skills/pr-review`(team 스킬을 가리킴)가 우선한다.
- 규칙을 고친 뒤에는 `../team/tests/규칙_점검/`으로 다시 확인한다(Windows: `PYTHONIOENCODING=utf-8 python ...`).
- Windows에서 서버는 psycopg 비동기를 쓰지 않는다(Proactor 루프 오류, 동기+스레드로 해결). 닫힌 포트 거부가 2초 넘게 걸려 시험은 가짜 소켓을 쓴다. `uv`는 `pip install --user uv` 후 `python -m uv`로 실행(2026-11-12).
- mac 환경에는 `python`이 없고 `python3`만 있다(2026-11-10 기록).
- mac에는 `uv`가 설치돼 있지 않다. 서버 시험은 임시 가상환경에 넣어 돌렸다: `python3.12 -m venv <임시>/uvenv && <임시>/uvenv/bin/pip install uv` → `docker compose up -d --wait db` → `cd server && <임시>/uvenv/bin/uv sync --locked && APP_ENV=test DATABASE_URL=postgresql+psycopg://localone:localone@localhost:5433/localone_test <임시>/uvenv/bin/uv run pytest -W error` (2026-11-13, 18 passed). `server/.venv`는 gitignore다.
- mac의 `/bin/sh`는 `"$base에"`처럼 변수 이름 바로 뒤에 한글이 붙으면 글자가 깨진다. team 스크립트에서는 `${base}에`로 쓴다(2026-11-12).
- 새로 clone한 PC는 코드 레포에서 `git config --local team.role D`, team 폴더에서 push 주소 복구(`git remote set-url --push origin https://github.com/axteamc/team.git`)를 다시 해야 한다. team 도구(`sync.sh`·`notify_junior.sh`)는 `team.ghuser`(이 mac은 `Hunseokc`)로 돌아 gh 전환이 필요 없지만, 직접 치는 `gh` 명령은 여전히 활성 계정을 쓴다(2026-11-12).
