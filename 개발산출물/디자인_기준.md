## 1. 원칙

1. 모던하고 차분하게. 배경은 콘크리트·회반죽 벽 같은 웜 그레이, 따뜻한 간접조명 느낌. 나무 질감·나무색은 쓰지 않는다.
2. 곡률·배색·형태는 Arne Vodder 사이드보드(슬라이딩 도어 색 블록, 렌즈형 손잡이, 아치)에서만 가져온다.
3. 장황한 연출은 없다. 지도 → 도서관은 **페이지가 바뀐 것을 알아볼 수 있는 전환**(옆으로 밀림 + 배경·헤더 변화 + 방문 멘트 카드 한 줄)이면 충분하다. "입장했어요" 문구는 방문 횟수에 따른 멘트 카드로 바꿨다(2026-11-13, C-55, [D 결정 1.2-1](명세/VISIT_LOCAL_D결정.md)).
4. **색과 곡률은 값을 직접 쓰지 말고 토큰으로 쓴다.** 도서관 룩(M2, VISIT-07)이 토큰만 바꿔 끼우기 때문이다. M1에서는 기본 룩(warm) 하나만 쓴다.
5. **색의 최종 조정은 D가 한다(2026-11-16 사용자 결정).** 휴관 핀을 포함한 현행 색은 유지하고, 세밀한 색 조정은 마지막에 D가 캘리브레이션된 디스플레이에서 일괄 수행한다. 색의 미세 차이나 회색 토큰 미정만으로 기획·구현을 막지 않는다. 시안·앱 화면·공통 부품의 스타일에는 HEX·RGB·색 이름을 직접 반복하지 않는다. 실제 색 값은 공통 토큰 정의 한 곳에만 두고 사용처는 토큰 이름으로 참조한다. 필요한 토큰이 없으면 현재 값을 유지하는 의미별 토큰(예: `pin-closed`)을 정의하고 임시값·사용처를 명세에 기록한다. 최종 조정은 토큰 정의를 바꿔 반영하며, 휴관 등의 의미는 문구도 함께 표시한다.
6. **글자와 공간 규칙 7개(2026-11-18 확정, 강도 2단계)**: ① 크기와 무게를 떼어 놓는다(제목 크게·400·`inkSoft`, 700·600 없음, 강조는 크기로) ② 크기 세 단계(제목 22~24 · 본문 14 · 표찰 10~11, 한 화면 4개 이하) ③ 글자는 격자에 기댄다(왼쪽 정렬, 가운데는 축 위의 물체만, 여백 4의 배수) ④ 두 목소리(한글 문장 / 계기판: 작게·자간·500·대문자·`inkMuted`, 한 줄에 섞지 않음) ⑤ 색은 창 안에만(구조는 유리판 무채색, `fill1~3`은 스파인·표지·사진·로고, 버튼은 무광 판) ⑥ (선택) 프레임은 끝이 아니다 ⑦ 무거운 표식은 화면에 하나(홈 기점, 방문 스탬프, 그 밖은 주 버튼). 앱 값은 `mobile/src/theme/index.ts`의 `type`, 자세한 표와 **페이지 적용 레시피**는 [../DESIGN.md](../DESIGN.md).
7. **검정 + 노랑은 로고에만 쓰지 않는다(2026-11-18 D).** 참고 서비스 그믐(검정 바탕 + 노랑 달)과 로고가 겹치지 않게. 앱 화면·버튼에서는 쓸 수 있다(처음 "앱 전체 자제"에서 같은 날 좁힘).

- **웜 온도(C-48)**: warm은 -20%, toffee는 -30%. 모든 색은 원래 값에서 R를 24×n 낮추고 B를 24×n 올린 값이다(warm 4.8, toffee 7.2). 원래 warm은 bg #E6E1D9·fill1 #EEC96B, 원래 toffee는 bg #EBE2D4·fill1 #755139 등이다. 모던(주황)은 제외, Oxford는 이미 차가워 적용하지 않았다. `paper`는 원래 카드 흰색을 `bg` 쪽으로 40% 눌러 순백 느낌을 없앤 값이다.
- 파생: 보조 글자색 = `bg`를 50% 어둡게, 구분선 = `bg`를 13% 어둡게. 본문 글자 `#1D1D1F`.
- **채움 위의 글자색은 자동으로 고른다**(채움색과 흰색·어두운색 중 대비가 큰 쪽). 룩이 바뀌어도 글자가 묻히지 않게 한다.
- 지정 색(모던 #CDCDCB·#FB5102·#1C1E2A, toffee #F5EFE6·#755139, Oxford #002147·#D2B48C)은 사용자가 정했고, 큰 면에서 너무 튀는 곳만 조정했다. Oxford의 큰 면은 #002147보다 한 단계 밝은 #35557F를 쓰고 #002147은 버튼·받침에 쓴다. 모던은 튀어도 된다.
- 색 대비는 시안을 사용자가 보고 확정한다(자동 점검 요구 없음). 접근성(색약 등)은 확정 후 한 번 수치로 확인하길 권한다.
- **2026-11-17 확정(홈 시안 C, 사용자 결정)**: toffee `fill2` #C88A56(캐러멜 앰버)·`fill3` #7E8C7D(올리브 세이지)로 분리해 배경 표면과 겹침을 없앴다. Oxford는 `bg`·`surface2`·`surface3`·`cream`·`paper`를 모던과 같은 무채색으로 통일하고 `fill3`를 #7A93AC로 조정했다. 시안은 외부(웹 Gemini)에서 확인해 확정했고 이 문서가 기록이다. 전체 근거는 [개정 통합본](명세/DESIGN_개정통합본_홈중심_조형시스템.md).
- **파생 색(시안 C 파사드·릴리프)**: `mix(A,B,w)=A×w+B×(1-w)`. `panelFrosted=mix(paper,bg,.58)`, `panelLit=mix(paper,cream,.84)`, `seamHairline=mix(inkStrong,bg,.14)`, `rivetBase=mix(inkStrong,surface3,.34)`, `rivetShine=mix(paper,bg,.9)`, `reliefBottomMid=mix(inkStrong,surface2,.15)`, `reliefSideDark=mix(inkStrong,surface3,.26)`. 값의 원본은 `mobile/src/theme/tokens.ts`의 `DERIVE`와 `index.ts`의 `mix`다(통합본 표와 1~2 차이가 나면 코드 산식이 맞다). 조명·그림자(`seamHighlight`·`shadowAmbient`·`shadowCast`·`shadowDeep`)는 룩과 무관한 고정값이다.
- **색 배정 85:10:5**: 화면의 85%는 무광 배경·블록 윗면, 10%는 구조(`inkStrong`·줄눈·두께면), 5%는 블록 왼쪽 스파인(`fill1~3`, 휴관 `pinClosed`). `inkStrong`으로 꽉 채우는 면은 홈 중앙 + 기점(과 소식 칩·켜짐 아이콘 같은 작은 구조)뿐이다(주 행동 버튼은 `panelLit` + 2px 받침 무광 판). 스파인은 휴관 우선, 가장 가까운 영업 중 도서관 `fill1`, 나머지 `fill2`·`fill3` 교대.

## 5. 문구 규칙 (모든 화면)

- 대출 가능은 항상 **데이터 기준일**과 함께: "어제 기준 · 대출 가능", "어제 기준 · 대출 중". "지금 바로 대출 가능" 같은 단정 문구 금지(02 LIB-03).
- 못 찾았을 때는 "찾지 못했어요"(없다고 단정하지 않음). 응답이 없으면 "알 수 없음 + 다시 시도".
- "실시간 확인"은 외부 도서관 사이트로 이동함을 표시한다(02 LIB-06).
- "읽힌 책·인기 도서"는 대출 가능 표시가 아니다(M2 책장).
