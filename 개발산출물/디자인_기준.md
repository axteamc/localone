# 디자인 기준 (M1 화면 공통)

> 상태: **초안 — 사용자 시안 검토 반영**(2026-11-12, C-48: 웜 온도(warm -20%·toffee -30%)·취향 10% 반영). 요약본은 [../DESIGN.md](../DESIGN.md). 담당: D. 주니어가 `specs/<기능>/시안.html`과 화면을 만들 때 **같은 색·곡률·문구**를 쓰게 하는 기준이다. 화면 하나하나의 구성은 각 기능 명세서가 정한다.
> 기준 시안: [시안/방문_페이지_시안.html](시안/방문_페이지_시안.html)(브라우저로 열면 홈 → 방문 전환, 피드, 책장, 블러, 룩 4종, 웜 온도·태그 후보 비교와 명세 패널을 볼 수 있다). 값은 이 시안과 이 문서가 같아야 하며 다르면 이 문서를 고친다.
> 이유와 결정 기록: [00 O-19~O-38](00_기획_원본.md), [C-13~C-21](스펙_변경_이력.md). Q-29(디자인 토큰)의 1차 정리다.

## 1. 원칙

1. 모던하고 차분하게. 배경은 콘크리트·회반죽 벽 같은 웜 그레이, 따뜻한 간접조명 느낌. 나무 질감·나무색은 쓰지 않는다.
2. 곡률·배색·형태는 Arne Vodder 사이드보드(슬라이딩 도어 색 블록, 렌즈형 손잡이, 아치)에서만 가져온다.
3. 장황한 연출은 없다. 지도 → 도서관은 **페이지가 바뀐 것을 알아볼 수 있는 전환**(옆으로 밀림 + 배경·헤더 변화 + 방문 멘트 카드 한 줄)이면 충분하다. "입장했어요" 문구는 방문 횟수에 따른 멘트 카드로 바꿨다(2026-11-13, C-55, [D 결정 1.2-1](명세/VISIT_LOCAL_D결정.md)).
4. **색과 곡률은 값을 직접 쓰지 말고 토큰으로 쓴다.** 도서관 룩(M2, VISIT-07)이 토큰만 바꿔 끼우기 때문이다. M1에서는 기본 룩(warm) 하나만 쓴다.

## 2. 색 토큰 (룩 4종)

| 토큰 | 모던 | warm(M1 기본) | toffee | Oxford |
| --- | --- | --- | --- | --- |
| 배경 `bg` | #CDCDCB | #E1E1DE | #E4E2DB | #E3E5E8 |
| 선반·시트 `surface2` | #BDBDBA | #D0CEC8 | #D5CFC4 | #D1D5DB |
| 선반 진한색 `surface3` | #A8A8A5 | #BFBCB5 | #C2BBAD | #BCC2CC |
| 채움1 `fill1`(대표색) | #FB5102 | #E9C970 | #6E5140 | #35557F |
| 채움2 `fill2` | #F2F2EF | #EDC9A9 | #D2BE9E | #D2B48C |
| 채움3 `fill3` | #9AA0B4 | #B3BFB5 | #AEA18B | #9DB0C9 |
| 크림 `cream` | #E9E9E6 | #EFEFE7 | #EEEFED | #F3EFE7 |
| 카드 `paper`(순백 아님) | #E6E6E4 | #EFF1F1 | #EEEFED | #F2F3F5 |
| 진한색 `ink-strong`(버튼·받침) | #1C1E2A | #2E333F | #332A27 | #002147 |

- **웜 온도(C-48)**: warm은 -20%, toffee는 -30%. 모든 색은 원래 값에서 R를 24×n 낮추고 B를 24×n 올린 값이다(warm 4.8, toffee 7.2). 원래 warm은 bg #E6E1D9·fill1 #EEC96B, 원래 toffee는 bg #EBE2D4·fill1 #755139 등이다. 모던(주황)은 제외, Oxford는 이미 차가워 적용하지 않았다. `paper`는 원래 카드 흰색을 `bg` 쪽으로 40% 눌러 순백 느낌을 없앤 값이다.
- 파생: 보조 글자색 = `bg`를 50% 어둡게, 구분선 = `bg`를 13% 어둡게. 본문 글자 `#1D1D1F`.
- **채움 위의 글자색은 자동으로 고른다**(채움색과 흰색·어두운색 중 대비가 큰 쪽). 룩이 바뀌어도 글자가 묻히지 않게 한다.
- 지정 색(모던 #CDCDCB·#FB5102·#1C1E2A, toffee #F5EFE6·#755139, Oxford #002147·#D2B48C)은 사용자가 정했고, 큰 면에서 너무 튀는 곳만 조정했다. Oxford의 큰 면은 #002147보다 한 단계 밝은 #35557F를 쓰고 #002147은 버튼·받침에 쓴다. 모던은 튀어도 된다.
- 색 대비는 시안을 사용자가 보고 확정한다(자동 점검 요구 없음). 접근성(색약 등)은 확정 후 한 번 수치로 확인하길 권한다.

## 3. 형태 토큰

| 토큰 | 모던(직각 계열) | 나머지 3룩(아치 계열, M1 기본) |
| --- | --- | --- |
| 카드 곡률 | 6px | 18px |
| 모임 카드 곡률 | 6px | 위 70px·아래 18px (아치) |
| 도서관 아이콘 | 3px | 위 23px·아래 6px (아치) |
| 알약(모임 태그 등) | 6px | 18px |
| 책 표지 | 2·4·4·2px | 5·9·9·5px |
| 선반 아래 | 얇고 납작한 받침 | 도어 블록 3개 + 렌즈형 손잡이 |

- 컨트롤(스탬프 버튼·"열기 ↗")은 완전한 필(9999px). 뒤로가기는 알약 없이 굵은 "‹"(선 3.6) + 은은한 그림자. 목록·카드 안 행동은 텍스트 링크("들어가기 →"). 진한색 채움 강조는 화면에 하나(방문 스탬프 버튼).
- 태그(게시물·방명록·방문 기록)는 배경 없이 점 + 글자(투명도 70%). 모임 태그만 알약.

## 4. 화면 기준

- 기준 화면 390×844, 상태 막대 44, 하단 바 72. 하단 바는 홈·독서 기록·글쓰기·대출·반납·내 정보(내 발자취는 M2에 하단 탭/사이드바 중 결정, Q-44).
- 피드: 2열 메이슨리, 열 간격 10, 좌우 12. **게시물 카드는 제목·본문 없이 이미지만** 두고 글자는 이미지 안에 넣는다(2026-11-12 결정). M1 카드는 게시물 카드만, 방명록·모임·방문 기록 카드는 M2.
- 피드와 책장(M2) 사이: 얇은 블러 띠 72px, 블러 5겹(1·1.5·2.5·3.5·4.5px)이 아래로 갈수록 강해지고 선반색으로 녹는다. 블러가 안 되는 기기는 그라데이션 페이드만. M1 방문 페이지는 책장이 없어도 이 구조가 나중에 붙을 수 있게 만든다.
- 책장(M2): 높이 224, 한 페이지 책 3권(표지 104×150, 저자·제목 크게), 좌우로 넘김.
- 서체: 시안은 Noto Sans KR(400·500·700). **시안 가정이며 앱 번들 때 라이선스·로딩 방식을 확인하고 확정한다.**

## 5. 문구 규칙 (모든 화면)

- 대출 가능은 항상 **데이터 기준일**과 함께: "어제 기준 · 대출 가능", "어제 기준 · 대출 중". "지금 바로 대출 가능" 같은 단정 문구 금지(02 LIB-03).
- 못 찾았을 때는 "찾지 못했어요"(없다고 단정하지 않음). 응답이 없으면 "알 수 없음 + 다시 시도".
- "실시간 확인"은 외부 도서관 사이트로 이동함을 표시한다(02 LIB-06).
- "읽힌 책·인기 도서"는 대출 가능 표시가 아니다(M2 책장).
