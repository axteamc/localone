# 07. 테스트 결과서

> 상태: **골격 — 미작성**. 담당: D(취합), 기능별 결과는 각 담당. 선행: 구현·테스트 실행. 갱신 시점: 기능 단위 PR마다 + 마일스톤 검수 때. 실행하지 않은 것을 통과로 적지 않는다.
> 입력: `../team/contracts/*` §7 테스트 표, `specs/<기능>/명세서.md` §5 예외, 기능별 `verify.md`, [02 AC](02_요구사항_정의서.md).

## 작성할 내용

1. **실행 정보**: 대상 커밋, 환경(격리 DB·OS·앱 실행 환경), 명령, 실행 시각, 도구 버전
2. **분류별 요약**: 분류·건수·통과·실패·미실행
3. **수용 기준(AC) 결과**: AC별 준비·행동·기대·실제·증거 링크 — 02의 AC-AUTH~AC-DELETE 전부
4. **기능 테스트**: 정상·잘못된 입력·없는 ID·빈 데이터·남의 데이터(A↔B)·늦은 응답
5. **플랫폼 확인**: 웹·Android(담당)와 iOS(D)를 따로 기록. 한쪽만 했으면 나머지는 미확인
6. **통합 검증**: 실제 서버·격리 DB 연결 여정(가짜 응답 화면 테스트는 따로 표시)
7. **실패·미실행 목록**과 원인·조치([버그 리포트](버그_리포트.md) 링크)
