- 두 버튼 표시는 가로로 넘길 콘텐츠가 있을 때로 제한한다. 첫 위치에서는 이전, 끝 위치에서는 다음을 비활성화한다. 연속 입력은 범위 안에서만 움직인다. 이전·다음 방향과 초점 표시가 보이고, Tab으로 이동한 후 Enter·Space로 동작하며, 스크린리더에 항목과 방향을 함께 알린다.
- 레이아웃·스크롤 위치·콘텐츠 폭 변화 후 끝 상태를 갱신한다. 최근 본 도서 개별·전체 삭제, 검색 키보드가 열린 상태, 홈 창 높이 변경, 웹 창 크기 변경을 확인한다. 책장 버튼·점·스와이프는 현재 페이지·제목·기준 문구를 함께 갱신한다. 도서관을 바꾸면 첫 장으로 간다. 빈 상태와 한 장 상태에는 화살표가 없다.
- 웹 버튼은 공통 플랫폼 분기에서 제공하고 네이티브 기존 제스처를 유지한다. 최근 본 도서의 저장·삭제 계약 및 책장 묶음 순서·넘김 단위는 현행을 따른다. [서가 테마 초안의 페이지당 최대 4권](M2-0_서가테마_계약개정_초안.md#5-승인-결정과-시연-기준)은 별도 반영 기준이다.

## 4. 홈 소식의 지역 보충

### 화면 동작

1. 사용자가 도서관 필을 누르거나 단골 첫째 필이 자동으로 선택되면 해당 도서관을 기준으로 보충을 요청한다. 위치·단골 변경으로 기준이 바뀌면 이전 선택의 첫 조회·추가 페이지·오류 응답을 폐기한다.
2. 방문 기록이 없을 때는 현행 가까운 후보 최대 세 곳을 기존 순서로 자체 글만 조회한다. **자체 글이 있는 첫 후보**가 자동 선택되고, 그 도서관 자체 글이 6개 미만이면 선택 이후 보충한다. 앞선 빈 후보의 지역 글이 다음 후보의 자체 글을 앞서지 않는다.
3. 모든 후보가 성공적으로 비었을 때만 후보 첫째(위치가 있으면 가장 가까운 곳, 위치를 못 쓰면 현행 지역 기준 첫 곳)를 기준으로 보충을 요청한다. 보충 글이 있으면 기준 필을 켠다. 전부 비면 기존 미선택 상태와 `가까운 도서관에도 아직 게시물이 없어요.`를 유지한다. 후보가 하나도 없으면 조회 없이 같은 빈 상태를 사용한다.
4. 명시 선택의 전 범위가 비었으면 `<도서관명>에는 아직 게시물이 없어요.`를 사용한다. 조회 실패는 빈 후보로 넘기지 않고 기존 소식 오류와 새로고침을 표시한다. 다음 페이지 오류에는 보던 카드와 커서를 유지해 다시 시도한다. 인기 도서 상태에는 영향을 주지 않는다.
5. 다른 도서관에서 온 글(`post.library_id !== activeId`)에만 카드 오른쪽 위에 짧은 도서관 이름으로 된 정보용 필을 붙인다. 좁은 카드에서는 한 줄 말줄임하며 접근성 이름에는 전체 `library_name`을 제공한다. 이름 단축의 기본값은 표시 문자열 한 줄 말줄임이다. 포커스나 클릭을 가져가지 않으며 메뉴와 상세 이동을 가리지 않는다. 홈에서만 표시 옵션을 넘긴다.

### #26 계약 개정안

| 계약 항목 | 규칙 |
| --- | --- |
| 경로·인증 | `GET /api/v1/libraries/{library_id}/posts`, 선택 인증. `expand=region`을 홈 첫 조회 전용 선택 쿼리로 추가. 생략 시 해당 도서관의 공개 글만 반환 |
| 유효성 | `sort=latest`, `limit` 기본 20·범위 1~50. `expand` 미지원 값은 `422 VALIDATION_ERROR`, `detail="expand"`. 빈 커서는 기존처럼 첫 조회로 해석한다. 유효한 다음 커서에 `expand=region`을 함께 보내면 `422 VALIDATION_ERROR`, `detail="expand"`. 커서 자체가 깨진 경우 기존 `detail="cursor"`를 적용한다. 없는 도서관은 기존 `404 NOT_FOUND` |
| 최소 채움 | 첫 응답의 자체 글 전부(기존 페이지 최대치) → 동일한 비어 있지 않은 `dtl_region_code`의 다른 도서관 → 동일한 비어 있지 않은 `region_code`의 다른 도서관 순. 보충 목표는 `min(6, limit)`, 두 단계 모두 부족분만 가져온다. `region_code`가 같은 광역시·시도 전체가 대상이며 도 지역은 다른 시·군도 포함한다 |
| 정렬·중복 | 범위마다 `published_at DESC, id DESC`. 자체 도서관은 두 보충 단계에서 제외한다. 시·도 단계는 이미 반환한 ID를 제외하고 부족분만 반환한다. 지역 코드가 비어 있으면 해당 단계만 건너뛴다. 전체가 부족하면 있는 공개 글만 반환한다 |
| 페이지 | `FeedPage`와 `FeedPost` 형태를 유지하고 기존 `library_id`·`library_name`으로 출처를 판단한다. 자체 글에 다음 페이지가 있을 때만 기존 `(published_at, id)` 커서를 반환한다. 이어받기는 보충 옵션 없이 자체 글만 받으며, 보충 글의 ID가 커서에 들어가지 않는다. 클라이언트도 ID 기준 중복 제거와 같은 커서 중복 호출 방지를 적용한다 |
| 범위·권한 | `published`만 반환하고 기존 로그인 여부별 공감·북마크 플래그와 철회·숨김 처리를 유지한다. 홈은 #26을 쓰고 상세의 ‘이 도서관의 다른 글’은 보충 없는 #26, 방문 혼합 피드는 #32를 쓴다. #32는 선택 도서관의 콘텐츠로 제한한다 |

- 수용 기준은 자체 글 6개 이상·6개 미만·0개, 같은 구 소진 후 같은 도 타 시·군, 코드 누락, 타 시·도 제외, 타임스탬프 동률, 철회·숨김 제외, 기본 #26 호출자 호환, 로딩 중 필 전환, 자체 페이지 없음일 때 추가 호출 없음, 보충 글 필과 상세 이동이다.

## 5. 광주 시연 데이터

### 대상 도서관

- 승인한 기본 범위는 광주광역시 동구 `24010`·남구 `24030`·북구 `24040`의 카탈로그 전체다. 최소 포함 관은 아래 표와 무등 인근이다. 중흥은 한 곳으로 센다.

| 구 | 최소 포함 도서관 |
| --- | --- |
| 동구 | 계림꿈나무도서관, 광주 중앙도서관, 광주 산수도서관 |

| 북구 | 광주 중흥도서관, 광주 무등도서관 |

- **시연 범위 세부 기본값**은 무등도서관 좌표에서 현재 홈 기본 반경인 **3 km** 이내의 광주광역시 카탈로그 도서관을 구 경계를 넘어 합치는 것이다. 현행 주변 조회 거리 기준을 재사용한다. 구 전체·필수 관·무등 인근을 합집합으로 계산하고 `provider_lib_code`로 중복 제거한다. 필수 관의 코드는 실제 카탈로그에서 사전 확정한다. 이름 변형·동명은 구 코드와 주소로 식별하고, 누락·모호한 필수 관 또는 무등 좌표 누락이면 쓰기 전 중단한다. 실행 전 대상 코드를 목록으로 확인한다.

- 안정적인 시연 계정과 `provider_lib_code + 콘텐츠 종류 + 슬롯 번호`로부터 같은 `client_request_id`를 정한다. `posts`·`guestbook_entries`는 사용자와 요청 ID, `clubs`는 호스트와 요청 ID의 기존 고유 제약을 사용한다. 이미 있는 시연 행은 보존하며 철회·숨김·취소한 행도 되살리지 않는다. 시각은 최초 삽입 시에만 정한다. 도서관별 7개 레코드는 하나의 데이터 묶음으로 삽입하고 실패 시 롤백한다. 결과에는 대상·삽입·기존·실패 건수를 종류별로 남긴다.
- 기준 리비전에서 `clubs` 테이블은 존재하고 #32는 `post`·`guestbook`을 반환한다. 모임 **시드 저장 검증**과 **방문 피드·모임 상세에서 눌러보는 검증**은 구분한다. 화면 검증에는 CLUB-1의 `kind=club` 연결이 필요하다.
- 수용 기준은 필수 관과 무등 인근 포함, 관별 5/1/1, 두 번째 실행 신규 0건, 기존 데이터·상태 보존, 게시물·방명록·모임 표면별 표시다. 구·시도 확장 및 전체 빈 상태는 시연 데이터와 격리된 검증 데이터로 확인한다.
- 근거 `server/app/seed.py:1–32`, `server/app/services/provider_engine.py:213–226`, 마이그레이션 `0004_posts.py`·`0012_m2_targets.py`·`0016_guestbook_constraints.py`, `book-club` CLUB-1, `feed.py:219,271–305`.
