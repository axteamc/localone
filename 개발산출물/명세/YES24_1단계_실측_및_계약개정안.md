## 2. 실측 결과 (키 길이 56, 값은 기록하지 않음. 호출 약 45회 사용)

실측 스크립트: 세션 scratch(`probe*.py`, 저장소 밖). 모든 호출은 `https://apis.yes24.com`.

### 2.1 인증·한도 (Y-1)

| 호출 | 결과 |
| --- | --- |
| 헤더 `X-Api-Key: <키>` | `200` |
| 헤더 없음 | `401 {"success":false,"message":"API Key 값이 없습니다.","data":null,"errorCode":"AUTH_001"}` |
| 잘못된 키 | `401 ... "유효하지 않은 API Key입니다." errorCode AUTH_002` |
| 쿼리 `apiKey`/`api_key`/`key` | `401 AUTH_001` (쿼리 방식 불가) |
| 응답 헤더 | `x-ratelimit-limit-second: 10`, `x-ratelimit-limit-day: 20000` (+`remaining`/`reset`) |

### 2.2 오류 응답 (전수 관측)

| 요청 | HTTP | `errorCode` | 서버 처리 |
| --- | :---: | --- | --- |
| `pageSize=101` 또는 `0` | 400 | `PARAM_006` | `ProviderError`(코드 버그) |
| `categoryId=` 빈 값 | 400 | `PARAM_001` | `ProviderError` |
| goods `query` 누락 | 400 | `PARAM_003` | `ProviderError` |
| `searchType=ISBN` (잘못된 값) | 400 | `PARAM_004` | `ProviderError` |
| `categoryId=999`/`abc` | 404 | `BEST_001` | `no_data`(캐시 보호) |
| 미존재 ISBN13 | 404 | `GOODS_002` | `#15` 검색 폴백 |
| `page=0` | **500** | `INTERNAL_ERROR` | `ProviderError` — `page`는 항상 1 이상 고정 |
| 키 오류 | 401 | `AUTH_001`/`AUTH_002` | `ProviderError` + 경고 로그(키·응답 원문 미노출) |

모든 오류 envelope: `{"success":false,"message":"...","data":null,"errorCode":"..."}`.

### 2.3 카테고리·스테디셀러 (Y-3)

- `GET /v1/category/list`: 응답 232,900바이트(≈228KB), 1,361건(3자리 5·9자리 113·12자리 1,243), 필드 `categoryId`·`categoryName`·`categoryFullPath`·`categoryUrl`. **런타임 호출 불필요**(정책 상수 `001` 고정). 서버 `max_bytes` 한도는 2MB 유지.
- `bestsellerSteady`/`bestseller` `pageSize=100` 정상(`totalCount` 최대 1,000). 항목 `sortOrder` 1..100 연속.
- `001` 스테디셀러 100권 분포: 소설/시/희곡 33·인문 19·에세이 9·국어 외국어 사전 9·경제 경영 7·자기계발 7·청소년 4·어린이 3·유아 2·수험서 2·사회 정치 2·기타 3. 성인물 `adultYn=Y` 0건, ISBN13 누락·무효 0건, 중복 ISBN 0건, `cover`·`link` 전부 유효, `publishDate` 전부 8자리.
- 종합 베스트셀러(`bestseller`) 100권에는 중복 ISBN 1건·`예약판매`·`일시품절`·수험서 6건 포함 → 필터·중복 제거 필수.
- 만화/라이트노벨(`001001008`) 베스트셀러에서 `adultYn=Y` 3건 관측(성인물 가드 필요성 실증), `goodsType="만화"`.
- 결론: **`001` 스테디셀러 + 서버 필터(`goodsType="도서"`, `adultYn!="Y"`, 어린이·유아·참고서·수험서·대학교재·사전·전집·잡지·만화 분류 제외)**. 세부 카테고리 `001001046`(소설)·`001001047`(에세이)·`001001019`(인문)·`001001025`(경제경영)·`001001026`(자기계발)·`001001010`(역사)는 모두 호출 성공했고 `001`과 14/20 겹침 → 후속 서가 테마 확장용으로만 예약.

### 2.4 Goods API (Y-5)
