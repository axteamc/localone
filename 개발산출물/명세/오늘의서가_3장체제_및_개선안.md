## 1. 배경 및 목적

- 현재 방문 책장(`#31 GET /libraries/{library_id}/shelf`)의 `recent_reads`(“요즘 사람들이 읽은 책”)는 앱 내 반납 집계(`library_return_stats`)를 사용하나, `RETURN_STATS_WRITE_ENABLED = False`(Q-49 보류) 상태로 인해 실제 데이터가 쌓이지 않아 항상 생략된다.
- 일반/전국 추천(`#9 /books/recommendations`)에서는 이미 **YES24 API(`curated_books`)**를 활용하고 있으므로, 도서관 방문 책장에서도 이를 **`인기 도서`**로 배치하고, 기존 `popular`에 구현되어 있던 **정보나루 도서관별 인기대출 도서 API(`loanItemSrchByLib` + 만화·시리즈 제외)**를 **`최근 대출 도서`**로 재활용해 **3장 체제**를 구성한다.
- 아울러 실기기/웹 검수에서 발견된 **헤더 정렬·통일, 모임 카드 통합, 방문 화면 상단 압축, 모임 날짜/시간 선택기, 웹 하단 모달 폭 오류 및 `+` 버튼 팝오버화** 등 6개 UI/UX 개선사항을 함께 정리한다.

## 2. 오늘의 서가(#31) 3장 체제 개편 (개선 항목 #6 포함)

노출 순서: **① `화제의 책` → ② `{테마 이름}` → ③ `요즘 사람들이 읽고 간 책`** *(2026-11-25 C-94 이름 변경: 이전 인기 도서·최근 대출 도서)*  
공통 규칙: 각 장 최대 4권(`SHELF_BOOKS_PER_PAGE = 4`), 데이터가 없는 장은 생략, 세 장 모두 비면 `200 {"pages": []}` 및 기존 빈 책장 안내 유지.

| 순서 | `kind` | 좌측 제목 (`title`) | 우측 출처 표기 (`basis_label`) | 데이터 출처 및 로직 |
| :--- | :--- | :--- | :--- | :--- |
| ① | `popular` | `"화제의 책"` *(C-94, 이전: 인기 도서)* | `"YES24 베스트셀러"` *(우측 기준 문구 자리 동일 양식)* | **YES24 큐레이션 API** (`ProviderEngine.curated_books`, `list_kind="bestseller"`, KST 일 1회 캐시) 상위 최대 4권 |
| ② | `theme` | `"{테마 이름}"` | 테마의 `basis_label`(C-94, 운영자가 적음 — 예 `"YES24 스테디셀러"`, 없으면 `null`) | **운영자 서가 테마** (`looks.py:theme_page` 현행 유지 — 전용→공통, `priority ASC, id ASC`, 배치 소장 스냅샷 72시간 TTL 확인) 최대 4권 |
| ③ | `recent_reads` | `"요즘 사람들이 읽고 간 책"` *(C-94, 이전: 최근 대출 도서)* | `"{도서관명} · 최근 30일 대출"` *(현행 유지)* | **정보나루 도서관별 인기대출 도서 API (`loanItemSrchByLib`)** 최근 30일 호출 결과(기존 `popular_page` + `shelf_popular_books` 만화·시리즈 제외 필터 그대로 재활용), 최대 4권 |

### 정보나루 Open API 매뉴얼(v20260620) 대조 확인

1. **사용 API: 매뉴얼 28~31p §9 `loanItemSrchByLib` (현행 코드 유지)**
   - 매뉴얼 36~37p `hotTrend`(대출 급상승 도서)는 `libCode`·`startDt`/`endDt`·`kdc` 파라미터가 없는 전국 단위 API이므로, 이미 구현된 **28~31p `loanItemSrchByLib`**를 그대로 사용한다.
2. **대출기간: 최근 30일(한 달 이내) 유지**
   - 현행 `POPULAR_PERIOD_DAYS = 30`(`end = today - 1일`, `start = end - 29일`)을 유지한다.
   - 매뉴얼 30p의 `* 최소 3 개월 이상의 대출기간을 검색조건으로 입력해야 양질의 데이터를 제공받을 수 있습니다.` 주석에 따라, 일부 도서관에서 30일 데이터가 `no_data`일 경우 전국 폴백 없이 해당 장(`recent_reads`)만 생략한다.
3. **만화책·시리즈 제외: 현행 후처리 필터 유지 (`kdc` 미사용)**
   - 매뉴얼 59~62p의 대주제(`kdc`: `0`~`9`)와 세부주제(`dtl_kdc`: `00`~`99`)에는 만화책·시리즈를 분리할 수 있는 코드가 없다.
   - 기존 `looks.py:156-168`(`shelf_popular_books`)의 **`class_nm` 만화 분류명 제외 + 운영 제외 목록(`SHELF_POPULAR_EXCLUDED_SERIES`, `SHELF_POPULAR_EXCLUDED_ISBNS`) 필터**를 그대로 유지한다.

## 3. UI/UX 추가 개선사항 (항목 #1 ~ #5)

### 개선 1. 전 페이지 헤더 `<` 버튼 정렬 수정 및 영문 기본 헤더 디자인 통일

- **문제 현황 (첨부 스크린샷 확인)**
  - 모임 상세(`< 모임`), 도서관 방문 축소 헤더(`< 전남광주통합특별시교육청중앙도서관`) 등 다수 화면에서 `<`(뒤로가기) 버튼과 헤더 제목의 수직 중앙 정렬이 어긋나 있음.
- **개선 방향**
  - 앱 전체 화면의 헤더를 **전수조사**하여 `<` 버튼·제목·우측 액션 간 수직 정렬 깨짐을 모두 해결.
  - 헤더 디자인을 하단 탭 기본 헤더(`H O M E` — 자간 넓은 영문 대문자 캡스 스타일, [HeaderLabel.tsx](file:///c:/seokhunchoi_Ax_Fullstack/libproject/mobile/src/theme/HeaderLabel.tsx)) 기반의 **영어 기반 디자인**으로 통일.
  - `<` 뒤로가기 버튼도 해당 타이포그래피·선 굵기와 통일감 있게 개선하되, **필(pill)이나 원(circle)으로 감싸는 형태는 최대한 자제**하고 깔끔한 선/아이콘 형태로 유지.
- **참고 위치**
  - `mobile/src/theme/HeaderLabel.tsx`, `mobile/app/**/_layout.tsx`, `mobile/src/features/local-feed/VisitHeader.tsx`, `mobile/src/features/book-club/ClubScreen.tsx`, `mobile/src/features/book-club/ClubEditor.tsx` 등 전체 Stack/Custom 헤더 전수 대상.

### 개선 2. SNS 피드 내 모임 카드 디자인을 방명록 카드와 통합

- **문제 현황 (첨부 스크린샷 확인)**
  - 현재 방문 피드(SNS)에서 **모임 카드**만 주황/살구색 배경 + 상단 큰 아치형 곡률 + 흰색 필(pill) `모임` 배지로 이질적인 별도 디자인을 사용 중.
- **개선 방향**
  - 모임 카드의 별도 아치형·주황색 디자인과 **필 `모임` 배지를 제거**하고, **방명록 카드([GuestbookCard.tsx](file:///c:/seokhunchoi_Ax_Fullstack/libproject/mobile/src/features/local-feed/GuestbookCard.tsx))와 동일한 카드 디자인**으로 통합.
  - 상단 태그도 방명록과 동일한 **"점 + 글자"(예: `● 모임`)** 스타일, 동일한 카드 곡률(`radii.infoCard`)·바탕색·테두리·여백 규칙으로 통일.
- **참고 위치**
  - `mobile/src/features/book-club/ClubCard.tsx`, `mobile/src/features/local-feed/GuestbookCard.tsx`
  - 계약: `../team/contracts/book-club.md` (모임 카드 조형), `../team/contracts/local-feed.md` (V3-10 태그·곡률 규칙)

### 개선 3. 도서관 방문 화면 상단 압축 및 SNS 피드 영역 확대

- **문제 현황 (첨부 스크린샷 확인)**
  - 도서관 방문 화면 상단에 `"이 도서관 이야기"` 섹션 제목 줄이 별도로 차지하고 있으며, `"오늘 다녀감 · 나만 보기 ▼"`가 그 줄 우측에 배치되어 세로 공간을 불필요하게 사용함.
- **개선 방향**
  - 불필요한 `"이 도서관 이야기"` 문구 줄을 **제거**.
  - `"오늘 다녀감 · 나만 보기 ▼"` 컨트롤을 바로 위 메타 정보 줄(`276M · 09:00~18:00`)의 **우측으로 올려 같은 행에 배치**(첨부 합성 이미지 기준).
  - 상단에서 확보된 세로 공간만큼 **SNS 피드 섹션 영역을 위로 확장**.
- **참고 위치**
  - `mobile/src/features/local-feed/VisitHeader.tsx`, `mobile/src/features/local-feed/VisitScreen.tsx`

### 개선 4. 모임 만들기 날짜·시간 입력 UI 개선 (팝오버 캘린더·시/분 스크롤 휠 + 직접 입력) `[시안 1-A 확정]`

- **문제 현황 (첨부 스크린샷 확인)**
  - 모임 만들기([ClubEditor.tsx](file:///c:/seokhunchoi_Ax_Fullstack/libproject/mobile/src/features/book-club/ClubEditor.tsx))의 `날짜·시각 · 선택` 영역이 단순 텍스트 입력 칸(`2026-11-27` / `14:00`)으로만 되어 있어 입력이 불편함.
- **확정 방향 (시안 `#el-datetime` 후보 A 채택)**
  - 날짜·시간 입력 칸을 누르면 **칸 바로 아래에 작은 팝오버**가 열림: 날짜는 작은 월간 캘린더, 시간은 **길어지지 않는 콤팩트한 2열 `시 | 분` 스크롤 휠(5분 단위)**로 선택.
  - 선택기 사용뿐 아니라 **기존처럼 직접 텍스트 작성(타이핑)도 병행 가능**하도록 유지.
  - 각 입력 칸 끝에는 이모지가 아니라 **앱 디자인 기조에 맞춘 단색 선형 아이콘(달력·시계, 클릭 가능)**을 표기.
- **참고 위치**
  - `mobile/src/features/book-club/ClubEditor.tsx`, `mobile/src/features/book-club/NextClubSheet.tsx` (다음 모임 일정에도 동일 컴포넌트 재사용 검토)
  - 시안: [오늘의서가_UI개선_시안.html](../시안/오늘의서가_UI개선_시안.html) `#el-datetime`

### 개선 5. 웹 하단 모달 전체 폭 펼침 수정 및 SNS `+` 버튼·팝오버 메뉴 개선 `[시안 2-A 확정]`

- **문제 현황 (첨부 스크린샷 확인)**
  - 웹 환경(넓은 브라우저 화면)에서 SNS 화면 `+` 버튼을 눌렀을 때 뜨는 `"무엇을 올릴까요?"` 하단 모달이 모바일 앱 프레임 폭이 아니라 **브라우저 전체 폭(100vw)**으로 펼쳐져 표시됨.
  - 다른 하단 모달(방명록 메뉴, 삭제 확인창 등)에서도 동일한 `Modal` 전체 폭 펼침 현상이 발생하는지 전수 확인 필요.
- **확정 방향 (시안 `#el-compose` 후보 A 채택)**
  1. **하단 모달 폭 전수 점검·수정:** 앱 내 모든 하단 시트/모달이 웹에서도 모바일 컨테이너 최대 폭 안에 자연스럽게 정렬되도록 공통 래퍼/최대 폭 제약 점검.
  2. **SNS `+` 버튼 디자인 개선:** 책장의 가로 넘김 `>` 버튼([HorizontalArrows.tsx](file:///c:/seokhunchoi_Ax_Fullstack/libproject/mobile/src/lib/HorizontalArrows.tsx)의 `GlassArrows` — 유리 원 버튼 스타일)을 참조하여 `+` 버튼 디자인을 통일감 있게 수정.
  3. **`+` 버튼 클릭 메뉴 → 바로 위 2항목 팝오버 카드 전환:** 하단 전체 모달 대신 `+` 버튼 바로 위에 뜨는 둥근 팝오버(`게시물 올리기 / 모임 만들기` 2항목)로 변경하고, **`방명록 남기기`는 `+` 팝오버에서 제거**한다.
  4. **방명록–방문 스탬프 통합 확정:** 최초 기획 의도대로 방문 스탬프와 방명록을 하나의 방문 기록으로 통합한다.
     - **4가지 상태 지원:** `비공개(본문 없음)` / `비공개(본문 있음)` / `공개(본문 없음)` / `공개(본문 있음)`.
     - **진입점 통합:** 상단 `"오늘 다녀감 · 나만 보기 ▾"`(또는 `"피드에 공개 ▾"`) 삼각형 드롭다운 메뉴 안에 공개 범위 전환과 함께 **`한마디 남기기 / 수정` 버튼**을 제공하여 글을 추가·수정할 수 있게 한다.
     - **백엔드·계약 확장 포인트:** 스탬프(`visit_stamps` / `#35`·`#36`)에 선택적 본문 필드(`body`, 최대 140자) 추가 및 수정 허용, 피드 노출 시 `StampCard`에 본문 표시(기존 방명록 카드와 통합).
