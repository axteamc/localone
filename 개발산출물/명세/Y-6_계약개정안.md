## 2. `#70 POST /api/v1/me/loan-plans/availability`

### 2.1 요청

| 필드 | 타입 | 필수 | 규칙 |
| :--- | :--- | :--- | :--- |
| `plan_ids` | `str(UUID)[]` | N | 생략 또는 `null` = 내 활성(`planned`) 예정 전체(미지정 포함). 주면 1~50개, 중복 불가 |
| `lat`, `lng` | `float` | Y | `#12`와 같은 범위 검사 |
| `radius_km` | `int` | N | `#12`와 같은 `check_radius`(기본값 동일) |
| 그 밖 | — | — | 무시(`#17`과 같음) |

- 서버는 예정에서 `book_id`→`isbn13`을 뽑아 **중복 제거**한다. 순서는 예정 `created_at DESC, id DESC`의 첫 등장 순.
- 서로 다른 ISBN이 **20권을 넘으면 `422 VALIDATION_ERROR`, `detail="plan_ids"`**. `plan_ids`를 생략했는데 활성 예정의 ISBN이 20권을 넘어도 같다.
- 남의 예정·없는 예정·`planned`가 아닌 예정이 하나라도 있으면 `404 NOT_FOUND`, `detail="plan_ids"`(소유 은닉, `#18`과 같은 방식).
- 활성 예정이 0건이면 `200` + 빈 결과(`complete = true`).

### 2.2 처리 순서

1. 인증 → 형식 검사 → DB 읽기(예정·책, `user_id = :uid`) → `libraries_nearby(lat, lng, radius)`. **외부 호출은 트랜잭션 밖**(기존 규칙).
2. 주변 도서관이 0곳이면 `200`, `candidates = []`, `complete = true`.
3. 엔진 `bulk_availability(isbn13s, libraries_with_distance)`:
   - **오늘 관측 먼저**: 모든 (도서관, ISBN) 쌍에 오늘(`observed_on == 서울 오늘`) `bookExist` 관측이 있으면 그 `holding`·`loanable`을 확정값으로 쓴다.
   - **① 소장 1차(`libSrchByBook`)**: ISBN 순서대로, 주변 도서관의 서로 다른 `region_code`(시·도 2자리)마다, 그 지역 쌍 중 오늘 관측이 없는 것이 남아 있으면 `holdings_page(isbn13, region, page, 100)`를 끝 페이지까지 부른다. 기존 `sync_theme_holdings`의 페이지 무결성 검사(총건수·크기·누락·중복)를 그대로 적용한다.
     - 모든 페이지를 받으면 그 지역 도서관 중 목록에 있는 곳은 `holding = "yes"`, `loanable = "unknown"`, 없는 곳은 `holding = "no"`.
     - 중간에 실패하거나 한도에 걸리면 그 ISBN·지역의 미확정 쌍은 전부 `unknown`(`fallback_reason = "provider_error" | "limit"`). 일부 페이지 결과로 `no`를 단정하지 않는다.
     - 응답의 도서관 코드 중 우리 `libraries`에 없는 것은 무시한다.
     - ① 결과는 **요청 안에서만** 쓰고 저장하지 않는다(`기본값(Claude)`: `availability_observations`는 `bookExist` 관측만 저장해 단일 조회 의미를 지킨다).
   - **② 대출 가능(`bookExist`)**: ①·오늘 관측까지 반영한 임시 순위(소장 권수 ↓ → 거리 ↑ → ID ↑)로 도서관을 줄 세우고, 앞에서부터 `holding = "yes"`이면서 `loanable = "unknown"`인 쌍을 남은 예산 안에서 부른다. 성공한 결과는 기존 `_store_observations`로 저장한다(단일 조회와 같은 하루 1회 규칙).
   - **예산**: ①의 페이지 호출과 ②의 호출을 합쳐 **요청당 40건**, 동시 8건(`AVAILABILITY_MAX_CALLS_PER_REQUEST`·`AVAILABILITY_MAX_CONCURRENCY` 재사용). 예산이 떨어진 뒤의 쌍은 `fallback_reason = "limit"`. `ProviderLimitReached`(일 한도)도 `limit`. 제공자 미설정은 `not_configured`.
4. **최종 순위**: `holding_count ≥ 1`인 도서관만 후보. 소장 권수 ↓ → 대출 가능 권수 ↓ → 거리 ↑(없으면 뒤) → ID ↑로 최대 3곳(`BATCH_AVAILABILITY_TOP_LIBRARIES = 3`)을 고르고, 응답에는 거리 ↑(없으면 뒤) → ID ↑ 순으로 담는다.

### 2.3 응답 `200`

```text
{
  checked_at: str(ISO +09:00),
  radius_km: int,
  complete: bool,                 // 주변 도서관 × ISBN 모든 쌍의 holding이 yes/no로 확정됐으면 true
  unknown_pairs: int,             // holding이 unknown인 쌍 수
  fallback_counts: { limit: int, provider_error: int, not_configured: int },
  books: [ { isbn13: str, plan_ids: str[], status: "held" | "not_held" | "unknown" } ],
  candidates: [                   // 0~3곳, 표시 순서(거리순)
    {
      library: { id, name, address, area_label, distance_m, today, tel, homepage },
      holding_count: int,
      loanable_count: int,        // loanable == "yes"로 확인된 권수만
      held_isbn13s: str[],
      loanable_isbn13s: str[],
      link: { url: str, kind: "homepage" } | null
    }
  ]
}
```

- `books[].status`: 주변 도서관 중 한 곳이라도 `holding = "yes"`이면 `held`, 모든 도서관이 `no`로 확정이면 `not_held`, 그 밖은 `unknown`. **`unknown`을 `not_held`로 보지 않는다**(구매 버튼 조건, §5).
- `library` 칸은 `#12`의 `library`(`library_summary`) + `homepage`(`fix_homepage` 적용값). 여러 ISBN을 대표하므로 `live_check`(ISBN 검색 주소) 대신 `link`에 도서관 홈페이지를 준다. 홈페이지가 없으면 `null`.

### 2.4 오류

| 경우 | 응답 | 앱 문구 |
| :--- | :--- | :--- |
| 비로그인 | `401` | 기존 로그인 안내 |
| 형식(`plan_ids` UUID·중복·개수, `lat`·`lng`·`radius_km`) | `422 VALIDATION_ERROR`, `detail` 필드명 | "조회하지 못했어요. 다시 시도해 주세요." |
| ISBN 20권 초과 | `422 VALIDATION_ERROR`, `detail="plan_ids"` | "한 번에 20권까지 조회할 수 있어요. 책을 골라 주세요." |
| 남의·없는·활성 아닌 예정 | `404 NOT_FOUND`, `detail="plan_ids"` | "이미 바뀐 내용이에요. 목록을 새로 고쳤어요." + `#16` 재조회 |
| 제공자 오류·한도·미설정 | **`200`** + `unknown`·`complete=false` | "일부 도서관만 확인했어요." + "다시 조회" |
| DB 오류 | 기존 공통 envelope(5xx) | "조회하지 못했어요. 다시 시도해 주세요." |

## 4. 일괄 빌림 (`#20` 재사용)

| # | 규칙 |
| :--- | :--- |
| B1 | 새 API를 만들지 않는다. 선택한 예정마다 `#20 POST /api/v1/me/loans`를 `plan_id`와 함께 **순차로** 부른다(`기본값(Claude)`: 같은 사용자 잠금 경쟁을 피한다) |
