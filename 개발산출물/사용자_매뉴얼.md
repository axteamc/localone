# 사용자 매뉴얼

> 상태: **골격 — 미작성**. 담당: D + 기능 담당. 선행: M1 이후 실제 화면이 있어야 함(스크린샷 필요). 갱신·작성 시점: 마일스톤 공개 전, 화면 변경 때.
> 입력: [02 요구사항](02_요구사항_정의서.md), [유저 플로우](유저_플로우.md), 실제 앱 화면

## 작성할 내용

1. 설치·가입·로그인(소셜 로그인, 로그아웃, 탈퇴)
2. 도서 찾기와 도서관의 소장·대출 가능 보기("알 수 없음"·조회 시각의 의미, 대출 가능 정보는 전날 기준일 수 있음)
3. 빌릴 예정 담기(도서관 예약이 아님)
4. 대출 등록과 반납 알림(알림 받는 법, 푸시를 거부했을 때, 기한 수정·반납 처리)
5. 독서 기록과 서재, 공개 카드 올리기·철회
6. 위치 권한·카메라 권한 안내와 거부했을 때 쓰는 법
7. 자주 묻는 질문·문제 해결, 신고 방법
