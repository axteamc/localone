## 3. 하는 방법 (맥, 무료 Apple 계정 — 처음 할 때 공식 문서로 확인)

- **iOS(미확인):** 맥에서 레포를 `git pull` → `cd mobile && npm ci` → `npx expo prebuild -p ios` → Xcode로 `ios/` 열기 → Signing에서 개인(무료) 팀 선택 → 아이폰을 케이블로 연결해 실행. 처음엔 아이폰 설정에서 개발자 앱 신뢰가 필요하다. 무료 서명은 7일 만료·앱 개수 제한이 있다고 알려져 있다. SideStore 경로는 쓰지 않는다(맥에서 직접 설치가 더 짧다). 번들 ID가 `kr.localone.app`으로 등록되지 않으면 임시로 바꿔야 할 수 있는데, 그때는 Supabase 복귀 주소 허용 목록에 영향이 없는지 본다(Google 로그인은 `localone://` 복귀라 번들 ID와 무관할 것으로 봄, 미확인).
- **iOS 확인됨(2026-11-18 mac):** Apple 공식 문서(Compare memberships) — 무료 계정(Personal Team)은 프로비저닝 프로필이 **발급 7일 뒤 만료**, 기기당 앱 3개, App ID 10개(7일). Expo 공식 문서(Set up your environment, physical device) — 아이폰 **개발자 모드**(설정 → 개인정보 보호 및 보안) 켜기, `npx expo run:ios --device`. 실제 순서: 맥에 `mobile/.env`(Supabase 주소·publishable 키, `EXPO_PUBLIC_API_URL=http://<맥 LAN IP>:8000`, 카카오 JavaScript 키) → 서버는 `--host 0.0.0.0` → `npx expo run:ios --device <UDID>`(prebuild로 `ios/` 생성, gitignore 대상) → Personal Team 자동 선택, 번들 ID `kr.localone.app` 그대로 등록됨.
  - 함정: 설치 단계에서 멈추면 아이폰이 `available (paired)`일 뿐 `connected`가 아닌 것. 잠금 해제 뒤 `xcrun devicectl device install app --device <UDID> <.app 경로>`로 직접 설치하면 오류가 보인다. 이번엔 **무료 서명 앱 3개 제한**에 걸려 다른 무료 서명 앱(`com.ulevelp.redo.NativeUITests.xctrunner`)을 지우고 설치함(D 결정). 설치 뒤 `npx expo start --lan`으로 Metro, `devicectl device process launch`로 실행. `expo`가 `mobile/tsconfig.json`을 고치면 `git checkout -- mobile/tsconfig.json`.
  - 서버 데이터: 정보나루 지역 코드는 행정 코드와 다르다(광주 = `24`, 북구 = `24040`. `29`는 세종). `uv run python -m app.services.provider_engine sync-libraries 24010 24020 24030 24040 24050`로 광주 도서관 29곳을 로컬 DB에 넣음
- **Android(미확인):** 집에 Android 기기가 있으면 USB 디버깅을 켜고 `npx expo run:android`. 없으면 Android Studio 에뮬레이터로 대신하고 결과에 "에뮬레이터"라고 적는다(실기기와 구분).
- 결과는 각 항목을 `- [x]`로 바꾸고 줄 끝에 `(YYYY-MM-DD mac, iOS 버전/기기)`를 붙인다. 실패하면 `- [ ]`로 두고 아래에 증상 한 줄과 이슈·DEF 번호를 적는다. 계약서 P6 확인 기록과 인계 메모도 같은 차례에 맞춘다.
