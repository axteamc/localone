# 사용자 매뉴얼

> 상태: **골격 — 화면 구현·캡처 대기(M1 동결 후 작성)**. 담당: D + 기능 담당. 선행: M1 이후 실제 화면이 있어야 함(스크린샷 필요). 갱신·작성 시점: 마일스톤 공개 전, 화면 변경 때.
> 입력: [02 요구사항](02_요구사항_정의서.md), [유저 플로우](유저_플로우.md), 실제 앱 화면.

## 작성할 내용 (M1 우선 / M2 구분)

0. **[M1]** 홈 지도에서 도서관 고르고 방문 페이지 열기(위치를 거부했을 때, 홈 하단 창 피드·인기 도서 보기, 도서관 기본값 켜고 끄기) *(M2: 방명록·오늘의 서가·방문 스탬프)*
1. **[M1]** 설치·가입·로그인(소셜 로그인 Google·Apple(iOS), 로그아웃, 탈퇴)
2. **[M1]** 도서 찾기와 도서관의 소장·대출 가능 보기("알 수 없음"·조회 시각의 의미, 대출 가능 정보는 전날 기준일 수 있음, 실시간 확인 이동)
3. **[M1]** 빌릴 예정 담기(도서관 예약이 아님)
4. **[M1]** 빌렸어요와 반납 알림(D-day 타이머, 알림 권한을 거부했을 때, 기한 수정·반납했어요)
5. **[M1]** 게시물 올리기(사진·표지·단색·글자 넣기)·철회 *(M2: 독서 기록과 서재, 기록 템플릿 게시, 작은 모임)*
6. **[M1]** 위치 권한 안내와 거부했을 때 쓰는 법 *(M3: 카메라 권한·ISBN 스캔)*
7. **[M1/M2]** 자주 묻는 질문·문제 해결 *(M2: 신고 방법)*
