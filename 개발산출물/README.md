## 3. 작업 기록 (D)

`인수인계_메모.md`(PC·세션 간 현재 상태), `진행_<작업>.md`(진행 중 작업), `명세/`(Step 구현 명세, 필요할 때), `결과/`(실행·검증 결과), `완료/`(끝난 진행 파일·옛 문서). 일일 개발 로그는 따로 만들지 않고 이 기록과 git 이력, 기능 명세서의 `구현 진행 상태`로 대신한다.
