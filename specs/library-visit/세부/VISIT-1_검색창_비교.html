지도 홈 검색창: 마이크를 넣을까?

세 화면의 검색창을 눌러 보세요. 위쪽 지도는 같고 검색창만 다릅니다.

후보 1 — 마이크만 지금 내 시안

책 제목·저자를 검색
누르면 이렇게 이어져요
검색창 → C의 책 검색 화면 / 🎤 → "듣고 있어요", 말한 글자가 검색창에 들어가 책 검색 결과로
  • 검색창이 비어 보이고 단순합니다
  • 얻는 것: 손이 바쁠 때 말로 검색, 레퍼런스(카카오맵·네이버 지도·T맵)와 같은 느낌
  • 포기하는 것: 책 검색과 도서관 검색을 가르는 자리가 없음(D 결정 13과 충돌), D가 M1 동결이라 제외한 기능

후보 2 — "도서관 찾기" 버튼만 추천 D 결정

책 제목·저자를 검색
누르면 이렇게 이어져요
검색창 → 책 검색 화면 / "도서관 찾기" → 책 검색과 확연히 다른 도서관 검색 화면(지역·도서관 이름)
  • 책 검색과 도서관 검색의 입구가 한눈에 구분됩니다
  • 얻는 것: 입구가 헷갈리지 않음, M1 범위 안(마이크는 제안으로 보관)
  • 포기하는 것: 음성 검색(나중에 제안이 채택되면 오른쪽에 추가 가능)
  • 추천 이유: 지도 홈에서 제일 먼저 눈에 띄는 입구라 D가 정한 구분이 필요하고, 마이크는 M1 밖이라 뺀 채로도 나중에 붙일 수 있음.

후보 3 — 둘 다

책 제목·저자
누르면 이렇게 이어져요
검색창 → 책 검색 / 🎤 → 음성으로 책 검색 / "도서관 찾기" → 도서관 검색
  • 검색창 안이 빽빽해져 글자 들어갈 자리가 줄어듭니다
  • 얻는 것: 음성 검색과 도서관 구분 둘 다
  • 포기하는 것: 검색창이 복잡해짐, M1 동결 밖 기능이 들어옴(D에게 제안 필요)
