VISIT-1b 홈 하단 창 시안 — 창에 무엇을 넣고 어떤 순서로 둘까

지도 아래 하얀 창(홈 하단 창)을 비교해 보세요. 화면 3개는 창 안에 무엇이 어떤 순서로 있는지만 달라요. 창 안을 손가락(마우스 휠)으로 내려 보면 아래 내용도 보여요. 카드나 책을 누르면 어디로 넘어가는지 아래에 떠요. 추천 표시가 있는 화면이 Claude의 추천이에요. 고르는 건 직접 해 주세요.
창이 얼마나 올라오는지, 아무것도 없을 때 모습은 다음에 따로 정해요. 지금은 반쯤 올라온 모습으로 같게 그렸어요.

정할 것 2. 창이 평소에 얼마나 보이고, 올리면 어디까지 올라올까결정 전

창 안의 내용은 정할 것 1에서 고른 모양(인기 도서 한 줄 → 자주 가는 도서관 소식) 그대로예요. 화면마다 위의 버튼을 눌러 창을 올리고 내려 보세요.

A. 지도 크게, 창은 아래에 조금만

무엇이 다른가
평소엔 지도가 화면 대부분이고, 창은 손잡이와 "이 동네 인기 도서" 제목 한 줄만 보여요. 올리면 화면 꼭대기까지 덮어요(멈추는 곳 2곳).
누르면 이렇게 이어져요
앱을 켬 → 지도가 크게 보이고 아래에 제목 한 줄 → 창을 올리면 화면 전체가 창이 되어 인기 도서·게시물이 보임(지도·검색창은 가려짐) → 내리면 다시 지도.
화면을 열어야 보이는 것
평소엔 책 표지가 하나도 안 보여요. 올리면 맨 위 검색창도 가려져요.
얻는 것 / 포기하는 것
지도를 넓게 봄 / 인기 도서·게시물은 올려야만 보임

B. 반쯤 보이고, 세 군데에서 멈춤 추천

무엇이 다른가
평소엔 지도와 창이 반반이고 인기 도서 한 줄이 보여요. 올리면 맨 위 검색창 바로 아래까지, 내리면 손잡이만 남아요(멈추는 곳 3곳).
누르면 이렇게 이어져요
앱을 켬 → 지도 반, 인기 도서 한 줄이 바로 보임 → 창을 올리면 검색창은 남고 게시물이 넓게 보임 → 창을 끝까지 내리면 지도가 거의 전체로 보임.
화면을 열어야 보이는 것
올렸을 때도 맨 위 검색창은 그대로 있어요. 내렸을 때는 제목 한 줄만 남아요.
얻는 것 / 포기하는 것
켜자마자 지도와 인기 도서가 같이 보이고, 필요에 따라 넓힐 수 있음 / 평소 지도가 절반이라 멀리 있는 핀은 안 보일 수 있음
추천 이유
정할 것 1에서 "한꺼번에 보이는 것"을 고르셨으니, 켜자마자 둘 다 보이는 높이가 맞아서요. 반대로, 지도로 도서관 고르는 일이 훨씬 많다면 A가 더 나아요.

C. 반쯤에 고정, 창 안에서만 내려 보기

무엇이 다른가
창이 늘 지도 아래 절반에 있어요. 끌어 올리거나 내리지 않고, 창 안을 손가락으로 내려서 더 봐요.
누르면 이렇게 이어져요
앱을 켬 → 지도 반, 인기 도서 한 줄 → 창 안을 내리면 게시물이 이어짐 → 지도는 늘 위 절반에 그대로.
화면을 열어야 보이는 것
창 안을 내려 보세요. 게시물이 좁은 칸 안에서만 움직여요.
얻는 것 / 포기하는 것
움직임이 하나라 헷갈리지 않음 / 게시물을 넓게 볼 수 없고, 지도도 넓게 볼 수 없음

정할 것 3. 아직 방문한 도서관이 없을 때, 소식 자리에 무엇을 보여 줄까결정 전

처음 앱을 켠 사람은 방문한 도서관이 없어서 "자주 가는 도서관"이 비어 있어요. 화면마다 위 버튼으로 상황을 바꿔 보세요. 인기 도서 한 줄과 창 높이는 정한 그대로예요.
로그인을 안 해도 같은 모습이에요. 게시물은 모두에게 공개된 것만, 방문 기록은 이 기기에만 남아요.

A. 안내 글만

무엇이 다른가
소식 자리에 "도서관에 가면 여기에 소식이 모여요" 안내와 "지도에서 도서관 골라 보기" 글자 버튼만 있어요.
누르면 이렇게 이어져요
처음 켬 → 인기 도서 한 줄 + 안내 글 → "지도에서 도서관 골라 보기"를 누르면 창이 내려가고 지도가 보임 → 핀을 눌러 도서관에 들어가면 다음부터 그 도서관 소식이 여기 나옴.
화면을 열어야 보이는 것
안내 글 아래는 비어 있어서 창이 짧아 보여요.
얻는 것 / 포기하는 것
무엇을 하면 채워지는지 분명함 / 첫날엔 이웃 게시물을 하나도 못 봄

B. 가까운 도서관 소식으로 대신 추천

무엇이 다른가
방문한 곳이 없으면 칸 제목이 "가까운 도서관 소식"으로 바뀌고, 지금 위치에서 가까운 도서관(최대 3곳)의 게시물을 보여 줘요.
누르면 이렇게 이어져요
처음 켬 → 인기 도서 한 줄 + 가까운 도서관 게시물 → 게시물을 누르면 게시물 상세(다른 담당 화면)로 → 도서관에 방문하기 시작하면 제목이 "자주 가는 도서관 소식"으로 바뀌고 단골 도서관 게시물로 바뀜.
화면을 열어야 보이는 것
제목 옆에 작은 글 "자주 가는 곳이 생기면 바뀌어요". 이름 알약에 거리가 붙어요(가까운 순).
얻는 것 / 포기하는 것
첫날에도 이웃 이야기를 볼 수 있음 / 내가 가 본 곳이 아닌데 보여서 "왜 이 도서관?" 할 수 있음
추천 이유
창이 처음부터 비어 보이지 않고, 이웃 게시물이 뭔지 바로 알 수 있어서요. 반대로, 내가 간 곳만 보이는 게 중요하면 A가 더 나아요.

C. 소식 칸을 숨김

무엇이 다른가
방문한 곳이 없으면 소식 칸이 아예 없고 인기 도서 한 줄만 보여요. 처음 방문하면 그때 칸이 생겨요.
누르면 이렇게 이어져요
처음 켬 → 창에 인기 도서 한 줄만 → 도서관에 방문하면 다음에 켤 때 "자주 가는 도서관 소식" 칸이 새로 생김.
화면을 열어야 보이는 것
창을 올려도 인기 도서 한 줄 아래가 비어 있어요.
얻는 것 / 포기하는 것
빈 칸이나 안내 글이 없어 깔끔함 / 이런 칸이 있다는 걸 처음엔 모름

잘 안 될 때 보이는 화면

정한 화면(인기 도서 한 줄 → 소식, 평소 반쯤) 그대로에서 잘 안 될 때 모습이에요. 문구는 Claude가 먼저 넣어 둔 거예요. 버튼을 하나씩 눌러 보세요.

이 화면에서 일어나는 일

처음부터 끝까지 이렇게 써요

  1. 사용자가 앱을 켜면 동네한권이 지도 홈과 그 아래 홈 하단 창을 보여 준다.
  2. 동네한권이 창 맨 위에 이 동네 인기 도서를 옆으로 넘기는 한 줄로 보여 준다.
  3. 사용자가 책을 누르면 그 책의 상세 화면(다른 담당 화면)으로 넘어간다.
  4. 그 아래에 자주 간 도서관 이름(최대 3개)과 첫째 도서관의 게시물이 2열로 이어진다. 이름을 누르면 그 도서관 게시물로 바뀐다.
  5. 사용자가 게시물을 누르면 그 게시물의 상세 화면(다른 담당 화면)으로 넘어간다.
  6. 평소엔 지도와 창이 반반이다. 사용자가 창을 올리면 맨 위 검색창 바로 아래까지 올라와 게시물이 넓게 보인다.
  7. 사용자가 창을 끝까지 내리면 제목 한 줄만 남고 지도가 거의 전체로 보인다. 다시 올리면 반반으로 돌아온다.
  8. 아직 방문한 도서관이 없으면 소식 칸 제목이 "가까운 도서관 소식"이 되고, 가까운 도서관(최대 3곳) 게시물이 보인다. 도서관에 방문하기 시작하면 "자주 가는 도서관 소식"으로 바뀐다.
  9. 단골 도서관에 게시물이 없으면 그 자리에 "○○에는 아직 게시물이 없어요"가 보인다.
