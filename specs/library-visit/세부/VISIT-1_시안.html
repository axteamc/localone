정할 것을 다 고른 뒤에 같이 볼 거예요. 문구는 Claude가 먼저 넣어 둔 것이에요.

처음부터 끝까지 이렇게 써요

  1. 사용자가 앱을 켜면 동네한권이 현재 위치 주변의 지도와 도서관 핀(이름·거리)을 보여 준다.
  2. 사용자가 핀을 누르면 동네한권이 그 도서관 방문 페이지로 화면을 바꾼다(다음 세부 VISIT-2).
  3. 사용자가 맨 위 검색창을 누르면 동네한권이 책 검색 화면을 연다(다른 팀원 몫).
  4. 사용자가 지도를 끌어 옮기면 동네한권이 "이 지역에서 다시 찾기" 버튼을 보여 주고, 누르면 그 지역 도서관 핀을 다시 보여 준다.
  5. 사용자가 "도서관 찾기"를 누르면 동네한권이 지도 위로 하얀 창을 반쯤 내려 보이고, 아래 지도는 흐리게 남긴다.
  6. 사용자가 지역이나 도서관 이름을 치면 동네한권이 맞는 지역·도서관을 창 안 목록으로 보여 준다.
  7. 사용자가 목록에서 하나를 누르면 동네한권이 창을 올리고 지도를 그곳으로 옮긴다(고른 도서관 핀은 테두리).
  8. 사용자가 창 밖 흐린 지도를 누르면 동네한권이 창을 닫는다.
  9. (위치도 못 쓰고 지도도 안 뜰 때: 정할 것 2를 고르면 여기를 이어서 쓴다)
  10. 보는 위치가 바뀐 동안 동네한권이 지도 아래 가운데에 "현재 위치로" 버튼을 보여 주고, 사용자가 누르면 현재 위치로 돌아온다.
