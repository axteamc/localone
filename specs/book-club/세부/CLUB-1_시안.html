book-club · CLUB-1 시안 — 방문 페이지의 모임 카드

보는 법. 화면 3개를 비교해 보세요. 휴대폰 안의 "들어가기 →"를 누르면 모임 화면이 열리고, "‹"로 돌아와요. 화면 아래 "일정 미정으로 보기"를 누르면 날짜·장소가 아직 안 정해진 모임이 어떻게 보이는지 바뀌어요. 노란 테두리가 추천이에요. 고르는 건 직접 해 주세요.
이미 정한 것. 모임 카드는 방문 페이지 피드에 게시물 사이로 섞여 나와요. 위가 둥근 아치 모양, 위에 "모임" 알약, 아래 "들어가기 →". 누르면 모임 화면으로 가고, 모임 화면은 맨 위 약속 정보 → 바로 아래 "모임에 참가" → 참가자 → 댓글 순서예요(노트에 적어 둔 것).

정할 것 1. 피드의 모임 카드에서 제일 먼저 눈에 띄는 것 확인

왜 정하나. 피드를 내리던 사람이 이 카드를 보고 "들어가 볼까?"를 정해요. 카드에서 무엇이 제일 크게 보이느냐에 따라 누가 들어오는지가 달라져요. 세 화면 모두 같은 모임이에요.
다시 보기:

후보 A — 날짜가 크게 추천

반포도서관
+

카드 맨 위에 날짜·시각이 제일 크게, 그 아래 모임 이름과 참가 인원이 작게 있어요.

누르면 이렇게 이어져요

피드를 내림 → 큰 날짜가 먼저 눈에 들어옴 → "그날 시간 되나?" 보고 "들어가기 →" → 모임 화면에서 바로 "모임에 참가".

화면을 열어야 보이는 것
  • 날짜가 미정이면 큰 글자 자리에 "날짜 미정 · 댓글로 정해요"
  • 카드 높이는 게시물 사진 카드 하나와 비슷해요(한 칸)
  • 책 이름은 카드에 없고 모임 화면에서 보여요
얻는 것 / 포기하는 것

시간이 맞는 사람이 바로 알아봐요. / 무슨 책인지는 들어가야 알아요.

표준 근거

표준 근거: P-30 2열 메이슨리 한 칸 (핀터레스트 홈) — 사진 카드와 같은 폭에 글자 정보를 얹음

추천 이유: 보내 주신 당근마켓 모임 화면에서 "날짜 장소가 한눈에 보여요"라고 하셨고, 모임 화면도 날짜·장소를 먼저 두기로 해서 카드와 화면이 같은 순서가 돼요. 책이 먼저 궁금한 사람에게는 B가 더 나아요.

후보 B — 책 표지가 크게

반포도서관
+

아치 안에 함께 읽을 책 표지가 크게 있고, 날짜는 아래에 한 줄로 작게 있어요.

누르면 이렇게 이어져요

피드를 내림 → 아는 책 표지가 먼저 눈에 들어옴 → "이 책 얘기 하는구나" 하고 "들어가기 →" → 모임 화면에서 날짜·장소를 보고 참가.

화면을 열어야 보이는 것
  • 날짜가 미정이면 작은 줄에 "날짜 미정"만 바뀌어요
  • 책을 안 정한 모임은 표지 자리에 모임 이름 글자만 크게
  • 카드가 A보다 길어요
얻는 것 / 포기하는 것

책으로 모이는 모임이라는 게 바로 보여요. / 날짜가 작아서 시간이 맞는지는 들어가서 알아요.

표준 근거

표준 근거: P-41 위 이미지 → 본문 (인스타그램 게시물) — 표지를 이미지 자리에

후보 C — 두 칸을 가로지르는 넓은 카드

반포도서관
+

피드 두 칸을 다 쓰는 가로 카드예요. 왼쪽에 달력 같은 날짜 칸, 오른쪽에 이름·시각·장소·인원이 한 번에 있어요.

누르면 이렇게 이어져요

피드를 내림 → 사진 줄이 끊기고 넓은 모임 띠가 나타남 → 한눈에 날짜·장소·인원 확인 → "들어가기 →" → 모임 화면.

화면을 열어야 보이는 것
  • 이 카드가 나오는 자리에서 두 칸 줄이 한 번 끊겨요
  • 날짜가 미정이면 날짜 칸에 "?"와 "날짜 미정"
  • 위가 둥근 아치 대신 덜 둥근 모서리(넓어서 아치가 납작해 보임)
얻는 것 / 포기하는 것

모임이 피드에서 가장 눈에 띄고 정보가 다 보여요. / 사진 사이에 섞이지 않고 흐름을 끊어요.

표준 근거

표준 근거: P-31 1열 카드 피드 (인스타그램 홈) — 그 카드 한 장만 넓게

잘 안 될 때 보이는 화면

모임 화면에서 생기는 일이에요. 버튼을 눌러 상태를 바꾸고, 휴대폰 안의 버튼도 눌러 보세요. 바뀌는 곳만 바뀌고 나머지(약속 정보)는 그대로 남아요. 문구는 제가 먼저 넣어 둔 거예요.

처음부터 끝까지 이렇게 써요

  1. 사용자가 방문 페이지 피드를 내리면 동네한권이 게시물 사이에 모임 카드를 보여 준다. 카드에는 날짜·시각이 제일 크게, 그 아래 장소·모임 이름·참가 인원이 보인다(날짜가 미정이면 "날짜 미정").
  2. 사용자가 모임 카드의 "들어가기 →"를 누르면 동네한권이 모임 화면을 연다.
  3. 동네한권이 모임 화면 맨 위에 약속 정보(책·날짜·장소·인원)를, 바로 아래에 "모임에 참가" 버튼을 보여 준다.
  4. 사용자가 "모임에 참가"를 누르면 동네한권이 바로 참가자 명단에 사용자의 닉네임을 넣고 버튼을 "참가 취소"로 바꾼다.
  5. (만들기 화면·시작 시각이 바뀔 때는 정할 것 2·3을 고른 뒤 이어서 쓴다)
