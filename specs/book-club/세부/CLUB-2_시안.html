book-club · CLUB-2 시안 — 모임이 끝난 뒤 기록·후기

보는 법. 화면 3개를 비교해 보세요. 휴대폰 안의 버튼(후기 쓰기, 게시물로 올리기, 다음 모임 만들기)을 눌러 볼 수 있어요. 화면 아래 "만든 사람으로 보기"를 누르면 모임을 만든 사람에게 보이는 모습으로 바뀌어요. 노란 테두리가 추천이에요. 고르는 건 직접 해 주세요.
이미 정한 것. 모임이 끝나면 모임 화면의 참가 버튼 자리가 "기록·후기 쓰기"로 바뀌고, 누르면 이 기록 화면이 열려요. 알림함 안내를 누르면 늘 모임 화면으로 가요. 후기는 나만 보는 게 기본이고, 원하면 게시물로 올려요. 다음 모임 만들기는 만든 사람에게 먼저 권하고, 다른 참가자도 버튼으로 만들 수 있어요. 이미 만들어진 다음 모임이 있으면 그걸 먼저 보여 줘요.

정할 것 1. 기록 화면을 열면 무엇이 먼저 보이나 확인

왜 정하나. 모임이 끝나고 기록 화면에 들어온 사람이 제일 먼저 하는 일이 달라져요. 그날 모임을 돌아보는지, 바로 후기를 쓰는지, 다음 모임으로 이어 가는지요. 세 화면 모두 같은 끝난 모임이에요.

  • 만든 사람은 다음 모임 칸이 "다음 모임 만들어 볼까요?" 권하는 카드로 보여요

정할 것 2. 누가 "안 왔다"를 정하고, 언제 불참이 되나 확인

정해진 것. 참가 신청·실제로 왔는지·불참은 서로 다른 거예요. 만든 사람이 출석을 확인할 수 있지만, 만든 사람 표시만으로나 시간이 지났다는 이유만으로 불참을 정하거나 벌을 주지 않아요. 취소된 모임·일정이 바뀐 것 때문에는 불참이 생기지 않아요. 불참이 쌓이면 3일·7일·30일·참가 불가 순서로 참가가 막혀요.
정할 것. 끝난 모임에서 "안 온 사람"이 불참이 되기까지의 길이에요. 세 화면 모두 참가 신청 3명 중 "달"이 안 온 모임이에요. 만든 사람 화면에서 "출석 확인 보내기"를 누르고, "달에게 보이는 화면"도 눌러 보세요.

처음부터 끝까지 이렇게 써요

  1. 모임의 끝나는 시각이 지나면 동네한권이 만든 사람과 참가자의 알림함에 "모임이 끝났어요" 안내를 넣는다.
  2. 사용자가 안내를 누르면 동네한권이 모임 화면을 열고, 참가 버튼 자리에 "기록·후기 쓰기"를 보여 준다.
  3. 사용자가 "기록·후기 쓰기"를 누르면 동네한권이 기록 화면을 열고 맨 위에 그날 모임 기록(날짜·장소·책·내 참가)을 보여 준다.
  4. 사용자가 그 아래 후기 칸에 후기를 쓰고 "저장"을 누르면 동네한권이 나만 보는 후기로 저장하고 "게시물로 올리기"를 보여 준다.
  5. 사용자가 더 내리면 동네한권이 다음 모임(이미 만든 다음 모임, 다음 모임 만들기)을 보여 준다.
  6. 만든 사람이 기록 화면의 "출석 확인"에서 안 온 참가자를 "안 왔어요"로 바꾸고 보내면 동네한권이 그 참가자를 관리자 확인으로 넘긴다.
  7. 관리자가 맞다고 확인하면 동네한권이 그 참가자에게 불참 1회를 기록하고 알림함에 안내를 넣는다. 참가자는 재검토를 요청할 수 있다.
