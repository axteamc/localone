book-club · CLUB-2 시안 — 모임이 끝난 뒤 기록·후기

보는 법. 화면 3개를 비교해 보세요. 휴대폰 안의 버튼(후기 쓰기, 게시물로 올리기, 다음 모임 만들기)을 눌러 볼 수 있어요. 화면 아래 "만든 사람으로 보기"를 누르면 모임을 만든 사람에게 보이는 모습으로 바뀌어요. 노란 테두리가 추천이에요. 고르는 건 직접 해 주세요.
이미 정한 것. 모임이 끝나면 모임 화면의 참가 버튼 자리가 "기록·후기 쓰기"로 바뀌고, 누르면 이 기록 화면이 열려요. 알림함 안내를 누르면 늘 모임 화면으로 가요. 후기는 나만 보는 게 기본이고, 원하면 게시물로 올려요. 다음 모임 만들기는 만든 사람에게 먼저 권하고, 다른 참가자도 버튼으로 만들 수 있어요. 이미 만들어진 다음 모임이 있으면 그걸 먼저 보여 줘요.

정할 것 1. 기록 화면을 열면 무엇이 먼저 보이나 확인

왜 정하나. 모임이 끝나고 기록 화면에 들어온 사람이 제일 먼저 하는 일이 달라져요. 그날 모임을 돌아보는지, 바로 후기를 쓰는지, 다음 모임으로 이어 가는지요. 세 화면 모두 같은 끝난 모임이에요.
다시 보기:

후보 A — 기록 → 후기 → 다음 모임 추천

맨 위에 그날 모임 기록(날짜·장소·책·내 참석), 그 아래 내 후기 칸, 맨 아래 다음 모임이 있어요.

누르면 이렇게 이어져요

모임 화면 "기록·후기 쓰기" → 그날 기록을 먼저 봄 → 아래 후기 칸에 쓰고 "저장" → 더 내리면 다음 모임 만들기·이미 만든 다음 모임.

화면을 열어야 보이는 것
  • 후기는 "나만 보기"가 기본, 쓰고 나면 "게시물로 올리기"가 생겨요
  • 만든 사람은 다음 모임 칸이 "다음 모임 만들어 볼까요?" 권하는 카드로 보여요
  • 다음 모임까지 가려면 한 번 내려야 해요
얻는 것 / 포기하는 것

그날 모임을 돌아보며 자연스럽게 후기로 이어져요. / 다음 모임은 맨 아래라 덜 눈에 띄어요.

표준 근거

표준 근거: P-40 전체 화면 상세 + 아래에 이어지는 것 (핀터레스트 핀 상세)

추천 이유: 모임 화면도 약속 정보를 맨 위에 두기로 해서, 기록 화면도 같은 순서면 덜 헷갈려요. 다음 모임을 빨리 잡는 게 더 중요하다면 C가 나아요.

후보 B — 후기 칸이 맨 위

들어오자마자 후기 칸이 열려 있어요. 그날 기록은 그 아래 한 줄로 작게, 다음 모임은 맨 아래예요.

누르면 이렇게 이어져요

모임 화면 "기록·후기 쓰기" → 바로 후기 칸에 씀 → "저장" → 아래로 내려 기록·다음 모임.

화면을 열어야 보이는 것
  • 후기 칸이 화면 위쪽 절반을 차지해요
  • 그날 기록은 접힌 한 줄("11.28 토 · 2층 세미나실 · 참석")
얻는 것 / 포기하는 것

후기를 바로 써요. / 그날 기록이 작아서 돌아보기 어려워요.

표준 근거

표준 근거: P-71 한 화면에 칸을 두고 "올리기" (당근 글쓰기)

후보 C — 다음 모임이 맨 위

맨 위에 다음 모임(이미 만든 것 또는 만들기 버튼), 그 아래 그날 기록, 맨 아래 후기 칸이에요.

누르면 이렇게 이어져요

모임 화면 "기록·후기 쓰기" → 다음 모임이 먼저 보임 → "다음 모임 만들기" 또는 이미 만든 다음 모임에 들어가기 → 후기는 내려서.

화면을 열어야 보이는 것
  • 다음 모임이 이미 있으면 그 카드가 맨 위에 커다랗게
  • 후기 칸은 맨 아래라 한 번 이상 내려야 해요
얻는 것 / 포기하는 것

모임이 다음 회차로 잘 이어져요. / 후기는 덜 쓰게 될 수 있어요.

표준 근거

표준 근거: P-42 핵심 정보 + 주 버튼 (배민 "담기")

잘 안 될 때 보이는 화면

기록 화면에서 생기는 일이에요. 버튼을 눌러 상태를 바꿔 보세요. 문구는 제가 먼저 넣어 둔 거예요(정할 것을 다 정한 뒤 다시 볼게요).

처음부터 끝까지 이렇게 써요

  1. 모임의 끝나는 시각이 지나면 동네한권이 만든 사람과 참가자의 알림함에 "모임이 끝났어요" 안내를 넣는다.
  2. 사용자가 안내를 누르면 동네한권이 모임 화면을 열고, 참가 버튼 자리에 "기록·후기 쓰기"를 보여 준다.
  3. 사용자가 "기록·후기 쓰기"를 누르면 동네한권이 기록 화면을 열고 맨 위에 그날 모임 기록(날짜·장소·책·내 참가)을 보여 준다.
  4. 사용자가 그 아래 후기 칸에 후기를 쓰고 "저장"을 누르면 동네한권이 나만 보는 후기로 저장하고 "게시물로 올리기"를 보여 준다.
  5. 사용자가 더 내리면 동네한권이 다음 모임(이미 만든 다음 모임, 다음 모임 만들기)을 보여 준다.
