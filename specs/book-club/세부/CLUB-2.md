## 1. 이 세부에서 정한 결정

**이미 정해진 것 (다시 묻지 않음)**: 끝난 모임은 모임 화면의 참가 버튼 자리가 "기록·후기 쓰기"(큰 틀 결정 3) · 알림함 안내는 종류와 관계없이 모임 화면으로(큰 틀 결정 4) · 종료 안내는 만든 사람·참가자 모두, 다음 모임 제안은 만든 사람에게만(K2-1·K2-2) · 후기는 나만 보기 기본, 게시물로 올리면 따로 고침(K2-3) · 다음 모임은 이름·소개·책·도서관 복사, 장소는 이전 값, 날짜는 새로, 자동 참가 없음, 이미 만든 다음 모임을 먼저 보여 줌(K2-4·K2-5) · 출석 확인·시각만으로 불참·패널티를 자동으로 주지 않음(K2-7) · 불참 패널티 단계 1회 3일·2회 7일·3회 30일·4회 참가 불가(K2-8) · 댓글 운영은 만든 사람 요청 → 관리자가 삭제만/삭제와 제한, 운영자만 해제(K2-9) · 제한은 참가·댓글, 사유 구분(K2-10).

### 결정 1. 기록 화면에서 먼저 보이는 것: 기록 → 후기 → 다음 모임
- 고른 것 (사용자 말): "기록이 먼저 보이는 게 좋아요" — A(맨 위 그날 기록, 그 아래 후기, 맨 아래 다음 모임)를 가리킴 (Claude 추천과 같음)
- 이유 (사용자 말): "기록이 먼저 보이는 게 좋아요. 그날 모임을 돌아볼 수 있어서요"
- 포기한 것 (반영 후 "불편해지는 점", 사용자 말): "다음 모임이 맨 아래라 찾기 어려워요"
- 차선: 차선 없음
- 유저 플로우: 모임 화면 "기록·후기 쓰기" → 기록 화면 맨 위 그날 기록 → 아래 후기 칸에 쓰고 "저장"(나만 보기) → "게시물로 올리기"(원할 때) → 더 내리면 다음 모임(만든 사람은 "다음 모임 만들어 볼까요?" 카드, 참가자는 이미 만든 다음 모임과 "다음 모임 만들기" 버튼).
- 값: 기록 카드 곡률 `radii.infoCard`, 책 표지·이름·날짜 시각("끝난 모임")·장소·참가 수·내 참가 신청/참석 → 후기 칸 2000자 → 다음 모임. 탈락: B 후기 칸 맨 위, C 다음 모임 맨 위(시안 선택 상자로 다시 볼 수 있음)

### 결정 2. 출석 확인과 불참 판정: 만든 사람이 표시하고 관리자가 확인
- 고른 것 (사용자 말): "만든 사람이 표시하고 관리자가 확인하는 게 좋아요" — A (Claude 추천과 같음)
- 이유 (사용자 말): "관리자가 확인하니까 억울하게 불참되는 사람이 없어서요"
- 포기한 것 (반영 후 "불편해지는 점", 사용자 말): "관리자 확인을 기다리는 동안 결과가 늦어요"
- 차선: 차선 없음
- 유저 플로우: 모임이 끝남 → 만든 사람 기록 화면 "출석 확인" → 참가자마다 "왔어요/안 왔어요"(기본 왔어요) → "출석 확인 보내기"(확인창) → "안 왔어요"인 사람은 관리자 확인 대기("출석 확인 결과를 기다리고 있어요") → 관리자가 맞다고 하면 불참 1회 + 본인 알림함 안내 → 본인은 재검토 요청 가능.
- 값(K2-O1·O2): 출석의 뜻 = 참가 신청한 사람이 실제로 왔는지(신청하지 않고 온 사람 추가는 없음). 불참 판정 = 만든 사람 "안 왔어요" + 관리자 확인 둘 다(만든 사람 표시만·시간 지남만으로 정하지 않음, K2-7). 취소된 모임은 출석 확인 없음(K1-12). 탈락: B 본인 "참석했어요" + 만든 사람, C 본인에게 사정 묻기(시안 선택 상자로 다시 볼 수 있음)

### 결정 3. 불참 횟수 세는 법과 4회째: 최근 1년만 셈, 참가 불가는 운영자가 풀 때까지
- 고른 것 (사용자 말): "최근 1년만 세는 게 좋아요" — A (Claude 추천과 같음)
- 이유 (사용자 말): "최근 1년만 세는 게 좋아요. 예전 실수가 계속 남지 않아서요"
- 포기한 것 (반영 후 "불편해지는 점", 사용자 말): "자주 빠지는 사람이 계속 30일까지만 가요"
- 차선: 차선 없음
- 유저 플로우: 관리자가 불참을 확인 → 최근 1년 안의 불참 수로 단계(1회 3일·2회 7일·3회 30일·4회 참가 불가) → 1년 지난 불참은 저절로 세지 않음 → "참가 불가"는 끝나는 날 없이 이어지고, 본인이 재검토를 요청하면 운영자가 풀 수 있음.
- 값(K2-O3): 셈 기준 = 관리자 확인 시각이 지금부터 365일 안인 불참. 4회째 = 기간 없음(`ends_at` null), 운영자만 해제(K2-9). 내 참가 제한 화면에 기록마다 "셈 / 1년 지나 안 셈". 탈락: B 지금까지 전부, C 연속만·90일 자동 해제(시안 선택 상자로 다시 볼 수 있음)

### 결정 4. 불참 제한 범위: 모든 모임에서 참가만 막힘, 댓글은 됨
- 고른 것 (사용자 말): "모든 모임 참가만 막히는 게 좋아요" — A (Claude 추천과 같음)
- 이유 (사용자 말): "댓글을 쓸 수 있어서요"
- 포기한 것 (반영 후 "불편해지는 점", 사용자 말): "제한 중에도 댓글로 계속 말을 걸 수 있어요"
- 차선: 차선 없음
- 유저 플로우: 불참 제한 중인 사람이 아무 모임 화면을 연다 → 참가 버튼 자리에 흐린 "지금은 모임에 참가할 수 없어요 (12.5 18:00까지)" → 댓글은 평소대로 씀 → 기간이 끝나면 다시 참가.
- 값(K2-O4): 불참 사유(`no_show`) 제한 = 모든 도서관의 모든 모임 참가(#55)만 막음, 댓글(#58)은 막지 않음. 댓글 운영 사유(`comment`) 제한은 결정 5. "참가 불가"는 괄호 없이 "지금은 모임에 참가할 수 없어요". 탈락: B 참가·댓글 모두, C 불참한 모임(다음 회차)만(시안 선택 상자로 다시 볼 수 있음)

### 결정 5. 댓글 운영 제한 기간·사유: 불참과 같은 단계, 정해진 문구
- 고른 것 (사용자 말): "불참과 같은 단계가 좋아요" — B (Claude 추천과 같음)
- 이유 (사용자 말): "규칙이 같아서 헷갈리지 않아요"
- 포기한 것 (반영 후 "불편해지는 점", 사용자 말): "처음에 3일이라 가벼워 보일 수 있어요"
- 차선: 차선 없음
- 유저 플로우: 만든 사람이 댓글 처리 요청 → 관리자 "삭제와 제한" → 본인 알림함 안내 → 내 참가 제한 화면 "모임 댓글 운영 기준에 따라 모임 댓글과 참가가 제한돼요. 최근 1년 1번째 → 3일 (11.26 18:00까지)" + 숨겨진 내 댓글 → 재검토 요청 가능 → 기간 뒤 풀림.
- 값(K2-O5): 댓글 운영 사유(`comment`) 제한은 불참과 따로, 관리자 확인 시각이 최근 365일 안인 것만 세어 1번째 3일·2번째 7일·3번째 30일·4번째 참가 불가(운영자 해제). 참가(#55)와 댓글(#58) 모두 막음(K2-10). 문구는 정해진 문장(관리자가 사유를 직접 적지 않음). 탈락: A 늘 7일, C 관리자가 기간·사유 정함(시안 선택 상자로 다시 볼 수 있음)

### 결정 6. 알림함 화면: 최신순 한 줄 목록, 열면 모두 읽음
- 고른 것 (사용자 말): "최신순으로 보이는 게 좋아요" — A (Claude 추천과 같음)
- 이유 (사용자 말): "열면 다 읽음이라서 편해서요" → "새 안내를 한 번에 확인하고 하나씩 안 눌러도 돼서요"
- 포기한 것 (반영 후 "불편해지는 점", 사용자 말): "열기만 해도 읽음이 돼서 놓칠 수 있어요"
- 차선: 차선 없음
- 유저 플로우: 내 정보의 알림 아이콘(점) → 알림함 → 최신 안내부터 한 줄씩, 새 안내에만 점 → 열자마자 모두 읽음(아이콘 점 꺼짐) → 안내를 누르면 그 모임 화면.

## 2. 유저 플로우 (정상 흐름)

1. 모임의 끝나는 시각이 지나면 동네한권이 만든 사람과 참가자의 알림함에 "모임이 끝났어요" 안내를 넣는다.
2. 사용자가 안내를 누르면 동네한권이 모임 화면을 열고, 참가 버튼 자리에 "기록·후기 쓰기"를 보여 준다.
3. 사용자가 "기록·후기 쓰기"를 누르면 동네한권이 기록 화면을 열고 맨 위에 그날 모임 기록(날짜·장소·책·내 참가)을 보여 준다.
4. 사용자가 그 아래 후기 칸에 후기를 쓰고 "저장"을 누르면 동네한권이 나만 보는 후기로 저장하고 "게시물로 올리기"를 보여 준다.
5. 사용자가 더 내리면 동네한권이 다음 모임(이미 만든 다음 모임, 다음 모임 만들기)을 보여 준다.
6. 만든 사람이 기록 화면의 "출석 확인"에서 안 온 참가자를 "안 왔어요"로 바꾸고 보내면 동네한권이 그 참가자를 관리자 확인으로 넘긴다.
7. 관리자가 맞다고 확인하면 동네한권이 그 참가자에게 불참 1회를 기록하고 알림함에 안내를 넣는다. 참가자는 재검토를 요청할 수 있다.
8. 동네한권이 최근 1년 안의 불참 수로 제한 기간(3일·7일·30일·참가 불가)을 정한다. 1년이 지난 불참은 세지 않는다.
9. 제한 중인 사람이 어느 모임 화면을 열어도 동네한권이 참가 버튼 자리에 "지금은 모임에 참가할 수 없어요 (언제까지)"를 보여 준다. 댓글은 평소대로 쓸 수 있다.
10. 사용자가 내 정보의 알림 아이콘을 누르면 동네한권이 알림함을 열어 최신 안내부터 한 줄씩 보여 주고, 새 안내에 점을 찍은 뒤 모두 읽음으로 바꾼다. 안내를 누르면 그 모임 화면이 열린다.
11. 만든 사람이 댓글 처리를 요청하고 관리자가 "삭제와 제한"을 고르면 동네한권이 댓글을 숨기고, 최근 1년 댓글 제한 횟수로 3일·7일·30일·참가 불가를 정해 본인 알림함에 안내를 넣는다. 이 동안 그 사람은 참가와 댓글을 모두 못 한다.
