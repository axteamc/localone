## 1. 이 세부에서 정한 결정

**이미 정해진 것 (다시 묻지 않음)**: 만드는 입구는 방문 페이지 `+` → 게시물/방명록/모임 고르기 → "모임"(큰 틀 결정 1) · 모임 화면은 맨 위 약속 정보 → 바로 아래 "모임에 참가" → 참가자 이름 → 댓글(큰 틀 결정 2) · 참가는 승인 없이 바로, 미정 일정도 게시·참가 가능, 참가 취소는 미정이면 언제든·확정 뒤엔 시작 전까지(K1-2~K1-4) · 만든 사람은 시간·장소를 바꿀 수 있고 시작 뒤엔 시작 시각만 못 바꿈(K1-5) · 확정·변경·취소되면 참가자 알림함에 안내(K1-6·K1-8) · 정원 선택, 시작 시각에 자동 마감, 일찍 마감 가능(K1-7) · 댓글은 로그인한 누구나(K1-9) · 모임 카드는 아치(위 70·아래 18), "모임" 알약, "들어가기 →"(디자인 기준).

### 결정 1. 피드의 모임 카드에서 제일 먼저 보이는 것: 날짜가 크게
- 고른 것 (사용자 말): "날짜 크게 보이는 게 좋아요" — A(카드 맨 위에 날짜·시각이 제일 크게)를 가리킴 (Claude 추천과 같음)
- 이유 (사용자 말): "날짜 크게 보이는 게 좋아요. 이유는 시간이 되는지 바로 알 수 있습니다"
- 포기한 것 (반영 후 "불편해지는 점", 사용자 말): "책 이름이 카드에 안 보여서 무슨 책인지 몰라요"
- 차선: 차선 없음
- 유저 플로우: 피드를 내린다 → 모임 카드의 큰 날짜로 그날 시간이 되는지 본다 → "들어가기 →" → 모임 화면 맨 위 약속 정보 → "모임에 참가".
- 값: 아치 위 70·아래 18, 바탕 `fill2`, "모임" 알약 → 날짜·요일 24 → 시각 · 장소 한 줄 14 → 모임 이름 → "n/정원명 참가" → "들어가기 →". 미정이면 날짜 자리에 "날짜 미정", 아래 "댓글로 정해요". 책 이름은 카드에 없고 모임 화면에서 보임. 탈락: B 책 표지가 크게, C 두 칸을 가로지르는 넓은 카드(시안 선택 상자로 다시 볼 수 있음)

### 결정 2. 만들기 화면 칸 순서: 이름·날짜만 보이고 나머지는 접힘 (시안 #el-editor 후보 C, 2026-11-19 D 시안 확인 후 변경)
- 고른 것: 후보 C — 처음엔 이름(필수)과 날짜·시각("미정" 스위치 포함)만 보이고, "+ 장소·책·정원·소개 더 쓰기"를 누르면 나머지 4칸이 아래에 펼쳐짐
- 차선: 차선 없음
- 유저 플로우: 방문 페이지 "+" → "모임" → 만들기 화면에서 이름·날짜(모르면 "미정")만 쓰고 바로 "올리기" (더 쓰고 싶으면 "+ 장소·책·정원·소개 더 쓰기"를 눌러 채움) → 피드 맨 위에 내 모임 카드.
- 값: 이름만 "필수", 나머지 "선택" 표시. 날짜 칸 오른쪽 "미정" 스위치(켜면 "날짜 미정 — 댓글로 정해요"). 접힌 칸을 펼치면 장소 → 책(`book-search`) → 정원 → 소개 순. 글자 수 "n/40"·"n/100"·"n/500". 입력 칸 곡률 `radii.infoCard`(9). 머리 "✕ · 모임 만들기 · 올리기"(P-03, 올리기는 무광 판). 탈락: A 한 화면에 다, B 세 단계로 나눠 묻기(시안 선택 상자로 다시 볼 수 있음)

### 결정 3. 시작 시각이 바뀌면 이미 참가한 사람은: 규칙 그대로, 바뀐 시작 시각 전까지만 (시안 #el-timechange 후보 A, 2026-11-19 D 시안 확인 후 변경)
- 고른 것: 후보 A — 안내만 가고, 다른 모임과 똑같이 바뀐 시작 시각 전까지만 "참가 취소"를 누를 수 있음(K1-4 그대로)
- 차선: 차선 없음
- 유저 플로우: 만든 사람이 시작 시각을 바꿈 → 참가자 알림함에 안내 → 누르면 모임 화면(바뀐 시각에 "바뀜" 표시) → 시작 전이면 "참가 취소" → 시작 뒤에는 버튼이 "시작한 모임이라 취소할 수 없어요".
- 값: K1-4 그대로(미정이면 언제든 취소, 확정 뒤엔 바뀐 `starts_at` 전까지 취소 가능). 탈락: B 끝날 때까지 빠질 수 있음, C 다시 묻기(시안 선택 상자로 다시 볼 수 있음)

## 2. 유저 플로우 (정상 흐름)

1. 사용자가 방문 페이지 피드를 내리면 동네한권이 게시물 사이에 모임 카드를 보여 준다. 카드에는 날짜·시각이 제일 크게, 그 아래 장소·모임 이름·참가 인원이 보인다(날짜가 미정이면 "날짜 미정").
2. 사용자가 모임 카드의 "들어가기 →"를 누르면 동네한권이 모임 화면을 연다.
3. 동네한권이 모임 화면 맨 위에 약속 정보(책·날짜·장소·인원)를, 바로 아래에 "모임에 참가" 버튼을 보여 준다.
4. 사용자가 "모임에 참가"를 누르면 동네한권이 바로 참가자 명단에 사용자의 닉네임을 넣고 버튼을 "참가 취소"로 바꾼다.
5. 사용자가 방문 페이지 "+"를 누르고 "모임"을 고르면 동네한권이 모임 만들기 화면을 연다.
6. 사용자가 처음 보이는 이름(필수)·날짜(모르면 "미정")를 채우고, 필요하면 "+ 장소·책·정원·소개 더 쓰기"를 눌러 나머지를 채운다.
7. 사용자가 "올리기"를 누르면 동네한권이 모임을 만들고 피드 맨 위에 그 모임 카드를 보여 준다.
8. 만든 사람이 머리 ⋯ → "일정·장소 바꾸기"에서 시작 시각을 바꾸면 동네한권이 이미 참가한 사람의 알림함에 안내를 넣는다.
9. 참가자가 안내를 누르면 동네한권이 모임 화면을 열고 바뀐 시각("바뀜")을 보여 준다.
10. 참가자가 바뀐 시작 시각 전에 "참가 취소"를 누르면 동네한권이 명단에서 뺀다(시작 뒤에는 "시작한 모임이라 취소할 수 없어요").
11. 만든 사람이 머리 ⋯ → "모임 취소"에서 이유를 적고 "모임 취소"를 누르면 동네한권이 모임을 "취소된 모임"으로 바꾸고 참가자 알림함에 안내를 넣는다.
