## 4. 결정 기록

### 결정 1. 모임 만드는 입구 (E1, K1-O1)

- 장면: 단골 도서관 방문 페이지에서 이웃과 만날 약속을 잡고 싶은 사람이 모임을 만들러 갈 때
- 고른 것: 방문 페이지의 `+`를 누르면 게시물·방명록·모임 중에서 고른다 → "모임" → 모임 만들기 화면
- 이유 (사용자 말): "+ 누르면 모임 고르기요, 글 쓰는 곳이랑 같이 있어서"
- 포기한 것 (사용자 말): "모임 만들려면 한번 더 눌러야 해요"
- 고르지 않은 보기: 피드 맨 위 "모임 만들기" 버튼 따로 / 피드의 모임 카드 아래 "나도 모임 열기"

## 6. 다른 기능과 닿는 곳

정해진 것(`기능_배정.md` CLUB 절·`contracts/book-club.md` C1 확정 행 그대로):

- 모임은 도서관 하나에 속한 **회차별 약속**이다. 미정 일정으로 게시·참가 가능, 확정·변경되면 참가자에게 알림함 안내.
- 참가는 **승인 없이 바로 등록**. 참가 취소는 시작 시각이 미정이면 언제든, 확정 뒤에는 시작 전까지.
- 만든 사람은 시간·장소를 바꿀 수 있고(시작 뒤에는 시작 시각 변경 불가), 정원은 선택, 시작 시각에 자동 마감·조기 마감 가능, 종료 전 취소(사유 필수, 기록 남음).
- 댓글은 참가 여부와 관계없이 로그인한 누구나. 만든 사람의 댓글 처리 요청 → 관리자가 삭제만 / 삭제와 참가 제한 중 선택.
- 종료 안내는 만든 사람·참가자 모두, 다음 모임 제안은 만든 사람만(다른 참가자는 기록 화면 버튼). 다음 모임은 자동 참가하지 않는다. 후기는 본인 비공개 기본, 별도 올리기로 공유.
- 불참 패널티 단계: 누적 1회 3일·2회 7일·3회 30일·4회 참가 불가. 출석 확인·시각 도달만으로 자동 부과하지 않는다.
- 모임 카드는 방문 페이지 피드(B `local-feed` VISIT-3 `#32`)에 섞여 나온다. 누르면 모임 화면으로 간다. VISIT-3 미머지 시 가짜 값 `TODO(연결): B`.
- 알림함 서버는 core M2-0-P1(머지 완료), 내 정보의 알림 아이콘은 A MY-2.
