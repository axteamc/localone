독서 기록 · READ-2 시안 — 전체·도서관별 보기, 기초 통계, 홈 "내 최근 독서 기록"

보는 법. 화면 3개를 비교해 보세요. 휴대폰 안의 책장을 위아래로 밀어 보고, 오른쪽 위 "전체 ⇄"를 눌러 보세요 — 도서관별 책장으로 바뀌어요. 노란 테두리가 추천이에요. 고르는 건 직접 해 주세요.
이미 정해진 것. 책장은 표지 면, 한 줄 3권, 한 달 한 줄(최근이 위·왼쪽). 책을 누르면 책장 위 카드. 오른쪽 위 "전체 ⇄"로 도서관별 책장(도서관마다 색, 한 줄 9권 옆으로 밀기, 이름표 ›를 누르면 그 도서관만)으로 바뀌어요. 도서관 없이 쓴 기록은 "전체"에만 있어요. 숫자는 내 기록만 세고, 하나도 없으면 0이에요.

정할 것 1. 책장 위쪽에 내 기록 숫자(전체·올해·이번 달)를 어떻게 둘까 확인

고른 것: 후보 A. "A가 위에 책읽은숫자 제일 보기 깔끔하고 좋은데" — 제목 아래 한 줄 글자로 숫자 셋, 책장을 밀면 같이 올라가요. 차선은 없음.
정해진 것. 위쪽 줄 오른쪽에 ⚙(배치 바꾸기)와 "전체 ⇄"가 있어요. 숫자는 전체 기록 수, 올해 읽은 수, 이번 달 읽은 수 세 가지예요. 정할 것은 그 숫자를 책장 위에 어떤 모양으로 두느냐예요. 세 화면 모두 같은 기록 12개(올해 9, 이번 달 2)예요.

제목 바로 아래 작은 글자 한 줄로 숫자 셋이 보여요. 책장을 위로 밀면 이 줄도 같이 올라가고, 제목 줄(⚙·전체 ⇄)만 남아요.

누르면 이렇게 이어져요

탭 열기 → 숫자 한 줄 + 책장 → 책장을 밀어 올리면 숫자 줄은 사라지고 책이 더 보임 → "전체 ⇄" → 도서관별 책장(숫자 줄은 그대로, 이름표 옆에 도서관마다 권수).

화면을 열어야 보이는 것
  • 처음 화면에 책장이 4달치 넘게 보임(숫자 줄이 얇아서)
  • 책장을 밀면 숫자 줄이 같이 올라가 사라짐 — 다시 보려면 맨 위로
  • 도서관별 보기에서는 이름표 옆에 "6권"처럼 도서관마다 수가 붙음

  2. 사용자가 오른쪽 위 "전체 ⇄"를 누르면 동네한권이 도서관별 책장(도서관마다 색, 한 줄에 옆으로 밀기)으로 바꿔 보여 준다.

  4. 사용자가 다시 "도서관별 ⇄"를 누르면 동네한권이 전체 책장으로 돌아간다.
