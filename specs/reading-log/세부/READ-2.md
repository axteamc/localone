## 1. 이 세부에서 정한 결정

### 결정 1. 책장 위 내 기록 숫자: 제목 아래 한 줄 글자, 책장과 같이 올라감 (시안 #el-top 후보 A)
- 고른 것 (사용자 말): "A가 위에 책읽은숫자"
- 이유 (사용자 말): "제일 보기 깔끔하고 좋은데"
- 포기한 것 (반영 후 "불편해지는 점", 사용자 말): "숫자가 작아서 체감은 덜될거같아"
- 차선: 차선 없음
- 유저 플로우: 탭 열기 → "전체 12 · 올해 9 · 이번 달 2" 한 줄 + 책장 → 책장을 밀면 숫자 줄도 올라가 사라짐 → "전체 ⇄" → 도서관별 책장(숫자 줄 그대로, 이름표 옆에 도서관마다 권수)

### 결정 2. ⚙ 배치 바꾸기: 작은 메뉴에서 순서 고르기(최근 읽은 순·오래 전 읽은 순·내가 옮긴 자리) (시안 #el-preset 후보 B)
- 고른 것 (사용자 말): "B가 제일 좋은거같은데 오래전에 읽었던 책도 제대로 확인 가능하고"
- 이유 (사용자 말): "순서대로란 생각도 들어"
- "내가 옮긴 자리"를 남기는 이유 (설명 들은 뒤 사용자 말): "그대로 두자 감명깊게 읽은책 순서대로 배치해도 재밌고 좋을거같아"
- 포기한 것 (반영 후 "불편해지는 점", 사용자 말): (책이 100권쯤 쌓인 장면을 들어 다시 물음) "많아지면 번거롭고 불편할수 있겠지만 그만큼 읽은책이 쌓인느낌이나서 좋을거같은데"
- 차선: 차선 없음
- 유저 플로우: ⚙ → 작은 메뉴(최근 읽은 순 ✓ / 오래 전 읽은 순 / 내가 옮긴 자리) → 고르면 메뉴가 닫히고 책 순서가 바뀜(한 칸은 늘 한 달) → 고른 순서는 다음에 탭을 열어도 그대로

### 결정 3. 도서관별 책장 순서: 최근에 읽은 도서관이 위 (시안 #el-libsort 후보 B)
- 고른 것 (사용자 말): "B가 좋은거같아"
- 이유 (사용자 말): "최근에 읽은책을 바로 확인할수 있다는점이 좋은거같아"
- 포기한 것 (반영 후 "불편해지는 점", 사용자 말): "도서관 순서가 바뀌는건 헷갈릴거같아"
- 차선: 차선 없음
- 유저 플로우: "전체 ⇄" → 가장 최근에 읽은 책이 있는 도서관 줄이 맨 위(이름표 옆 "2권 · 최근 11월 22일") → 새 기록을 쓰면 그 도서관이 맨 위로 → 이름표 › → 그 도서관 책장 → ‹

### 결정 4. 홈 하단 창 "내 최근 독서 기록": 인기 도서 아래, 표지 최대 5권 옆으로 넘김 (시안 #el-home 후보 A)
- 고른 것 (사용자 말): "A가"
- 이유 (사용자 말): "홈에는 어울리는데"
- 포기한 것 (반영 후 "불편해지는 점", 사용자 말): "언제 읽었는지 확인하려면 결국 눌러봐야 하는점 정도?"
- 차선: 후보 B(맨 위, 가장 최근 1권 한 줄 카드) — "B도 아깝다 싶을정도로". 사용자가 더한 생각 "지금 대여중인 도서가 있으면 저렇게 뜨고 아니면 A처럼"은 빌린 책(대출) 이야기라 이번 범위 밖 → `다음에 할 것`
- 유저 플로우: 홈 하단 창 → "이 동네 인기 도서" 한 줄 → 바로 아래 "내 최근 독서 기록" 표지 최대 5권(옆으로 넘김) → 표지 누르기 → 그 기록 화면 → ‹ → 홈. 로그인 안 했거나 기록이 없으면 칸이 없음

## 2. 유저 플로우 (정상 흐름)

<!-- 중심 요소를 정한 뒤 Claude가 결정대로 쓴다. 시안 #fullflow와 같게. -->

1. 사용자가 하단 "독서 기록" 탭을 누르면 동네한권이 내 책장(표지 면, 최근 읽은 책이 위·왼쪽)과 제목 아래 한 줄 글자로 내 기록 숫자(전체·올해·이번 달)를 보여 준다. 사용자가 책장을 밀어 올리면 숫자 줄도 같이 올라간다.
2. 사용자가 오른쪽 위 "전체 ⇄"를 누르면 동네한권이 도서관별 책장(도서관마다 색, 한 줄에 옆으로 밀기)으로 바꿔 보여 준다. 동네한권은 가장 최근에 읽은 책이 있는 도서관을 맨 위에 두고, 이름표 옆에 권수와 마지막으로 읽은 날을 붙인다.
3. 사용자가 도서관 이름표 ›를 누르면 동네한권이 그 도서관에서 읽은 책만 책장으로 보여 준다.
4. 사용자가 다시 "도서관별 ⇄"를 누르면 동네한권이 전체 책장으로 돌아간다.
5. 사용자가 ⚙를 누르면 동네한권이 작은 메뉴(최근 읽은 순·오래 전 읽은 순·내가 옮긴 자리)를 띄운다.
6. 사용자가 "오래 전 읽은 순"을 고르면 동네한권이 처음 읽은 책이 맨 위·왼쪽에 오도록 책장을 다시 꽂는다(한 칸은 한 달).
7. 사용자가 책을 꾹 눌러 같은 줄 안에서 옮기면 동네한권이 그 자리를 기억하고, 사용자가 "내가 옮긴 자리"를 고르면 동네한권이 옮겨 둔 순서로 보여 준다.
8. 사용자가 홈 하단 창을 올리면 동네한권이 "이 동네 인기 도서" 한 줄 바로 아래에 "내 최근 독서 기록" 표지를 최근 것부터 최대 5권 보여 준다(로그인했고 기록이 있을 때만).
9. 사용자가 그 표지를 누르면 동네한권이 그 기록 화면을 연다.
