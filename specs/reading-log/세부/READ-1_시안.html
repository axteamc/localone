보는 법. 화면 3개를 비교해 보세요. 휴대폰 안의 별을 눌러 보고, "저장"을 눌러 보세요 — 책장으로 돌아가고, 꽂힌 "소년이 온다"를 누르면 책장 위에 카드가 떠요. 노란 테두리가 추천이에요. 고르는 건 직접 해 주세요.
큰 틀에서 정해진 것. 오른쪽 아래 + → 한 화면에 다 같이 쓰는 쓰기 화면(책 고르기는 검색 화면) → 저장하면 책장 맨 위·왼쪽에 꽂혀요. 책장은 표지 면, 한 줄 3권, 한 달 한 줄. 책을 누르면 책장 위에 카드(표지·제목·저자·읽은 날·읽은 도서관). 기록은 나만 봐요.

정할 것 1. 책을 내가 평가하는 칸을 어떻게 둘까 확인

정해진 것. 쓰기 화면에는 책 칸, 감상, 좋았던 문장, 읽은 날, 도서관, 대출 연결이 있어요(책만 꼭, 나머지는 비워도 돼요). 처음에 "책을 누르면 책 작가와 내가 평가할 수 있는 칸"이 있으면 좋겠다고 했어요. 정할 것은 그 평가를 어떤 칸으로, 어디에 두느냐예요.

화면을 열어야 보이는 것
  • 별은 1~5개, 안 누르면 "평가 안 함"(카드에 별 줄이 안 보임)
  • 마지막으로 칠한 별을 한 번 더 누르면 다 지워짐
  • 쓰기 화면 칸이 한 줄 늘어남
얻는 것 / 포기하는 것

한 번 눌러 평가하고, 책장 카드에서 바로 보여요. / 감상과 별이 따로라 칸이 하나 더 많아요.

처음부터 끝까지 이렇게 써요

  1. 사용자가 하단 "독서 기록" 탭을 누르면 동네한권이 내 책장(표지 면, 최근 읽은 책이 위·왼쪽)을 보여 준다.
  2. 사용자가 오른쪽 아래 +를 누르면 동네한권이 쓰기 화면을 연다.
  3. 사용자가 책 칸을 누르면 동네한권이 책 검색 화면을 열고, 사용자가 책을 고르면 동네한권이 쓰기 화면으로 돌아와 책 칸을 채운다.
  4. 사용자가 책 바로 아래 별을 누르면 동네한권이 누른 별까지 칠한다(안 눌러도 저장할 수 있다). 사용자가 감상·좋았던 문장·읽은 날·도서관을 원하는 만큼 채운다.
  5. 사용자가 저장을 누르면 동네한권이 기록을 저장하고 책장 맨 위·왼쪽에 그 책을 꽂는다.
