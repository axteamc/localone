## 2. 유저 플로우 (정상 흐름)

1. 사용자가 하단 "독서 기록" 탭을 누르면 동네한권이 내 책장(표지 면, 최근 읽은 책이 위·왼쪽)을 보여 준다.
2. 사용자가 오른쪽 아래 +를 누르면 동네한권이 쓰기 화면을 연다.
3. 사용자가 책 칸을 누르면 동네한권이 책 검색 화면을 열고, 사용자가 책을 고르면 동네한권이 쓰기 화면으로 돌아와 책 칸을 채운다.
4. 사용자가 감상·좋았던 문장·읽은 날·도서관을 원하는 만큼 채운다(감상 칸으로 평가를 남기며 비워도 저장할 수 있다).
5. 사용자가 고른 책을 전에 빌린 적이 있으면 동네한권이 "이 대출과 연결할까요?" 카드를 한 번 띄운다. 사용자가 "연결하기"를 누르면 동네한권이 대출과 그 도서관을 채우고, "아니요"를 누르면 아무것도 채우지 않는다.
6. 사용자가 읽은 날·도서관·대출 연결 줄을 누르면 동네한권이 아래에서 고르는 카드를 올린다(도서관은 "도서관 없이 (집·카페)"도 고를 수 있다).
7. 사용자가 저장을 누르면 동네한권이 기록을 저장하고 책장 맨 위·왼쪽에 그 책을 꽂는다.
8. 사용자가 책장의 책을 누르면 동네한권이 책장 위에 카드(표지·제목·저자·감상 첫 줄·읽은 날·읽은 도서관)를 띄운다.
9. 사용자가 카드의 "기록 자세히 보기"를 누르면 동네한권이 기록 화면(읽은 날·도서관·대출·감상·좋았던 문장)을 연다.
10. 사용자가 오른쪽 위 ⋯ → "수정"을 누르면 동네한권이 쓰기 화면과 같은 모양의 수정 화면을 열고(책은 바꿀 수 없다), 사용자가 저장하면 동네한권이 기록 화면에 고친 내용을 보여 준다.
11. 사용자가 ⋯ → "지우기"를 누르면 동네한권이 "이 기록을 지울까요?"를 묻고, 사용자가 "지우기"를 누르면 동네한권이 기록을 지우고 책장에서 그 책을 뺀다.
12. 사용자가 아래 "게시물로 올리기"를 누르면 동네한권이 게시물 쓰기 화면으로 넘긴다(이미 올린 기록이면 "올린 게시물 보기"로 그 게시물을 연다).
