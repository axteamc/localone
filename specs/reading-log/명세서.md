## 4. 결정 기록

### 결정 1. 기록 쓰는 입구: 채택 — 오른쪽 아래 떠 있는 + (시안 #el-entry 후보 A)
- 고른 것 (사용자 말): "1번째가 좋은거같아"(오른쪽 아래 떠 있는 +)
- 이유: "요즘 사용 앱들 대부분이 오른쪽 아래 저런식으로 있어서 익숙한게 좋다 생각해" / (덧붙임) "B랑 C는 위쪽에서 눌러야하는데 폰 잡을떄 주로 손가락이 아래있을수밖에 없어서 A에 비해 B,C가 불편할거라 생각해서"
- 포기한 것: 없음(사용자) — "아쉬운점은 모르겠어 있어도 다른거에 비해 아쉬운거 적을거같은데"
- 2026-11-19: 승인(후보 A 그대로)
- 누르면 이렇게 이어진다 (유저 플로우 한 줄): + 누름 → 쓰기 화면 → 책 고르기 → 쓰기 화면으로 돌아옴 → 저장하면 목록 맨 위에 생김 (결정 2 수정에 맞춤)
- 겹침일 때 따른 쪽과 이유: 없음

### 결정 2. 쓰는 순서: 채택 — 한 화면에 다 같이(시안 #el-order 후보 C) + 책 고르기는 후보 A 모양 (2026-11-19 수정)
- 처음 고른 것 (사용자 말): "A가 검색창에 설명도 보기좋아서" → 2026-11-19 수정(PR #219 결정 코멘트): 첫 쓰기 화면은 후보 C(책 칸 + 감상 + 좋았던 문장 + 읽은 날 + 도서관), C의 "책 고르기"를 누르면 후보 A 모양의 책 검색 화면(검색창 + 결과 목록 + 고르기), 고르면 쓰기 화면으로 돌아와 책 칸이 채워짐
- 이유 (처음 고를 때 사용자 말): "바로바로 이해되는 화면이야" / "다른건 좀 지저분해" — 수정 뒤에도 책 검색 화면은 A 모양 그대로
- 포기한 것 (처음 고를 때 사용자 말): "책 찾는건 귀찮겠지만 결국 떠오른 생각쓰고 책찾아야 하는데 그렇게 치면 똑같은거라 생각해"
- 유지: 책이 하나 있어야 저장된다. 책 없이 저장하면 "책을 골라야 저장할 수 있어요"
- 누르면 이렇게 이어진다 (유저 플로우 한 줄): + → 쓰기 화면(C) → 책 고르기(A 모양) → 쓰기 화면으로 돌아옴 → 저장 → 목록 맨 위
- 겹침일 때 따른 쪽과 이유: 없음

### 결정 3. 탭에서 처음 보이는 것: 채택 — 책장(시안 #el-first 후보 B), 표지 면 배치 (2026-11-19 수정)
- 고른 것 (사용자 말): "B처럼 책장에 꽃혀 있는게 좋은거같아"
- 이유: "읽은책마다 두께도 다르고 다 다르지만 내가 읽은 나만의 책장의 느낌도 나고 채워가는 느낌으로 계속 책을 봐서 많이 채우고 싶을거같아"
- 포기한 것: (Claude 장면 제시: 책등이 좁아 언제·어디서 읽었는지 눌러야 앎) → "해결책은 책을 누르면 이런식으로 나오고 어디서 읽었는지 나오는거 까지 넣었으면 좋겠어"(책인아웃 캡처: 책장 위에 뜨는 카드)
- 사용자가 더한 방향: 책을 누르면 책장 위에 카드가 떠서 표지·제목·저자·읽은 날·**읽은 도서관**이 보인다(모양은 세부 READ-2에서, 카드에서 기록 화면으로 가는 길은 세부 READ-1 E7과 함께)
- 2026-11-19 수정(PR #219 결정 코멘트) — 책장은 유지, 책등 표기가 보기 불편해 표기만 바꿈:
  - **표지 면**: 책등이 아니라 표지가 보이게 칸에 나열(SNS 피드 화면 아래 격자처럼). 책등 두께는 쓰지 않는다
  - **한 줄 3권**(휴대폰), 책장은 아래로 쌓이고 **세로 스크롤**
  - **기본 정렬 = 시간순**: 최근에 읽은 책이 위쪽·왼쪽. 책을 **꾹 눌러** 같은 줄 안에서 자리를 바꿀 수 있다
  - **한 달 = 한 줄**, 책장 칸에 **월을 영어로**(임시, 예 `Nov`). 적게 읽으면 3|6개월씩 묶어 1~2줄로 쓰고 책장에 이름을 붙인다(아이디어 수준, 지금은 칸에 월만)
  - 위 규칙이 기본값 "시간순 정렬"이고, 다른 배치(프리셋)는 **제목 오른쪽 위 설정 버튼**에서 바꾼다
  - 세부 READ-2에서 정할 것: 프리셋 종류(시간순 외), 한 달 4권 이상일 때 줄 나눔, 묶음 책장 이름 정하는 법, 설정 버튼과 도서관 전환 버튼이 위쪽 줄에 함께 놓이는 모양
- 누르면 이렇게 이어진다 (유저 플로우 한 줄): 탭 열기 → 책장을 세로로 훑어보기(최근이 위·왼쪽) → 책 누르면 책장 위 카드 → 그 기록 화면. 기초 통계(전체·올해·이번 달)는 책장 위 한 줄
- 겹침일 때 따른 쪽과 이유: 없음

### 결정 4. 전체 ↔ 도서관별: 채택 — 도서관마다 책장 한 칸씩(시안 #el-lib 후보 B), 전환 버튼은 오른쪽 위 (2026-11-19 변경)
- 처음 고른 것 (사용자 말): "C에서 전체 누르면 다른도서관 이름 뜨면서 무엇을 읽었고 정리되어있는점" → 2026-11-19 변경(PR #219 결정 코멘트): 후보 B 채택, 후보 C는 **차선**으로 남김

## 6. 다른 기능과 닿는 곳

이미 정해진 것(`기능_배정.md` READ절, `contracts/reading-log.md` C1 확정 행):

- 독서 기록은 기본 비공개이고 본인만 본다. 도서관 없이 쓴 기록은 전체 서재에만 들어간다. 대출 기록과 독서 기록은 따로이며 연결은 사용자가 고를 때만. 기록이 없으면 통계는 0.
- 내 발자취는 독서 기록 탭의 도서관별 보기로 통합한다(별도 탭·사이드바 없음, Q-44 해소).
- 하단 탭은 홈 / 독서 기록 / 대출·반납 / 내 정보 순서. 독서 기록 탭은 READ-1에서 두 번째 자리에 생긴다.
- 책 고르기는 책 검색(C `book-search`)을 그대로 쓴다.
- "게시물로 올리기"를 누르면 게시물 쓰기 화면(B `local-feed` LOCAL-3)으로 간다. 이미 올린 기록이면 그 게시물로 간다.
- 홈 하단 창 "내 최근 독서 기록"은 A의 홈 화면(`library-visit`) 안에 들어간다(READ-2).
