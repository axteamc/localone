## 1. 이 세부에서 정한 결정

### 결정 1. 머리 배치: 왼쪽 정렬 두 줄
- 고른 것 (사용자 말): "a가 좋아요" — 이유 "피드가 많이 보여서요"가 A(머리가 낮아 피드가 가장 많이 보임)를 가리킴 (Claude 추천과 같음)
- 이유 (사용자 말): "깔끔하고 피드가 많이 보여서요."
- 포기한 것 (반영 후 "불편해지는 점", 사용자 말): 없음(사용자) — "불편한점 없어요". 처음 온 도서관에서 큰 간판 없이 "들어왔다"를 알아보기 어렵지 않은지 한 번 더 물었을 때도 "네 없어요"
- 차선: 차선 없음
- 유저 플로우: 핀을 누른다 → 옆으로 밀리며 들어온다 → 왼쪽 위 "‹", 그 아래 큰 이름, 그 아래 작은 "거리 · 오늘 운영시간"과 오른쪽 ⋯를 한눈에 본다 → 바로 아래 피드를 구경한다 → "‹"로 지도 홈으로.
- 값: 이름 20px 굵게(앱 26), 정보 12px `--text-sub`, 머리 높이 약 86(앱 115). 운영시간을 모르면 "운영시간 정보 없음", 쉬는 날 "오늘 휴관"(굵게). 탈락: B 가운데 큰 간판, C 한 줄 이름 + 정보 알약(시안 선택 상자로 다시 볼 수 있음)

### 결정 2. 피드를 올렸을 때 머리: "‹ 이름" 한 줄로 접힘
- 고른 것 (사용자 말): "a가 좋아요" (Claude 추천·기존 기본값과 같음)
- 이유 (사용자 말): "어느 도서관인지 계속 보여서요"
- 포기한 것 (반영 후 "불편해지는 점", 사용자 말): 없음(사용자) — "불편한점 없어요". 한참 내린 뒤 오늘 몇 시까지 여는지 궁금할 때(맨 위로 올라가야 보임)를 짚어 한 번 더 물었을 때도 "네 없어요"
- 차선: 차선 없음
- 유저 플로우: 피드를 내린다 → 거리·운영시간 줄이 접히고 "‹ 이름 ⋯" 한 줄만 맨 위에 남는다 → 어디서든 "‹"로 지도 홈, ⋯로 메뉴 → 맨 위로 오면 두 줄로 다시 펼쳐진다.
- 값: 한 줄 높이 약 40(앱 52), 이름 15px 굵게, 아래 은은한 그림자 `--shadow-soft`. 탈락: B 내리면 사라지고 살짝 올리면 다시 나옴, C 두 줄 그대로(시안 선택 상자로 다시 볼 수 있음)

### 결정 3. 게시물이 하나도 없을 때: 안내 + "첫 글 올리기 →"
- 고른 것 (사용자 말): "a가 좋아요" — "첫 글을 올려 보라고 해서요"가 A의 안내 문구를 가리킴 (Claude 추천과 같음)
- 이유 (사용자 말): "첫 글을 올려 보라고 해서요."
- 포기한 것 (반영 후 "불편해지는 점", 사용자 말): 없음(사용자) — "불편한점 없어요.". 글 쓸 생각 없이 구경만 하러 왔을 때를 짚어 한 번 더 물었을 때도 "네 없어요"
- 차선: 차선 없음
- 유저 플로우: 빈 도서관에 들어온다 → 피드 자리 가운데 "아직 게시물이 없어요" / "이 도서관의 첫 글을 올려 보세요" → "첫 글 올리기 →"(또는 "+")를 누른다 → 글쓰기 화면이 아래에서 올라온다. 로그인 안 했으면 "로그인하면 글을 올릴 수 있어요" 작은 창.
- 값: 안내 14px(첫 줄 굵게, 둘째 줄 `--text-sub`), 링크는 굵은 글자 + "→"(DESIGN.md "목록·카드 안의 행동은 텍스트 링크"). 탈락: B 안내 한 줄만, C 안내 + 다른 도서관 둘러보기(시안 선택 상자로 다시 볼 수 있음)

## 2. 유저 플로우 (정상 흐름)

1. 사용자가 지도 홈에서 도서관 핀을 누르면 동네한권이 화면을 오른쪽에서 왼쪽으로 밀며 그 도서관 방문 페이지를 연다.
2. 동네한권이 머리 왼쪽 위에 "‹", 그 아래 도서관 이름을 크게, 그 아래 작은 글자로 "거리 · 오늘 운영시간"과 오른쪽 ⋯를 보여 주고, 바로 아래 피드를 2열로 보여 준다. 운영시간을 모르면 "운영시간 정보 없음", 쉬는 날이면 "오늘 휴관"을 보여 준다.
3. 사용자가 피드를 내리면 동네한권이 거리·운영시간 줄을 접고 맨 위에 "‹ 이름 ⋯" 한 줄만 남긴다. 사용자가 맨 위로 돌아오면 동네한권이 다시 두 줄로 펼친다.
4. 사용자가 "‹"를 누르거나 화면 왼쪽 끝에서 밀면 동네한권이 지도 홈으로 돌아간다.
5. 게시물이 하나도 없으면 동네한권이 피드 자리 가운데에 "아직 게시물이 없어요" / "이 도서관의 첫 글을 올려 보세요"와 "첫 글 올리기 →"를 보여 준다. 동네한권은 가짜 게시물을 만들지 않는다.
6. 사용자가 "첫 글 올리기 →"나 "+"를 누르면 동네한권이 글쓰기 화면을 연다. 사용자가 로그인하지 않았으면 동네한권이 "로그인하면 글을 올릴 수 있어요" 작은 창을 띄운다.

## 6. 다른 기능과 닿는 곳

**정해진 것 (`../team/기능_배정.md` B절, 방문 페이지의 틀)**
- 방문 페이지에 들어오는 모습: 바뀐 것을 알아볼 수 있어야 한다(옆으로 밀림 + 배경·헤더 변화 + 방문 멘트 카드). 방문 멘트 카드는 첫 방문·연속 방문 주기(3·7·14·30일째, 그 뒤 100일마다)·오랜만(30일 이상 만에)일 때만 뜬다. "N번째 방문이에요"는 쓰지 않는다. 방문은 기기에만 저장하고 도서관마다 하루 한 번 센다. 문이 열리는 식의 연출은 쓰지 않는다.
- M1에는 피드만 만든다. 책장(오늘의 서가)·방명록·스탬프·룩은 M2이므로 만들지 않지만 책장이 나중에 화면 아래에 붙을 수 있게 레이아웃을 열어 둔다. 빈 가짜 화면을 만들지 않는다.
- 방문 스탬프·방명록·게시물은 대출·위치·실제 방문의 증거가 아니다. 인증 배지를 만들지 않는다.
- 도서관 기본값: 켜면 다음 실행에서 지도 없이 그 도서관 방문 페이지가 열리고, 다른 도서관이 있는 곳으로 가면 풀린다. 기기에만 저장한다(도서관 하나). 켜고 끄는 자리는 머리 오른쪽 ⋯ 메뉴이고, 같은 도서관의 누적 세 번째 방문 때 카드로 한 번 물어본다. 3일 연속 방문은 연속 멘트로 처리하고, 겹치면 누적 질문이 우선이다. 이름 옆 별·머리의 스위치·집 모양 버튼은 쓰지 않는다.
- 머리에는 도서관 이름·거리·오늘 운영시간을 보여 준다(운영시간을 못 받으면 "정보 없음"). 왼쪽 위 굵은 "‹"와 화면 왼쪽 끝에서 밀기로 지도로 돌아간다. ⋯ 버튼은 머리의 도서관 정보 줄 오른쪽이다.
- 방문 페이지에는 검색창을 두지 않는다. 대신 피드 카드 메뉴에서 책 제목·저자로 검색한다.
- 빈 피드에는 가짜 게시물을 만들지 않고 "아직 게시물이 없어요" 같은 안내만 보여 준다. 화면 모양은 기획에서 정한다.

**다른 기능과 주고받는 것**
- A `library-visit`(홈 화면): 지도 홈에서 핀을 누르면 이 화면으로 온다. "‹"·왼쪽 끝 밀기를 누르면 지도 홈으로 간다. 앱을 켤 때 지도를 건너뛰는 분기와 풀렸을 때 지도 홈의 한 줄은 계약서에서 누가 만들지 정한다.
- D `core`: 도서관 정보(#11 이름·오늘 운영시간·홈페이지), 기기 저장, 화면 경로 `/libraries/[libraryId]`.

**요구사항 (M1)**: VISIT-02·VISIT-03 중 방문 페이지 부분 (`개발산출물/02_요구사항_정의서.md`)
