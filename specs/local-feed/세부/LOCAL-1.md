## 1. 이 세부에서 정한 결정

### 결정 1. 글쓰기 버튼의 모양·자리: 오른쪽 아래에 떠 있는 둥근 "+"
- 고른 것 (사용자 말): "오른쪽 아래 + 버튼이요" (Claude 추천과 같음)
- 이유 (사용자 말): "가장 직관적이고 깔끔해요"
- 포기한 것 (반영 후 "불편해지는 점", 사용자 말): 없음(사용자) — "크게 불편한건 없는거같아요". 오른쪽 맨 아래 카드 귀퉁이를 가리는 장면을 짚어 한 번 더 물었을 때도 "네"(불편 없음)
- 차선: 차선 없음
- 유저 플로우: 피드를 구경하다가 오른쪽 아래 "+"를 누른다 → 글쓰기 화면이 아래에서 올라온다 → 사진 찍기·앨범 / 책 표지 / 단색 배경 중 하나를 고른다. 피드를 내려도 버튼은 같은 자리에 있다.
- 값: 지름 48(시안 0.75배, 앱 64), `fill1` 채움, 완전한 원(`9999px`), 오른쪽 16·아래 24, 은은한 그림자. 탈락: B 머리 오른쪽 연필, C 피드 첫 칸 "+ 올리기" 카드(시안 선택 상자로 다시 볼 수 있음)

**큰 틀에서 이미 정한 것 (다시 묻지 않음)**: 쓰는 순서 = 사진·표지·단색 → 글자 → 감상 → 책·도서관(큰 틀 결정 5) · 단색 배경 글자는 가운데(결정 2, 15px 굵게 자동 대비) · 이미지만 올릴 때 감상 칸은 접고 "+ 감상 쓰기"(결정 6) · 피드 카드는 이미지만(결정 1).

### 결정 2. 첫 화면에서 '책 표지'를 누르면: 누르자마자 책 찾기
- 고른 것 (사용자 말): "A가 마음에 드네요" — 고른 이유에 "마지막에 다시 찾을 일이 없어서요"(A만의 흐름: 처음에 찾은 책이 마지막 단계에 이미 붙어 있음)가 들어 있어 어느 후보인지 분명함 (Claude 추천과 같음)
- 이유 (사용자 말): "심플하기도 하고, 마지막에 다시 찾을 일이 없어서요."
- 포기한 것 (반영 후 "불편해지는 점", 사용자 말): 없음(사용자) — "불편점한 점 없네요". 책을 찾기 전에 떠오른 문장부터 빨리 적고 싶을 때를 짚어 한 번 더 물었을 때도 "네 없어요"
- 차선: 차선 없음
- 유저 플로우: '책 표지'를 누른다 → 책 찾기 화면에서 책을 고른다 → 표지가 들어간 글자 단계로 돌아온다 → 감상(선택) → 마지막 단계에 책·도서관이 이미 붙어 있어 바로 올린다. 표지가 없는 책이면 제목·저자로 만든 표지가 들어가고 "사진·단색으로 바꾸기"가 함께 보인다(AC-COVER).
- 탈락: B 빈 표지 틀로 먼저 쓰고 마지막에 책 찾기, C 책 찾기 뒤 표지 고르기 화면 한 번 더(시안 선택 상자로 다시 볼 수 있음)

### 결정 3. 사진·표지 위 글자 자리: 위·가운데·아래 세 자리 중 고르기, 처음은 가운데
- 고른 것 (사용자 말): "A가 좋아요" — 이유의 "버튼 한번으로 자리를 옮길수 있어서요"가 A(위·가운데·아래 버튼)를 가리킴 (Claude 추천과 같음)
- 이유 (사용자 말): "버튼 한번으로 자리를 옮길수 있어서요"
- 포기한 것 (반영 후 "불편해지는 점", 사용자 말): 없음(사용자) — "불편한점 없어요". 세 자리 모두 얼굴·책 제목에 겹치는 사진을 짚어 한 번 더 물었을 때도 "네 없어요"
- 차선: 차선 없음
- 유저 플로우: 사진·표지를 고른다 → 글자를 친다 → 글자가 가운데에 놓인다 → 겹치면 "위"나 "아래"를 한 번 누른다 → 다음 단계로. 단색 배경은 늘 가운데(큰 틀 결정 2).
- 값: 위 = 이미지 높이의 10% 지점, 가운데 = 45% 지점, 아래 = 아래 끝. 글자 15px 굵게, 자동 대비(정해짐). 탈락: B 끌어서 아무 데나, C 늘 아래(시안 선택 상자로 다시 볼 수 있음)

### 결정 4. 내 게시물을 내리는 자리: 내 게시물 상세의 ⋯ 메뉴
- 고른 것 (사용자 말): "A가 좋아요" — 이유 "실수로 누를 일이 없어서요"가 A(평소엔 숨어 있는 ⋯ 메뉴 안)를 가리킴 (Claude 추천과 같음)
- 이유 (사용자 말): "실수로 누를 일이 없어서요."
- 포기한 것 (반영 후 "불편해지는 점", 사용자 말): 없음(사용자) — "불편한 점 없어요". 게시물 세 개를 한꺼번에 내리려면 하나씩 상세를 열어야 하는 장면을 짚어 한 번 더 물었을 때도 "네 없어요"
- 차선: 차선 없음
- 유저 플로우: 내 카드를 누른다 → 상세 오른쪽 위 ⋯ → "게시물 내리기" → "이 게시물을 내릴까요? 내리면 광장과 링크에서 바로 사라져요."에서 "내리기" → 피드로 돌아오고 내 카드가 사라지며 "내렸어요" 2초. 남의 게시물 ⋯ 메뉴에는 없다. 링크로 열면 "더 이상 공개되지 않는 게시물이에요."
- 탈락: B 피드 길게 누르기 메뉴, C 상세 맨 아래 글자 버튼(시안 선택 상자로 다시 볼 수 있음)

## 2. 유저 플로우 (정상 흐름)

1. 사용자가 방문 페이지 피드를 구경하다가 오른쪽 아래에 떠 있는 둥근 "+"를 누른다. 버튼은 피드를 내려도 같은 자리에 있다.
2. 동네한권이 글쓰기 화면을 아래에서 올려 "어떤 이미지로 올릴까요?"(사진 찍기·앨범 / 책 표지 / 단색 배경)를 보여 준다.
3. 사용자가 '책 표지'를 누르면 동네한권이 책 찾기 화면으로 보낸다.
4. 사용자가 책을 고르면 동네한권이 그 책의 표지를 이미지로 넣고 글자 단계로 돌아온다. 표지가 없는 책이면 제목·저자로 만든 표지를 넣고 "사진·단색으로 바꾸기"를 함께 보여 준다.
5. 사용자가 글자를 치면 동네한권이 글자를 이미지 가운데에 놓는다. 사용자가 "위"나 "아래" 버튼을 한 번 누르면 동네한권이 글자를 그 자리로 옮긴다(단색 배경은 늘 가운데).
5-1. 사용자가 감상을 쓰거나 건너뛴다.
6. 마지막 단계에서 동네한권이 고른 책과 지금 도서관을 이미 붙여 보여 준다.
7. 사용자가 "올리기"를 누르면 동네한권이 글쓰기 화면을 닫고 피드 맨 앞에 내 카드를 보여 주며 "올렸어요"를 2초 띄운다.
8. 나중에 사용자가 내 게시물 상세에서 오른쪽 위 ⋯를 누르면 동네한권이 "게시물 내리기"가 있는 메뉴를 보여 준다(남의 게시물에는 없다).
9. 사용자가 "게시물 내리기"를 누르면 동네한권이 "이 게시물을 내릴까요? 내리면 광장과 링크에서 바로 사라져요."를 묻는다.
10. 사용자가 "내리기"를 누르면 동네한권이 게시물을 광장과 링크에서 바로 감추고, 피드로 돌아가 "내렸어요"를 2초 띄운다. 다른 사람이 링크로 열면 동네한권이 "더 이상 공개되지 않는 게시물이에요."를 보여 준다.

## 6. 다른 기능과 닿는 곳

**정해진 것 (`../team/기능_배정.md` B절, 이 세부와 관련된 줄)**
- 게시물은 올리기를 눌러야 공개된다. 철회하면 바로 목록·직접 주소에서 안 보인다. 신고·운영자 숨김이 생기기 전(M1)에는 파일럿 참여자에게만 보인다.
- 게시물 이미지는 직접 찍은 사진 / 책 표지 / 단색 중 하나이고 글자를 얹을 수 있다. 본문(감상·좋았던 문장)은 선택이며 제목·본문 없이 이미지만으로도 올릴 수 있다. 사진의 위치 정보는 올리기 전에 지운다.
- 표지가 없으면 제목·저자 표지를 만들거나 사진·단색으로 대신한다. 표지는 네이버 책 검색 API로 ISBN을 조회한다(Q-39, 한도·이용 조건은 Q-41).
- 글쓰기 버튼은 SNS 안의 +/연필이다(하단 탭에 없음). 형태·위치는 세부 명세에서 정하고 실제 시안 검토가 필수다(C-46 F3). 헤더 오른쪽 연필은 추천안일 뿐 확정이 아니다.
- 피드 카드는 제목·작성자 줄 없이 이미지만이다(글자는 이미지 안, C-48).

**다른 기능과 주고받는 것**
- C `book-search`: "책 붙이기"·"책 표지"를 누르면 책 찾기 화면(C의 화면)으로 간다. 고른 책(제목·저자·ISBN·표지 주소)이 돌아온다. 넘겨주는 값은 계약서에서 정한다.
- D `core`: 로그인한 사용자 함수, 표지 조회(네이버), 사진 위치 정보 지우기, 파일럿 참여자 범위.

**요구사항 (M1)**: LOCAL-01, LOCAL-02, NFR-05 · 수용 기준 AC-PUBLISH, AC-COVER
