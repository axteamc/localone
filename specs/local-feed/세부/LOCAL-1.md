### 결정 1. 글쓰기 버튼의 모양·자리: 오른쪽 아래에 떠 있는 둥근 "+"
- 고른 것 (사용자 말): "오른쪽 아래 + 버튼이요" (Claude 추천과 같음)
- 이유 (사용자 말): "가장 직관적이고 깔끔해요"
- 포기한 것 (반영 후 "불편해지는 점", 사용자 말): 없음(사용자) — "크게 불편한건 없는거같아요". 오른쪽 맨 아래 카드 귀퉁이를 가리는 장면을 짚어 한 번 더 물었을 때도 "네"(불편 없음)
- 차선: 차선 없음
- 유저 플로우: 피드를 구경하다가 오른쪽 아래 "+"를 누른다 → 글쓰기 화면이 아래에서 올라온다 → 사진 찍기·앨범 / 책 표지 / 단색 배경 중 하나를 고른다. 피드를 내려도 버튼은 같은 자리에 있다.
- 값: 지름 48(시안 0.75배, 앱 64), `fill1` 채움, 완전한 원(`9999px`), 오른쪽 16·아래 24, 은은한 그림자. 탈락: B 머리 오른쪽 연필, C 피드 첫 칸 "+ 올리기" 카드(시안 선택 상자로 다시 볼 수 있음)

**큰 틀에서 이미 정한 것 (다시 묻지 않음)**: 쓰는 순서 = 사진·표지·단색 → 글자 → 감상 → 책·도서관(큰 틀 결정 5) · 단색 배경 글자는 가운데(결정 2, 15px 굵게 자동 대비) · 이미지만 올릴 때 감상 칸은 접고 "+ 감상 쓰기"(결정 6) · 피드 카드는 이미지만(결정 1).

## 6. 다른 기능과 닿는 곳

**정해진 것 (`../team/기능_배정.md` B절, 이 세부와 관련된 줄)**
- 게시물은 올리기를 눌러야 공개된다. 철회하면 바로 목록·직접 주소에서 안 보인다. 신고·운영자 숨김이 생기기 전(M1)에는 파일럿 참여자에게만 보인다.
- 게시물 이미지는 직접 찍은 사진 / 책 표지 / 단색 중 하나이고 글자를 얹을 수 있다. 본문(감상·좋았던 문장)은 선택이며 제목·본문 없이 이미지만으로도 올릴 수 있다. 사진의 위치 정보는 올리기 전에 지운다.
- 표지가 없으면 제목·저자 표지를 만들거나 사진·단색으로 대신한다. 표지는 네이버 책 검색 API로 ISBN을 조회한다(Q-39, 한도·이용 조건은 Q-41).
- 글쓰기 버튼은 SNS 안의 +/연필이다(하단 탭에 없음). 형태·위치는 세부 명세에서 정하고 실제 시안 검토가 필수다(C-46 F3). 헤더 오른쪽 연필은 추천안일 뿐 확정이 아니다.
- 피드 카드는 제목·작성자 줄 없이 이미지만이다(글자는 이미지 안, C-48).

**다른 기능과 주고받는 것**
- C `book-search`: "책 붙이기"·"책 표지"를 누르면 책 찾기 화면(C의 화면)으로 간다. 고른 책(제목·저자·ISBN·표지 주소)이 돌아온다. 넘겨주는 값은 계약서에서 정한다.
- D `core`: 로그인한 사용자 함수, 표지 조회(네이버), 사진 위치 정보 지우기, 파일럿 참여자 범위.

**요구사항 (M1)**: LOCAL-01, LOCAL-02, NFR-05 · 수용 기준 AC-PUBLISH, AC-COVER
