## 1. 이 세부에서 정한 결정

**이미 정해진 것 (다시 묻지 않음)**: 책장은 방문 페이지 아래 고정, 높이 224, 한 장에 3권, 좌우로 넘김(V3-1) · 묶음은 요즘 사람들이 읽은 책·인기 도서·테마 추천 세 가지, 읽은 책이 비면 숨김(V3-2) · 책장의 책은 대출 가능 표시가 아니고 누르면 책 화면(V3-3) · 방명록은 따로 된 화면 없이 피드에 카드로 섞임, 쓰기는 로그인 필요, 내 글은 지울 수 있음(V3-6) · 인증 배지 없음(V3-7) · 방명록 카드 태그는 점 + 글자, 곡률 `radii.infoCard`(V3-10).

### 결정 1. 책장 첫 장과 넘기는 순서: 요즘 사람들이 읽은 책 → 인기 도서 → 테마 추천
- 고른 것 (사용자 말): "A가 좋아" — "최근 사람들이 찾은 책들을 먼저 보여줘서"가 A(첫 장이 이 도서관에서 반납된 책)를 가리킴 (Claude 추천과 같음)
- 이유 (사용자 말): "A가 좋아. 최근 사람들이 찾은 책들을 먼저 보여줘서"
- 포기한 것 (반영 후 "불편해지는 점", 사용자 말): 없음(사용자) — "불편한점 없어요". 처음 몇 주 반납이 쌓이기 전 첫 장이 인기 도서였다가 바뀌어 보이는 때를 짚어 다시 물었을 때도 "네 없어요"
- 차선: 차선 없음
- 유저 플로우: 방문 페이지가 열린다 → 책장 첫 장에 "요즘 사람들이 읽은 책" 3권 → 옆으로 밀면 인기 도서, 한 번 더 밀면 테마 추천 → 책을 누르면 그 책 화면에서 빌릴 수 있는지 확인. 읽은 책이 비면 그 장을 빼고 인기 도서가 첫 장, 테마가 없으면 테마 장을 뺀다.
- 값: 점 묶음 수만큼(2~3개), 처음 열 때는 늘 첫 장. 탈락: B 인기 도서 먼저, C 테마 먼저(시안 선택 상자로 다시 볼 수 있음)

### 결정 2. 방명록 쓰는 입구: "+"를 누르면 게시물/방명록 고르기
- 고른 것 (사용자 말): "A가 좋아요" — "하나로 다 쓸수 있어서요"가 A("+" 하나로 게시물·방명록을 다 씀)를 가리킴 (Claude 추천과 같음)
- 이유 (사용자 말): "A가 좋아요. 하나로 다 쓸수 있어서요"
- 포기한 것 (반영 후 "불편해지는 점", 사용자 말): 없음(사용자) — "불편한점 없어요". 사진 게시물을 자주 올리는 사람이 "+" 뒤에 매번 한 번 더 골라야 하는 때를 짚어 다시 물었을 때도 "네 없어요"
- 차선: 차선 없음
- 유저 플로우: 오른쪽 아래 "+"를 누른다 → 아래에서 "게시물 올리기 / 방명록 남기기" 고르기 창 → "방명록 남기기" → 쓰는 칸(140자까지)에 한마디 → "올리기" → 피드 맨 위에 내 방명록 카드. "게시물 올리기"는 지금의 글쓰기 화면.
- 값: 고르기 창 두 줄(제목 + 작은 설명), 쓰는 칸 140자·글자 수 "n/140", "닫기"·"올리기". 탈락: B 피드 맨 위 한 줄 입력 칸, C 머리 ⋯ 메뉴 안(시안 선택 상자로 다시 볼 수 있음)

### 결정 3. 방명록 카드 모양: 한 칸짜리 글 카드
- 고른 것 (사용자 말): "a가 좋아요" — "사진 사이에 자연스럽게 섞여서요"가 A(사진 카드와 같은 한 칸에 들어가는 글 카드)를 가리킴 (Claude 추천과 같음)
- 이유 (사용자 말): "a가 좋아요. 사진 사이에 자연스럽게 섞여서요"
- 포기한 것 (반영 후 "불편해지는 점", 사용자 말): 없음(사용자) — "불편한점 없어요". 글 카드가 밝고 조용해서 사진이 많은 피드에서 방명록을 지나칠 수 있는 때를 짚어 다시 물었을 때도 "네 없어요"
- 차선: 차선 없음
- 유저 플로우: 피드를 내린다 → 사진 카드 사이에 같은 폭의 밝은 글 카드가 섞여 보인다 → 글을 끝까지 읽는다 → 내 카드면 ⋯ → "지우기" → "이 방명록을 지울까요?" → "지우기" → 피드에서 사라진다.
- 값: 바탕 `paper`, 곡률 `radii.infoCard`(9), 위 태그 점 + "방명록"(투명도 70%), 글 15(앱) 140자까지 전부 보임, 아래 닉네임 · 언제 11(앱) `--sub`, 내 글만 오른쪽 위 ⋯. 탈락: B 두 칸을 가로지르는 한 줄 띠, C 색 쪽지 카드(시안 선택 상자로 다시 볼 수 있음)

## 2. 유저 플로우 (정상 흐름)

1. 사용자가 지도 홈에서 도서관을 누르면 동네한권이 그 도서관 방문 페이지를 연다(VISIT-2 그대로).
2. 동네한권이 방문 페이지 맨 아래에 책장 "오늘의 서가"를 붙여 보여 주고, 피드와 책장 사이를 얇게 흐리게 녹인다.
3. 동네한권이 책장 첫 장에 "요즘 사람들이 읽은 책" 3권을 보여 준다. 아직 하나도 없으면 그 묶음을 빼고 "인기 도서"를 첫 장으로 보여 준다.
4. 사용자가 책장을 옆으로 밀거나 점을 누르면 동네한권이 인기 도서 → 테마 추천 순서로 다음 묶음을 보여 준다. 테마가 없는 기간에는 테마 장을 뺀다.
5. 사용자가 책장의 책을 누르면 동네한권이 그 책 화면을 열고, 사용자는 거기서 이 도서관에서 빌릴 수 있는지 확인한다.
6. 사용자가 오른쪽 아래 "+"를 누르면 동네한권이 "게시물 올리기 / 방명록 남기기" 고르기 창을 띄운다. 로그인하지 않은 사람이 "방명록 남기기"를 고르면 "로그인하면 방명록을 남길 수 있어요" 창을 띄운다("게시물 올리기"는 지금의 글쓰기 로그인 창).
7. 사용자가 "방명록 남기기"를 고르면 동네한권이 쓰는 칸(140자까지, 글자 수 표시)을 연다. "게시물 올리기"를 고르면 지금의 글쓰기 화면을 연다.
8. 사용자가 한마디를 쓰고 "올리기"를 누르면 동네한권이 방명록을 한 번만 저장하고 피드 맨 위에 내 방명록 카드를 보여 준다. 비어 있으면 "한 글자 이상 써 주세요"를 보여 준다.
9. 동네한권이 방명록을 사진 카드와 같은 한 칸짜리 밝은 글 카드로 피드에 섞어 보여 준다. 카드 위에 점과 "방명록", 글 전부, 아래에 작게 닉네임 · 언제를 적는다.
10. 사용자가 내 방명록 카드의 ⋯를 누르고 "지우기"를 고르면 동네한권이 "이 방명록을 지울까요?" 확인창을 띄우고, "지우기"를 누르면 카드를 피드에서 내린다. 남의 카드에는 ⋯가 없다.
