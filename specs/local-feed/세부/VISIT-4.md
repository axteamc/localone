## 1. 이 세부에서 정한 결정

**이미 정해진 것 (다시 묻지 않음)**: 그날 그 도서관에 처음 들어오면 피드 오른쪽 위에 "다녀왔어요" 버튼, 방문 페이지에서 가장 눈에 띄는 표식은 이 버튼 하나(V4-1) · 누르면 찍힌다(V4-2) · 누르면 그 자리에서 나만 보기/피드에 남기기를 정하고 나중에 바꿀 수 있다(V4-3) · 피드 카드 이름은 닉네임(V4-4) · 하루 한 도서관 한 개(V4-5) · "인증"·"확인됨" 같은 말·배지 없음(V4-6) · 방문 멘트와 별개(V4-7) · 룩 4종, 방문 페이지와 거기서 연 상세만, 이어 읽기에서도 방문 중인 도서관 룩 유지(V4-8) · 룩 배정은 서버(V4-9) · 글자 대비 4.5:1(V4-10) · 공개 스탬프 카드 북마크(V4-11).

### 결정 1. "다녀왔어요"를 누른 뒤 공개 여부 고르는 모양: 누르면 아래에서 고르는 창
- 고른 것 (사용자 말): "a가 좋아요" — "누구에게 보일지 매번 골라서요"가 A(누를 때마다 창에서 나만 보기/피드에 남기기를 고름)를 가리킴 (Claude 추천과 같음)
- 이유 (사용자 말): "a가 좋아요. 누구에게 보일지 매번 골라서요"
- 포기한 것 (반영 후 "불편해지는 점", 사용자 말): 없음(사용자) — "불편한점 없어요". 매일 같은 도서관에 오는 사람이 올 때마다 창에서 한 번 더 골라야 하는 장면을 짚어 다시 물었을 때 "괜찮아요. 조금은 귀찮더라도 매번 고르는데 더 안심돼요"
- 차선: 차선 없음
- 유저 플로우: "다녀왔어요" 누름 → 아래에서 고르는 창(제목 "오늘 {도서관}에 다녀왔어요", 작은 설명 "어떻게 남길까요? 나중에 바꿀 수 있어요.") → "피드에 남기기"면 버튼이 진하게 바뀌고 피드 맨 위에 내 스탬프 카드 / "나만 보기"면 버튼만 바뀜 → "닫기"면 아무것도 남지 않음.
- 값: 창 두 줄(제목 + 작은 설명) "나만 보기"(작게 "내 기록에만 남아요")·"피드에 남기기"(작게 "이 도서관 피드에 카드로 보여요"), "닫기". 탈락: B 바로 남고 아래 안내에서 바꾸기, C 버튼 옆 스위치(시안 선택 상자로 다시 볼 수 있음)

### 결정 2. 이미 남긴 뒤 버튼과 바꾸는 자리: 진한 버튼 그대로, 다시 누르면 같은 창
- 고른 것 (사용자 말): "a가 좋아요" — "같은 창이라 헷갈리지 않아요"가 A(남긴 뒤에도 같은 버튼, 다시 누르면 정할 것 1과 같은 창)를 가리킴 (Claude 추천과 같음)
- 이유 (사용자 말): "a가 좋아요. 같은 창이라 헷갈리지 않아요"
- 포기한 것 (반영 후 "불편해지는 점", 사용자 말): 없음(사용자) — "불편한점 없어요". 남긴 뒤에도 피드 오른쪽 위 진한 버튼이 피드만 보려는 사람에게도 계속 눈에 띄는 장면을 짚어 다시 물었을 때 "괜찮아요. 오늘 다녀온게 바로 보여서 좋아요"
- 차선: 차선 없음
- 유저 플로우: 같은 날 다시 들어옴 → 피드 오른쪽 위 진한 "다녀왔어요 ✓" → 누름 → 같은 고르는 창(작은 설명 "지금은 {나만 보기|피드에 남기기}예요. 바꿀 수 있어요.") → 반대쪽을 고르면 피드의 내 스탬프 카드가 생기거나 빠짐 / 같은 쪽을 고르면 그대로.
- 값: 남긴 뒤 버튼 글자 "다녀왔어요 ✓", 채움(`inkStrong` 바탕·`paper` 글자), 곡률 9999. 탈락: B 작은 글자 표시 + ⋯ 메뉴, C 버튼 자리 스위치(시안 선택 상자로 다시 볼 수 있음)

### 결정 3. 피드의 스탬프 카드 모양: 한 칸짜리 작은 카드(도장 + 닉네임)
- 고른 것 (사용자 말): "a가 좋아요" — "방명록처럼 자연스럽게 섞여서요"가 A(방명록과 같은 한 칸 폭의 작은 카드)를 가리킴 (Claude 추천과 같음)
- 이유 (사용자 말): "a가 좋아요. 방명록처럼 자연스럽게 섞여서요"
- 포기한 것 (반영 후 "불편해지는 점", 사용자 말): 없음(사용자) — "불편한점 없어요". 카드가 작아서 사진이 많은 피드에서 남의 "다녀왔어요"를 지나칠 수 있는 장면을 짚어 다시 물었을 때 "괜찮아요. 방명록이랑 비슷해서 자연스러워요"
- 차선: 차선 없음
- 유저 플로우: 피드를 내림 → 사진·방명록 카드 사이에 작은 도장 카드 → 오른쪽 아래 북마크를 누르면 채워지고 "저장했어요" → 다시 누르면 풀림. 카드 자체를 눌러도 다른 화면으로 가지 않음.
- 값: 2열 메이슨리 한 칸, 바탕 `paper`, 곡률 `radii.infoCard`, 위 동그란 도장(날짜 `MM.DD`), "`author_nickname` · 다녀왔어요", 아래 언제(방명록과 같은 규칙), 오른쪽 아래 북마크(비움 `surface3` / 채움 `inkStrong`). 탈락: B 한 줄 띠, C 정사각 큰 도장(시안 선택 상자로 다시 볼 수 있음)

### 결정 4. 룩이 바뀌는 범위: 색과 모서리 모양까지 전부
- 고른 것 (사용자 말): "a가 좋아요" — "도서관마다 다른곳에 온 느낌이라서요"가 A(바탕·카드·버튼·책장 색과 모서리 모양이 모두 그 룩)를 가리킴 (Claude 추천과 같음)
- 이유 (사용자 말): "a가 좋아요. 도서관마다 다른곳에 온 느낌이라서요"
- 포기한 것 (반영 후 "불편해지는 점", 사용자 말): 없음(사용자) — "불편한 점 없어요". 도서관을 옮길 때마다 카드 모서리 모양까지 바뀌어 처음엔 낯설 수 있는 장면을 짚어 다시 물었을 때 "괜찮을거같아요"
- 차선: 차선 없음
- 유저 플로우: 지도 홈에서 도서관 누름 → 방문 페이지 전체가 그 도서관 룩 → 게시물을 누르면 상세도 같은 룩(이어 읽기로 다른 도서관 글을 열어도 방문 중인 도서관 룩) → ‹로 홈에 돌아가면 기본 색.
- 값: `getTheme(look)`의 색 토큰 전부 + `radii`(아치 룩 card 18·infoCard 9·bookCover [5,9,9,5] / modern 6·6·[2,4,4,2]). 머리·피드 바탕·게시물·방명록·스탬프 카드·"다녀왔어요"·"+"·책장 선반·표지 없는 책 모두. 탈락: B 색만, C 머리 띠·책장만(시안 선택 상자로 다시 볼 수 있음)
