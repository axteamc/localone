local-feed · VISIT-3 시안 — 도서관 방문 페이지 아래 "오늘의 서가"(책장)와 방명록

보는 법. 화면 3개를 비교해 보세요. 휴대폰 안 책장은 옆으로 밀거나 점을 눌러 넘길 수 있고, 책을 누르면 어디로 가는지 한 줄로 떠요. 휴대폰 아래 버튼으로 "요즘 사람들이 읽은 책"이 아직 비어 있을 때 모습도 볼 수 있어요. 노란 테두리가 추천이에요. 고르는 건 직접 해 주세요.

정할 것 1. 책장을 처음 볼 때 어떤 책 묶음이 먼저 보일까 확인

이미 정해져 있어요. 방문 페이지 맨 아래에 책장이 붙어 있고, 한 번에 책 3권이 보여요. 옆으로 넘기면 묶음이 바뀌어요. 묶음은 세 가지예요 — 요즘 사람들이 읽은 책(이 도서관에서 "반납했어요"를 누른 책을 모은 것) · 인기 도서(도서관에서 많이 빌린 책) · 테마 추천(도서관 쪽에서 고른 책). "요즘 사람들이 읽은 책"이 아직 하나도 없으면 그 묶음은 숨겨요. 책장의 책은 "빌릴 수 있다"는 뜻이 아니에요.
정할 것은 책장을 처음 볼 때 어느 묶음이 첫 장이고, 넘기면 어떤 순서로 나오느냐예요.
고른 것: 후보 A — 요즘 사람들이 읽은 책이 먼저. "A가 좋아. 최근 사람들이 찾은 책들을 먼저 보여줘서" · 차선 없음 · 불편한 점: 없음(사용자) — "불편한점 없어요" → (처음 몇 주 첫 장이 바뀌어 보이는 때를 짚어 다시 물음) "네 없어요"
다시 보기:

후보 A — 요즘 사람들이 읽은 책이 먼저 추천

첫 장이 이 도서관 사람들이 실제로 읽고 반납한 책이에요. 넘기면 인기 도서 → 테마 추천.

누르면 이렇게 이어져요

방문 페이지가 열림 → 아래 책장 첫 장에 "요즘 사람들이 읽은 책" 3권 → 옆으로 밀면 인기 도서, 한 번 더 밀면 테마 → 책을 누르면 그 책 화면에서 빌릴 수 있는지 확인.

화면을 열어야 보이는 것
  • 점 3개, 지금 장의 점만 진하게. 제목 옆에 "최근 30일 · 이 도서관"처럼 기준이 작게
  • 비어 있으면(위 버튼) 첫 장이 인기 도서로 바뀌고 점이 2개로 줄어요 — 아직 반납 기록이 쌓이기 전인 처음 몇 주는 대부분 이 모습이에요
얻는 것 / 포기하는 것

도서관마다 첫 장이 달라 "이 동네 사람들이 읽는 책"이 바로 보여요. / 처음에는 대부분 비어 있어서, 도서관마다 첫 장이 바뀌어 보여요.

표준 근거

표준 근거: P-33 가로로 넘기는 띠 (넷플릭스·앱스토어 줄) — 묶음마다 맛보기

추천 이유: 세 묶음 중 이 도서관에서만 볼 수 있는 것이 "요즘 사람들이 읽은 책"뿐이라, 방문 페이지가 "이 도서관에 왔다"는 느낌을 주는 데 가장 맞아요. 비면 저절로 인기 도서가 먼저 나와서 빈 첫 장도 없어요.

후보 B — 인기 도서가 먼저

첫 장이 늘 인기 도서예요. 넘기면 요즘 사람들이 읽은 책 → 테마 추천.

누르면 이렇게 이어져요

방문 페이지가 열림 → 책장 첫 장에 "인기 도서" 3권 → 옆으로 밀면 요즘 사람들이 읽은 책, 한 번 더 밀면 테마 → 책을 누르면 그 책 화면.

화면을 열어야 보이는 것
  • 점 3개. 비어 있어도(위 버튼) 첫 장은 그대로 인기 도서이고 점만 2개로 줄어요
  • 어느 도서관에 들어가도 첫 장 모양이 같아요
얻는 것 / 포기하는 것

첫 장이 늘 채워져 있고 도서관마다 같은 자리에 같은 묶음이 있어요. / 인기 도서는 도서관끼리 비슷해서 "이 도서관만의 책"은 한 번 넘겨야 보여요.

표준 근거

표준 근거: P-33 가로로 넘기는 띠 — 늘 있는 묶음을 앞에

후보 C — 테마 추천이 먼저

첫 장이 테마 추천("비 오는 날 읽기 좋은 책"처럼 이름이 붙은 묶음)이에요. 넘기면 요즘 사람들이 읽은 책 → 인기 도서.

누르면 이렇게 이어져요

방문 페이지가 열림 → 책장 첫 장에 테마 이름과 3권 → 옆으로 밀면 요즘 사람들이 읽은 책, 한 번 더 밀면 인기 도서 → 책을 누르면 그 책 화면.

화면을 열어야 보이는 것
  • 책장 제목 자리가 테마 이름이라 철마다 첫 장 제목이 바뀌어요
  • 테마가 없는 기간에는 테마 장이 빠지고 요즘 사람들이 읽은 책(그것도 비면 인기 도서)이 첫 장이 돼요
얻는 것 / 포기하는 것

계절·행사에 맞춘 책이 먼저 보여 들어올 때마다 새로워요. / 테마가 있는 때와 없는 때 첫 장이 자주 바뀌고, 동네 사람들이 읽은 책은 뒤로 밀려요.

정할 것 2. 방명록은 어디를 눌러서 쓰기 시작할까 결정 전

이미 정해져 있어요. 방명록은 이 도서관에 남기는 짧은 한마디예요. 따로 된 화면이 없고, 올리면 피드에 게시물과 섞여 카드로 나와요. 쓰려면 로그인해야 해요. 오른쪽 아래 "+"는 지금처럼 게시물 글쓰기 버튼이에요. 쓰는 칸(140자까지, "올리기")은 세 후보 모두 같아요.
정할 것은 방명록을 쓰러 어디를 눌러 들어가느냐예요. 휴대폰 안을 눌러 직접 한마디를 올려 보세요.

후보 A — "+"를 누르면 게시물/방명록 고르기 추천

오른쪽 아래 "+" 하나로 둘 다 써요. 누르면 "게시물 올리기 / 방명록 남기기" 중 고르는 작은 창이 떠요. "+"를 눌러 보세요.

누르면 이렇게 이어져요

"+" 누름 → 아래에서 고르기 창 → "방명록 남기기" → 쓰는 칸에 한마디 → "올리기" → 피드 맨 위에 내 방명록 카드.

화면을 열어야 보이는 것
  • 화면에 새 버튼이 늘지 않아요 — 피드와 책장 모양이 지금 그대로
  • 게시물만 쓰려는 사람도 "+" 뒤에 한 번 더 골라야 해요
얻는 것 / 포기하는 것

"쓰는 건 다 +에서"라 찾기 쉽고 화면이 깔끔해요. / 게시물을 쓸 때마다 한 번 더 눌러야 해요.

표준 근거

표준 근거: P-05 떠 있는 주 행동 버튼(+) + P-04 아래에서 올라오는 작은 창

추천 이유: 이미 정한 "오른쪽 아래 +" 하나를 그대로 쓰는 길이라, 쓰기 입구가 두 군데로 갈라지지 않아요. 피드와 책장 자리도 하나도 줄지 않아요.

후보 B — 피드 맨 위 한 줄 입력 칸

피드 맨 위에 "정독도서관에 한마디 남기기…" 한 줄이 늘 있어요. 그 줄을 누르면 바로 쓰는 칸이 열려요. "+"는 게시물 전용이에요.

누르면 이렇게 이어져요

방문 페이지가 열림 → 피드 맨 위 한 줄을 봄 → 누름 → 쓰는 칸에 한마디 → "올리기" → 그 줄 바로 아래에 내 방명록 카드.

화면을 열어야 보이는 것
  • 들어오자마자 "한마디 남기기" 줄이 보여서 방명록이 있다는 걸 바로 알아요
  • 그 줄만큼 첫 화면에 보이는 게시물이 조금 줄고, 피드를 내리면 줄도 같이 올라가 사라져요
얻는 것 / 포기하는 것

한 번 눌러 바로 쓰고, 방명록이 눈에 잘 띄어요. / 첫 화면 피드 자리가 줄고, 쓰는 입구가 "+"와 두 군데가 돼요.

표준 근거

표준 근거: P-71 한 화면에 칸을 두고 "올리기" (트위터·당근 짧은 글)

후보 C — 머리 ⋯ 메뉴 안 "방명록 남기기"

도서관 이름 옆 ⋯를 누르면 지금 메뉴 맨 위에 "방명록 남기기"가 더해져요. "+"는 게시물 전용이에요. ⋯를 눌러 보세요.

누르면 이렇게 이어져요

⋯ 누름 → 메뉴 맨 위 "방명록 남기기" → 쓰는 칸에 한마디 → "올리기" → 피드 맨 위에 내 방명록 카드.

화면을 열어야 보이는 것
  • 평소 화면에는 방명록 입구가 전혀 보이지 않아요
  • ⋯ 메뉴가 3줄로 늘어요
얻는 것 / 포기하는 것

화면이 가장 깔끔하고 "+"는 지금처럼 바로 게시물로 가요. / 방명록이 있다는 걸 모르는 사람이 많아요.

처음부터 끝까지 이렇게 써요

  1. 사용자가 지도 홈에서 도서관을 누르면 동네한권이 그 도서관 방문 페이지를 연다(VISIT-2 그대로).
  2. 동네한권이 방문 페이지 맨 아래에 책장 "오늘의 서가"를 붙여 보여 주고, 피드와 책장 사이를 얇게 흐리게 녹인다.
  3. 동네한권이 책장 첫 장에 "요즘 사람들이 읽은 책" 3권을 보여 준다. 아직 하나도 없으면 그 묶음을 빼고 "인기 도서"를 첫 장으로 보여 준다.
  4. 사용자가 책장을 옆으로 밀거나 점을 누르면 동네한권이 인기 도서 → 테마 추천 순서로 다음 묶음을 보여 준다. 테마가 없는 기간에는 테마 장을 뺀다.
  5. 사용자가 책장의 책을 누르면 동네한권이 그 책 화면을 열고, 사용자는 거기서 이 도서관에서 빌릴 수 있는지 확인한다.
  6. (방명록 쓰기·카드는 정할 것 2·3을 고른 뒤 이어서 쓴다)
