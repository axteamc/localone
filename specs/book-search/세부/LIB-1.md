## 1. 이 세부에서 정한 결정

<!-- 확인 목록에서 '확인'이 된 것만 적는다. -->

### 결정 1. 검색 결과 목록의 모양: 2열 표지 큰 카드가 기본, 오른쪽 위 버튼을 누르면 1열 목록으로 바뀜
- 장면: 책 이름을 치고 검색하면 표지가 큰 카드 2열로 결과가 나온다. "내 주변 3km 도서관 기준" 줄 오른쪽 버튼을 누르면 같은 결과가 1열 목록(작은 표지 + 출판사·연도)으로 바뀌고, 다시 누르면 돌아온다.
- 이유 (사용자 말): "첫번째 화면은 시력이 안좋으신분들이나 어른들이 보기 편하시게 좋게 고른거고 두번째는 뭐 젊은 사람들이 그런식으로 보는걸 좋아하는분들이 잇으니 골랏어"
- 차선: 1열 목록(버튼으로 바꿔 볼 수 있게 함께 들어감). 탈락: 1열 큰 카드
- 포기한 것 (사용자 말): "불편해지는 점은 화면 이크게나오냐 안나오냐 차이지 시력이 안좋은사람들일수로 큰화면 를 선호 하시니까 그러니 시력좋은사람과 안좋은사람 이 편하게볼수잇게 설정하라는거다" — 차이는 화면이 크게 나오느냐뿐이고, 그래서 둘 다 고를 수 있게 한 것이라는 뜻
- 값: 기본 한 화면 6권쯤, 목록 5~7권. 버튼 글자 "☰ 목록으로" / "▦ 표지로"는 기본값(Claude). 사용자는 "카테고리 버튼"이라고 부름
- 유저 플로우: 검색 → 2열 결과 → (원하면) 오른쪽 위 버튼 → 1열 목록 → 책을 누름 → 책 상세

## 2. 유저 플로우 (정상 흐름)

1. 사용자가 검색창을 누르면 동네한권이 키보드와 함께 검색 진입 화면(전국 기준)을 연다.
2. 사용자가 책 이름을 치고 검색하면 동네한권이 결과를 표지 큰 2열로 보여 준다.
3. 사용자가 오른쪽 위 "☰ 목록으로"를 누르면 동네한권이 같은 결과를 1열 목록으로 바꿔 보여 준다(다시 누르면 2열).
4. (정할 것 2·3을 고르면 이어서 쓴다)

## 6. 다른 기능과 닿는 곳

- [큰 틀에서 이미 정함, 다시 묻지 않음] 결정 1(책 옆 "어제 기준 · 대출 가능"), 결정 4(책 옆에서 시작해 도서관 고르는 창에서 저장), 결정 5(추천 검색어 보여 주기), 결정 6(화면을 내리면 계속 나오기), 결정 9("실시간 확인"은 도서관 카드 맨 아래 큰 버튼 — LIB-2), 결정 10("현재 도시 내 모든 도서관 검색"은 검색창 바로 아래에 늘 보이게 — 모양은 LIB-2, 이 세부 시안에는 자리만)
- D가 정한 것(기능_배정.md 도서 탐색): 소장·대출 정보는 D의 조회 엔진으로만 받고 세 갈래 상태와 "알 수 없음 + 다시 시도"를 보여 준다. 대출 가능은 전날 기준이라 항상 기준일과 함께 쓴다. 검색 진입 화면은 키보드 위 영역에 추천 도서·최근 본 도서가 스크롤된다(02 LIB-01). 추천은 범위별 활성 테마가 있으면 테마, 없거나 비면 인기 도서, 조회 실패는 오류·다시 시도. 최근 본 도서는 검색 결과에서 상세를 연 책만, 다시 본 책은 맨 앞, 개별·전체 삭제, 비로그인은 이 기기에만 저장.
- D 결정 10 영향(VISIT_LOCAL_D결정.md:24, C-54): 방문 페이지에는 검색창이 없어 M1에는 "도서관 안에서 검색을 여는" 길이 없다. **검색 진입 화면은 항상 전국 기준으로 열린다.** 도서관별 추천(C-46 E3)은 규칙으로만 남기고 쓰는 화면이 생길 때 켠다 → 이 세부의 시안·플로우에 도서관별 추천을 넣지 않는다.
- A(도서관 방문)와 닿는 곳: 지도 홈 맨 위 검색창을 누르면 이 세부의 검색 진입 화면이 열린다(D 결정 11). 그 검색창 안 오른쪽 "도서관 찾기" 버튼은 A의 도서관 검색으로 가고 책 검색과 화면이 확연히 다르다(D 결정 13). 마이크(음성 검색)는 M1에 없다.
- LIB-2와 닿는 곳: 책 상세 아래의 도서관 목록과 "실시간 확인"은 LIB-2에서 정한다. 이 세부의 시안에서는 자리만 가짜 값으로 둔다.
- LIB-3과 닿는 곳: "빌릴 예정" 저장·목록은 LIB-3에서 정한다. 이 세부의 시안에서는 버튼 자리만 둔다.
