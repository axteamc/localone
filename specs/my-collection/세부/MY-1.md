## 1. 이 세부에서 정한 결정

### 결정 1. 위쪽 내 프로필 배치 (Y-O1): 왼쪽 사진 + 옆에 이름·소개·"프로필 수정"
- 고른 것 (사용자 말): 1번째 화면(왼쪽 사진 + 옆에 이름). "공백은 적고 있을 건 다 잘 보이고"
- 이유 (사용자 말): "공백은 적고 있을 건 다 잘 보이고 깔끔해 보여"
- 포기한 것 (반영 후 "불편해지는 점", 사용자 말): 없음(사용자). 소개 없음 보기에 대해 "자기소개 없을 때 칸 절약되는 거 나쁘지 않은 거 같아". 프로필 수정은 "안 들어가져서 잘 모르겠고"(MY-2 전이라 안내만 뜸)
- 차선: 차선 없음
- 탈락 이유 (사용자 말): B 가운데 큰 사진 — "내 정보가 너무 커서 다른 목록 보기가 힘들어" / C 한 줄로 작게 — "내 정보가 너무 적어서 좀 아쉬운 느낌"
- 유저 플로우: "내 정보" 탭을 누르면 → 위 왼쪽에 내 사진, 옆에 이름·소개·"프로필 수정", 바로 아래 탭과 내 게시물 카드 → 내리면 프로필은 위로 사라지고 탭이 맨 위에 붙음 → 카드를 누르면 게시물 상세. 오른쪽 위 ⚙는 설정·로그아웃.

### 결정 2. 좋아요 취소·북마크 해제 뒤 카드 (Y-O4): 흐리게 남고 "되돌리기", 4초 뒤 함께 빠짐
- 고른 것 (사용자 말): "1번에 2번처럼 흐릿하게 남겨 주면 좋을 거 같고", "되돌리기는 몇 초 뒤에 사라지는 식"
- 이유 (사용자 말): "사라지기 전에 게시글 보고 고민돼서 되돌릴 수도 있고, 되돌리기만 남겨 두기는 좀 그렇긴 해"
- 이유 더 (반영 후, 사용자 말): "다른 거는 너무 딱딱하거나 설명이 모자란데 지금 고른 안은 그런 단점이 없거나 적어"
- 포기한 것 (반영 후 "불편해지는 점", 사용자 말): 연달아 취소하면 흐린 카드가 여러 개 남는 장면을 물음 → "연달아 취소할 때는 전에 취소 누른 거 바로 없어지는 식으로 만들 수 있어?" → 흐린 카드는 한 번에 하나만 두도록 반영 → "응 합친 안에 내가 생각한 게 딱 맞는 거 같아"
- 차선: 차선 없음
- 탈락 이유 (사용자 말): A 바로 빠지고 되돌리기 — "되돌리기만 남겨 두기는 좀 그렇긴 해"
- 유저 플로우: 카드를 길게 누름 → "좋아요 취소" → 카드가 흐리게 "취소함"으로 남고 아래 "좋아요를 취소했어요 · 되돌리기" 4초 → 되돌리기를 누르면 원래대로 / 안 누르면 4초 뒤 안내와 카드가 함께 빠짐. 4초 안에 다른 카드도 취소하면 앞 카드는 바로 빠지고 새 카드만 흐리게 남음. 북마크 탭의 북마크 해제도 같음.

### 결정 3. 탭이 비었을 때 (Y-O3): 탭별 안내 한 줄 + "가까운 도서관 둘러보기" 버튼(화살표 없음)
- 고른 것 (사용자 말): "1번째꺼 가까운 도서관 둘러보기", "화살표 없는 게 좋고"
- 이유 (사용자 말): "2번이 너무 불친절한 거 같고, 3번은 여기다 설명 안 적어도 될 거 적은 거 같아"
- 포기한 것 (반영 후 "불편해지는 점", 사용자 말): "아냐 원하는 대로 잘 바뀌었고 이유는 좀 전의 B, C 이유와 같아" (장면 하나 더 묻는 중)
- 차선: 차선 없음
- 탈락 이유 (사용자 말): B 안내 한 줄만 — "너무 불친절한 거 같고" / C 그림으로 순서 안내 — "여기다 설명 안 적어도 될 거 적은 거 같아"
- 유저 플로우: 빈 탭을 봄 → 탭에 맞는 안내 한 줄 → "가까운 도서관 둘러보기"를 누르면 홈 탭으로 → 도서관 블록을 눌러 방문 페이지에서 글·좋아요·북마크 → 이 탭에 모임.
- 문구: 내 게시물 "아직 올린 게시물이 없어요" / "도서관 방문 페이지에서 첫 글을 올려 보세요" · 좋아요 "아직 좋아요한 게시물이 없어요" / "마음에 드는 게시물에 ♡를 누르면 여기 모여요" · 북마크 "아직 북마크한 게시물이 없어요" / "다시 보고 싶은 게시물을 북마크하면 여기 모여요"
