## 1. 이 세부에서 정한 결정

### 결정 1. 프로필 수정 화면 배치: 후보 A — 한 화면에 사진·닉네임·한 줄 소개를 모두 두고 맨 아래 "저장"
- 고른 것 (사용자 말): "A가 제일 편하고 알아보기 좋은데" / "사진이랑 입력칸이 한번에 보이고"
- 이유 (사용자 말): "입력하기 편하게 나와있어" · B를 뺀 이유 "왔다갔다 하는게 별로였어"
- 포기한 것 (반영 후 "불편해지는 점", 사용자 말): "불편한건 못느끼겠어 없어보이는데" → 키보드가 화면 아래를 덮는 장면을 묻자 "키보드 올라오는걸 못봐서 좀 애매하긴한데 보기엔 제일 좋다고 생각해" — 없음(사용자)
- 차선: 후보 C — "C도 나쁘진않았어"
- 유저 플로우: "프로필 수정" 누름 → 옆에서 고치는 화면이 들어옴(사진 위 가운데, 닉네임·한 줄 소개 칸 아래) → 세 가지를 한 번에 고침 → 맨 아래 "저장" → 내 정보로 돌아오며 "저장했어요"

### 결정 2. 사진 고르기·지우기 모양: 후보 C — 사진 모서리 ✎를 누르면 사진 옆 작은 메뉴
- 고른 것 (사용자 말): "볼펜모양 누르면 사진 설정하는기능"
- 이유 (사용자 말): "C가 제일 보기 좋다고 생각하고 이해하기도 빠를거같아"
- 포기한 것 (반영 후 "불편해지는 점", 사용자 말): (확인 중)
- 차선: 차선 없음
- 유저 플로우: ✎ 누름 → 사진 옆 작은 메뉴("사진 찍기"·"앨범에서 고르기"·"사진 지우기") → 고름 → 사진 자리가 바뀜 → 맨 아래 "저장"
- 함께 받은 말: "사진 모서리 볼펜모양 눌러 보세요 이거 없애고" — 시안의 안내 글자를 뺐다(앱 화면에는 원래 없음)

## 2. 유저 플로우 (정상 흐름)

1. 사용자가 하단 `"내 정보"` 탭을 누르면 동네한권이 위쪽에 내 사진·닉네임·한 줄 소개와 `"프로필 수정"` 버튼을 보여 준다.
2. 사용자가 "프로필 수정"을 누르면 동네한권이 옆에서 들어오는 프로필 수정 화면을 열고, 위 가운데에 사진, 그 아래에 닉네임 칸과 한 줄 소개 칸을 한꺼번에 보여 준다.
3. 사용자가 닉네임·한 줄 소개 칸에 글자를 고치면 동네한권이 칸 아래에 글자 수(/40, /60)를 보여 준다.
4. 사용자가 맨 아래 "저장"을 누르면 동네한권이 고친 칸만 저장하고, 내 정보로 돌아가 "저장했어요"를 잠깐 보여 준다.
5. 사용자가 고친 뒤 저장하지 않고 ‹를 누르면 동네한권이 "고친 내용을 버릴까요?"를 묻는다.
6. 사용자가 사진 모서리의 볼펜 모양(✎)을 누르면 동네한권이 사진 옆에 "사진 찍기"·"앨범에서 고르기"·"사진 지우기"(사진이 있을 때만) 작은 메뉴를 띄운다.
7. 사용자가 "앨범에서 고르기"로 사진을 고르면 동네한권이 사진 자리를 새 사진으로 바꿔 보여 주고, "저장"을 누를 때 위치 정보를 지운 뒤 저장한다.
8. 사용자가 "사진 지우기"를 누르면 동네한권이 사진 자리를 기본 그림으로 바꾸고, "저장"을 누를 때 사진을 지운다.
